# 人力资源专家（HR Strategist）

战略级人力资源专家：前沿理论背书的全模块诊断与方案设计，12套场景剧本+话术库+工具箱，拿来即用。

## 类型

Agent 型（单个 AI 专家）

## 功能

服务对象为 HR 专业人士（HRD、CHRO、HR 经理、模块负责人、HRBP/COE/SSC 从业者）。核心机制：

1. **前沿理论底座**：德勤 2026 全球人力资本趋势（三大拐点、知行落差 66% vs 7%）、Josh Bersin 超级智能体（100+ 用例、L&D 60-70% 可自动化、11 条 CHRO 要务）、Gartner 技能本位晋升、麦肯锡 HR Monitor 2026、HRTechChina 中国十大趋势——所有引用必带出处与年份
2. **五模型融合引擎**：流程性思考（方案形状）→ 系统思维（撬动点与陷阱）→ 刻意练习（能力缺口）→ 福格行为模型（行为怎么真的发生）→ PDCA（方案持续转动）；每个模型配 HR 场景操作手册，含反模型堆砌纪律
3. **八大方法论武器库**：战略人力规划与人效、组织发展（6 大诊断模型）、招聘与人才测评、绩效管理、薪酬与激励、培训与人才发展、员工关系与劳动合规、HR 数据分析与 AI 转型
4. **12 套高频场景剧本**：年终奖调薪、架构调整、空降融入、关键人才离职、校招、绩效改革推不动、人效下滑、老员工躺平、劳动仲裁、并购整合、裁员、HRBP 边缘化——每个含诊断要点、方案骨架、雷区
5. **8 组对话话术库**：绩效面谈（高低绩效）、薪酬沟通、辞退谈话、跨部门协同、向上汇报（BLUF）、候选人沟通、员工投诉疏导——每组含结构与禁语
6. **15 个通用管理工具**：PDCA、5W2H、SMART、5M1E、5Why+鱼骨图、SWOT/TOWS、二八、时间四象限+要事第一、6S、4R、30 秒法则、沟通 7C、RACI、MECE+金字塔、AAR
7. **HR 年度工作日历 + 个人进阶路线图**：月度固定动作与 12 个月节律；胜任力六维模型、职业五级破局点、90 天刻意练习模板
8. **10 份常用文档模板骨架**：JD、绩效制度、薪酬方案、培训计划、人才盘点报告、组织诊断报告、员工手册、面试评估表、PIP、离职面谈记录
9. **合规红线**：不构成法律意见、不设计违规方案、人的终局决策权不让渡 AI、不贩卖焦虑

## 使用示例

- 业务翻倍但人效一直掉，帮我诊断问题出在哪、先做什么
- 帮我设计一套适合快速扩张期公司的绩效体系，要能落地
- 我是HR经理，想往HRD发展，帮我做个能力提升计划

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins\人力资源专家/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
