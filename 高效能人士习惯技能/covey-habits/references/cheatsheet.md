# 决策规则速查 — 柯维核心四部曲：高效能 · 要事第一 · 第八个习惯 · 第3选择

| 能力 | 一句话规则 |
|---|---|
| 影响圈切分与三类问题归因 | 先分 A/B/C 归属，能量只投 A/B；B 类换影响方法，不换人也不硬忍 |
| 范式定位与换镜检查表（地图非疆域） | 凑不出三条反例就不换镜；换镜必须导出一个不同的第一步动作 |
| 心声四要素交汇定位（天赋 × 热情 × 需求 × 良知） | 四维相乘，先补最短板那一维，禁止在长板上继续加码 |
| 移情倾听 / 诊断先于开方 | 先复述到对方认可，再表达自己；只做前半段是退让，只做后半段是自说自话 |
| 第3选择四步协同（不妥协的共同创造） | 对方不答「愿意」就不启动；新方案能在两个原方案的坐标系里被定位就是妥协 |
| 情感账户六种存款（信任存取清单） | 记账权在对方手里；同一句道歉说过两次以上就从存款变成提款 |
| 第二象限周计划四步骤（角色—目标—进度—调整） | 以角色为骨架先放大石头，七天必留白，优先级每周只动一次 |
| P/PC 平衡效能判据（鹅与金蛋的产能核算） | 每笔取舍先问是取蛋还是养鹅；一次性 P 消耗所有备选路径共同 PC 的判为负 |
| 刺激与回应之间的选择回路（四项人类天赋） | 停顿不是忍，是用自觉 / 想象力 / 良知 / 独立意志四路重合成第三个回应 |
| 时钟与罗盘双层对齐决策 | 时钟与罗盘冲突一律取罗盘，并把为此支付的代价当场写成数字 |
| 双赢可行性五支柱审计 + 无交易闸门 | 五根支柱缺一且不可修复，就走「无交易」而不是勉强成交 |
| GET 陷阱三维诊断（协同阻塞定位） | 任一方开始重复第二轮论据即冻结；先定位 G 利益 / E 情绪 / T 地盘哪一层中毒 |
| 全人四维更新平衡审计（含休息真伪判别） | 任一维连续两周 ≤2 分，停用下一周增量任务，只执行该维最小剂量 |
| 自我授权七级阶梯（从「坐等吩咐」到「只管去做」） | 一次只升一级；授权取决于对方的监督成本，不取决于你有多努力 |
| 个人使命宣言 / 两次创造（先有宪法，再有日程） | 假设所有目标都失败，宣言若什么都不剩就是 KPI 清单，重写 |
| 对「好机遇」说不（拒绝程序） | Q2 容量为 0 时再好的邀约也说「不」；拒后 24 小时空白没变成 Q2，这次拒绝不算数 |
