## R — 原文（Reading）

> '以终为始'的原则基础是'所有事物都经过两次创造'。我们通过思考、构思、计划，在头脑中先完成第一次创造，然后付诸实践，完成第二次创造。
> — 《高效能人士的七个习惯》S1.5 习惯二 以终为始 / 两次创造

---

## I — 方法论骨架（Interpretation）

任何一件事都必然经过两次创造：先在头脑里完成一次（想清楚目标、标准、样子），再在物质世界里完成一次（动手做）。跳过第一次创造直接开干，等于把梯子搭在没看过的墙上——爬得越快，错得越远。这套程序就是把"第一次创造"变成一个**可交付的成文文件**。

难点在于，直接问"你想成为什么样的人"绝大多数人答不上来。所以程序不走内省，走**反向叙述**：想象自己的葬礼，写下你希望四类人（亲属 / 朋友 / 同事 / 教友社群）各如何评价你的一生。用别人的嘴描述自己，门槛远低于正面自陈，而且天然引入了多元视角——室友看到的那部分和你未来雇主看到的那部分本来就不一样，四类齐全才算完整。

**为什么程序不走正面内省**：直接问"你想成为什么样的人"，多数人交白卷，或者交出一份愿望清单。反向叙述绕开了这个堵点——你不需要凭空定义自己，只需要想象别人会怎么描述你；而四类人分别对应四种不可互相替代的视角（家人看到的是你如何对待亲近的人，同事/同学看到的是你如何共事，社群看到的是你留下了什么）。四类缺任何一类，演练就不完整，因为你只写了自己最在意的那一面。

接着做**生活中心诊断**：你的安全感究竟建立在什么上面？配偶、家庭、金钱、工作、名利、享乐、朋友、敌人——这八种中心都不稳定，因为它们的支点都在你控制之外，外界一动你就摇摆。换成**以原则为中心**，会同时得到四根支柱：安全感、人生方向、智慧、力量。这一步的意义是把"我为什么总是改主意"从意志力问题重新判定为结构问题：中心错位的人，任何一次他人超车都会引发方向反转。

产出物必须**成文**，不接受"心里大概有数"。它是宪法，不是目标清单——区别在于：目标会达成或失败，宪法在两种情况下都继续有效。因此有一道刚性检验：假设你写下的每一项目标都失败了，这份宣言还剩什么？什么都不剩，它就是 KPI 清单，重写。

最后是一条顺序契约：使命宣言 → 角色 → 目标 → 周计划。每次排周计划前必须先联系自己的使命、角色、目标；跳过这一步的周计划会退化成第三代待办清单。

为什么非得**成文**？因为"心里大概有数"无法被检验。成文之后才能做那道可引用性检验：遇到任一重大取舍时，能否**逐字引用**宣言中的一句直接推出答案。这一条把"我有没有想清楚"从一种心理状态转成了可验收的测试——推不出答案，就是还没想清楚，不管你自我感觉多确定。这同时也是本单元与"空谈人生意义"的分界线：它的产出要能在下一次真实取舍里被当场使用。

## A1 — 书中的应用（Past Application）
### 案例 1: 动物学校寓言（里维斯）
- **问题**: 动物学校要求所有动物统一修跑步、飞行、爬树、游泳，并统一评分。
- **方法论的使用**: 反向检验——如果不先确立每个个体的"终"，而用一把统一的外部尺子衡量所有人，会发生什么。
- **结论**: 教育与自我管理应基于个体的独特天赋与使命，而不是流行的统一标准；把"终"外包给外部标准的人，会在随波逐流中丧失全部独特性。
- **结果**: 每种动物都因为补弱项而削弱了强项，最终得分最高的反而是样样平庸的鳗鱼。学生版对照：看到同学都去卷算法岗，自己也放弃擅长的产品/数据方向去硬补算法，最后两边都不精。

### 案例 2: 弗兰克尔在集中营
- **问题**: 自由、尊严、财产、亲人全被剥夺，外部条件已无任何可改动之处。
- **方法论的使用**: 在无法控制的遭遇中行使唯一剩下的自由——先有"意义之终"，再选择回应的态度。
- **结论**: 伤害我们的不是悲惨遭遇本身，而是我们对遭遇的回应；刺激与回应之间存在一段空间，选择权就在那里。
- **结果**: 他在最恶劣的环境中仍保有内在自由，并由此发展出意义疗法，成为"先立其终、后择其行"的极端佐证。学生版对照：保研名单没有你、实习简历被拒是"遭遇"，把回应从"完了"换成"我能控制的是接下来这三个月做哪三件事"，就是在那段空间里行使选择权。

## A2 — 触发场景（Future Trigger）★
### 用户会在什么情境下需要这个能力？
1. **大一被问"你想成为什么样的人"答不上来**，手上正在纠结的直接问题是"要不要加入学生会""要不要转专业"。
2. **大二下在"冲保研绩点"和"去心仪公司实习攒经历"之间反复摇摆**，每次听说别人做了什么就改主意，一学期换了三次方向——这是生活中心落在"同辈评价"上的典型症状。
3. **写保研个人陈述 / 考研复试自我介绍 / 实习面试被问"你的长期规划是什么"**，只能现编，且自己都不信，被追问两句就露馅。
4. **跨考、转专业、选方向的岔路口**：没有标准答案，家里有期待、同辈有样板，自己的判断始终立不住，需要一根不随结果作废的准绳。
5. **看到同学都在卷某个方向，自己也想跟着换赛道**（动物学校综合症），需要一条先于"别人在做什么"的判据，而不是又一次随大流。
6. **一次明确失败之后**（保研落榜、实习被拒、竞赛未获奖）突然失去全部方向，不知道接下来该干什么——这正是"以成就为中心"的宣言失效的时刻，需要重写一份不会因失败作废的宪法。
7. **连续两年排在绩点中上游却说不出自己擅长什么**：全面发展带来的不是选择权，而是没有一项拿得出手的识别度。

**一次典型调用的样子**：用户说"我在考研和实习之间摇摆"。本单元不做二选一推荐，而是先做葬礼演练逼出四类评价，再做生活中心诊断（大概率命中"同辈评价"），最后落成一句可引用的话——之后那句"要不要去实习"的答案由用户自己从宣言里推出来，而不是由 agent 给出。这是本单元与所有"帮你做选择"类能力的根本区别。

### 与相邻能力的区分（阶段 3 定稿）
- 与 `covey-weekly-first-things` / `covey-clock-compass` 的区别（本卡是两者的上游）: 本卡生产"宪法"本身——跨度是学期级以上，且在目标失败时仍然有效；`covey-weekly-first-things` 是每周的行程表（七天）；`covey-clock-compass` 在宪法尚未成形时现造一个"最小可行罗盘"（只对当前最忙的三件事各写一句"它为谁交付什么"，**只能在周级使用，月末必须升级为本卡的正式罗盘**）。顺序契约是 本卡 → 角色 → 目标 → `covey-weekly-first-things`；**本卡未完成不阻塞后两者**（没有宪法也可以先排周计划，但周计划会退化成高效待办清单）。判据一句话：用户问"我到底要成为什么样的人"→ 本卡；用户问"下周怎么排"→ weekly；用户问"这两件事冲突怎么裁"→ clock-compass。
- 与 `covey-find-your-voice` 的区别（composes-with / 常配合）: find-your-voice 回答"我该往哪投四年"——赛道选择（天赋 × 热情 × 需求 × 良知，含外部验证与保质期检查），产出是一次可更换的赛道判断，并要求写明被放弃的"好"是什么；本卡回答"我在任何结果下按什么原则行事"，产出是不可因成败而作废的宪法。赛道可以换，宪法不换。用户说"我不知道自己适合什么/天赋在哪"→ find-your-voice；用户说"我知道自己想做什么，但总在摇摆、需要一根准绳"→ 本卡。
- 与 `covey-say-no` 的区别（被依赖 / 本卡是其前提）: `covey-say-no` 处理单次邀约的取弃（动机检验 + 24 小时承接测试），它需要一个被保住的"更大的'是'"作为输入——那个"是"正是本卡的产物。用户说"这个比赛要不要接"→ say-no；用户说"我拿不出那句'我为了保住什么而不做'"→ 回到本卡。两者的时间尺度也不同：say-no 的结算周期是 24 小时，本卡的检验周期是一次重大取舍发生时（一学期数次）。

## E — 可执行步骤（Execution）

1. **葬礼演练（反向叙述，四类人缺一不可）**
   - 完成标准: 分别写下你希望**亲属 / 朋友 / 同事 / 教友（社群）**四类人各如何评价你的一生，四类齐全，每类 1–3 句。学生版替换为：父母与家人 / 室友与朋友 / 导师与同学 / 未来的雇主或你所服务的社群。
   - 判停条件: 任一类写不出 → 演练不完整，**不得进入下一步**；"我希望他们说我成功了/过得好"这类评价性套话不算，必须换成可观察的行为描述（"他是一个把复杂问题讲清楚的人"）。

**校园版四类人对照表**（用于把葬礼演练翻译成学生能写的对象）：亲属 → 父母与家人；朋友 → 室友与好朋友；同事 → 导师、同学、项目队友；教友/社群 → 你未来想服务的那群人（某个行业、某个社群、某个公益对象）。四类必须齐全，缺"社群"这一类是最常见的漏项，也是最容易被"我只要自己过得好"这句话掩盖过去的一类。

2. **生活中心诊断（排除法）**
   - 完成标准: 逐一检查你的安全感来源是否落在 配偶/家庭/金钱/工作/名利/享乐/朋友/敌人 中的任一项；命中即判为不稳定中心，改写为"以原则为中心"，并写下换中心后获得的四支柱各自对应什么——安全感（我不再因什么而恐慌）、人生方向（我据此往哪走）、智慧（我看事情的角度）、力量（我能行动的幅度）。校园里最常见的两个变体是**同辈评价**与**绩点排名**（属"名利/工作"的变体）。
   - 判停条件: 若命中不稳定中心却写不出替代的原则 → **停在本步**，本周不写宣言；改为观察一周，记录自己在哪些具体时刻因为别人的进展而改主意（至少 3 条），下周再回到本步。

3. **成文（一页纸宣言）**
   - 完成标准: 产出一页纸的成文宣言，含三要素且每要素至少一句：①我要扮演的**角色**（学生、研究者、子女、朋友、某社群成员）；②我要做的**贡献**（为谁交付什么）；③我依循的**原则**（在任何结果下都不违反的那几条）。必须写下来，不接受"心里大概有数"。
   - 判停条件: 若通篇是"GPA 3.8 / 考研上岸 / 进大厂 / 年薪 XX 万"这类可达成也可失败的目标 → 它是 KPI 清单而非宪法（x36），擦掉重写。

4. **反 KPI 检验**
   - 完成标准: 假设宣言里写下的每一项目标都失败了，宣言仍有剩余内容，且这份剩余能直接指导下一步行动；把检验结果写在宣言末尾一行。
   - 判停条件: 删去目标后什么都不剩 → 回到步骤 1 重做葬礼演练，不要靠加一句口号蒙混过关。

5. **可引用性检验（本单元的完成标准）**
   - 完成标准: 面对一个真实的重大取舍（考研/就业、选课、是否加入社团、是否接实习），能**逐字引用**宣言中的一句，并由该句直接推出答案（推的过程要写得出来，不能只说"感觉应该"）。
   - 判停条件: 推不出 → 宣言**尚未完成**，回到步骤 1；不得为通过检验临时编一句。典型通过形态："我要成为能独立交付完整项目的人" → 暑期实习与绩点冲突时，选能交付完整产出的一段实习，并据此反推本学期只选能承载产出的课。

**顺序契约（不可颠倒）**：使命宣言 → 角色 → 目标 → 周计划（`covey-weekly-first-things`）。每次做周计划前必须先联系自己的使命、角色、目标；本单元未完成**不阻塞**排程（`covey-clock-compass` 可用临时罗盘顶上），但缺了这一步的周计划会退化成一张高效的待办清单。

**维护节奏**：宣言每学期重读一次、每年重写一次；在遭遇重大失败（保研落榜、考研失利）后必须重做步骤 4 的反 KPI 检验——若失败后宣言失效，说明它从头到尾就是 KPI 清单。

**写作时长与节奏的现实约束**：完整跑完五步通常需要 2–3 小时，不要试图在一次对话里逼出一份完美宣言。落地建议是把步骤 1 单独安排在一个不受打扰的时段（周末上午或晚课后 90 分钟），步骤 2–3 放在第二天，步骤 5 的可引用性检验放到**下一次真实取舍发生时**——它本来就无法提前模拟。若用户只有 15 分钟，只做步骤 1 的"四类人各一句"，并明确告知这只是半成品。

## B — 边界（Boundary）★
### 不要在以下情况使用
- **用户只是要排下周的日程**：转 `covey-weekly-first-things`。不要在本单元里排行程表，也不要用"你先写宣言"拖住一个只想要七天表的人。
- **用户问的是四年赛道选择**（我适合什么、天赋在哪、这个方向四年后还在吗）：转 `covey-find-your-voice`，它带外部验证与保质期检查，本卡不评估外部需求。
- **情绪危机当周**（失恋、亲人变故、被处分、确诊）：葬礼演练会放大情绪负荷，此时不做，先处理当下。
- **纯信息查询**（"什么是两次创造""柯维的使命宣言长什么样"）：直接回答，不启动书写程序。
- **用户要的是一份给外人看的文书**（保研个人陈述、简历自我介绍）：可以引用宣言，但那是写作任务不是本单元；本单元的产物是给自己用的判据，不是包装材料。
- **用户正处在被高强度外部驱动的状态**（期末周、考研冲刺最后两周、竞赛交付期）：此时启动书写程序只会增加负担，安排在节点之后。
- **用户要的是一次性的价值判断**（"这个比赛值不值得参加""这门课该不该选"）：转 `covey-say-no` 或 `covey-clock-compass`，本单元不提供单次取舍的答案，只提供取舍时引用的那句话。
- **用户明确拒绝内省式对话**（"别跟我讲这些虚的，给我一个能立刻做的方案"）：尊重这个偏好，转 `covey-weekly-first-things` 或用 `covey-clock-compass` 的临时罗盘顶上，不要强行推进葬礼演练。
- **用户的真实需求是情绪支持**（"我觉得自己很失败"）：先接住，本单元的书写程序会要求他直面失败假设，时机不对会加重负担。

**一个必须回避的输出形态**：不要把本单元跑成"给自己打鸡血"。宣言里出现"我要成为更优秀的人""活出最好的自己"这类无代价的表述，说明步骤 1 和步骤 4 都没真正执行——它们既不能被引用，也不能在失败后继续有效。判据仍然是那一条：假设它全部失败，还剩什么？

### 作者在书中警告的失败模式
- **写成 KPI 清单（x36）**：把"GPA 3.8、考研上岸、进大厂、年薪 XX 万"当使命宣言。后果是可验证的——大三保研失败后整份宣言作废，人彻底失去方向；若当初写的是"我选择成为那种把复杂问题讲清楚的人"，失败后仍可据此决定去工作、去考研、去做内容，都是有效路径。
- **补弱项削平强项（x15 动物学校）**：为了"不拖后腿"把主要精力投在最弱的科目/技能上，同时荒废最强的能力。补弱的边际收益递减且上限低（40→70），强项边际收益递增且形成识别度（80→95）；在保研面试、实习筛选、竞赛组队这类由比较优势决定的场景里，平庸的全面不如锋利的单点。
- **只写不用**：宣言写完就归档，周计划前不联系使命、角色、目标——顺序契约断裂，周计划随即退化为第三代待办清单。判据很简单：上一次做周计划时，你有没有打开过这份宣言？
- **写成价值观口号**：通篇是"正直、勤奋、善良"这类无人会反对的词。检验方法：把每一条拿去问"我愿不愿意为它放弃一个真实的好处"（放弃一次评优、放弃一段轻松），答不出代价的原则条目是装饰，删掉重写。
- **把"终"外包给外部标准**：用同辈进度、热门岗位、父母期待代替自己的"终"，这是动物学校寓言的直接后果。校园里最常见的载体是"综测排名"与"同辈去了哪家公司"。
- **把宣言当成一次性作业**：写完交差、再不重读。宣言的价值只在使用时兑现——它不在书写那一刻生效，而在下一次取舍被引用时生效。

**中国高校的具体张力（作者未处理）**：本单元要求"以原则为中心"，但保研名额、综测加分、家庭经济压力是真实的外部约束，不是可以靠换中心取消的思维定式。落地时的处理办法不是否认这些约束，而是把它们写进宣言的**约束条款**（"在必须维持绩点不低于 X 的前提下，我选择……"），然后仍然要求原则部分独立存在——这样在约束消失或失败时，原则那部分仍然有效。

### 作者的盲点 / 时代局限
- 前数字时代：Q3 侵扰（微信群/打卡/签到/临时通知）密度远超 1989 年，需要长时间安静内省的书写程序在今天更难启动与维持
- 个人主义归因：低估结构性约束（培养方案硬性要求、经济压力、家庭期待），"要事"未必能自主选定——对需要兼职养活自己的学生，"以原则为中心"的可选空间远小于书中假设
- 学生角色的"重要性"常被外部评分体系（绩点/综测）定义，与柯维的"内在罗盘"存在真实张力：综测排名是制度性事实，不是思维定式，不能靠换中心取消
- 证据是轶事性的，因果叙事不可证伪（动物学校是寓言，弗兰克尔是极端个案，均不构成对"写宣言有效"的因果证明）

### 容易混淆的邻近方法论
- **时间管理技巧 / GTD vs 要事第一（必须区分）**：本卡位于四代时间管理的更上游。GTD、待办 App、优先级标签处理的都是"已有的任务集合"，而本卡的作用是**先生成那个集合**——角色与使命决定了哪些事有资格进入清单。跳过本卡直接排优先级，无论工具多精致都仍属第三代（以时钟为中心、把人异化为待办清单）。判据：你的待办是从"我的角色与使命"推导出来的，还是从"别人最近给我派了什么活"汇总出来的？后者即第三代陷阱。
- **效率 vs 效能（必须区分）**：效率是"正确地做事"（爬梯子的速度），效能是"做正确的事"（梯子靠在哪面墙）。本卡属于效能侧，且是效能侧最上游的一环——它定义"墙"在哪里。学生几乎全部的时间优化努力都在效率侧（更快的笔记法、更好的番茄钟），而"我凭什么判断这件事值得做"是效能问题，效率工具无法回答。典型症状：把所有事都做得极高效，四年后回头发现每一件都不是自己选的。
