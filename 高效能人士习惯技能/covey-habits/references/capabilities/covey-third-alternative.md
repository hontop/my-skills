# 第3选择四步协同（不妥协的共同创造）

<!-- capability_id: cap.covey.third-alternative | revision: 1 | 单元: p07 -->

## R — 原文（Reading）

> 提出第3选择的问题："你愿意寻找一种比你我现有方案都更好的解决方案吗？"——对方答"愿意"时冲突张力释放。需澄清："我不是要你妥协。"
> 妥协意味着一加一等于一或更少……而统合综效意味着一加一等于三，甚至更多。
> 四种思维模式：我看見自己 / 我看見你 / 我努力了解你 / 我与你发挥综效。
> —《第3选择》四步协同法（S4.3）· 四种思维模式（S4.2）；《高效能人士的七个习惯》习惯六 统合综效（S1.10）

---

## I — 方法论骨架（Interpretation）

这套方法处理的是"两个方案僵住了，只能二选一或各让一步"的局面。它的主张是：不选你的、也不选我的，按一个固定程序共同造出**一个双方原方案都达不到的更好方案**。

它先要求四种思维模式转换——我看見自己（我是有独立判断的个体，不是来求认可的）、我看見你（对方是人，不是标签/对手/障碍）、我找到你（主动去了解与我冲突的想法，不回避也不捍卫）、我和你发挥综效（目标是找出谁都没想到过的解，不是赢下辩论）。四步是心态地基，不是流程步骤。

真正的流程是四步，每步都有一道**可判定的闸门**：
1. 提出第3选择的问题——"你愿意寻找一种比你我现有方案都更好的解决方案吗？"，并主动澄清"我不是要你妥协"。闸门是对方**答"愿意"**；对方不愿意，整个流程不许启动。
2. 界定成功的标准——从表面冲突下探到深层原因，共同界定"赢"长什么样。闸门是双方各能用一句话说出**对方真正在意的是什么**，且被对方认可。
3. 创造第3选择——让两种对立的声音充分表达、先不评判，大量产生选项。闸门是**至少 3 个双方此前都没想到过的新选项**。
4. 达成协同——闸门是愤怒、戒备、沉默一去不返，且**没有任何一方觉得自己在让步**。

最锋利的一条是**妥协判别**：妥协是 1+1=1 或 1.5，统合综效是 1+1≥3。判别标准是可当庭检验的——新方案在两个原方案的坐标系里**能不能被定位**？能定位（是两者的加权平均）就是妥协；定位不到（引入了新维度）才可能是第 3 选择。宿舍四人间只有 3 个衣柜，"轮流用"在两个原方案坐标系里可定位（只是把"谁用"做了时序重排），所以是妥协；"把走廊公用柜纳入分配"引入了原本不在议题内的资源维度，才是第三选择。

最后一条：**"无交易"也是合法出口**。谈不拢时明确不成交，优于勉强达成一个最终让双方都失望的协议。

## A1 — 书中的应用（Past Application）

### 案例 1: 玩具公司 / 乐高式协同（把入侵者变成共同创造者）
- **问题**: 丹麦一家玩具公司发现顾客偷偷进入公司电脑系统查存货，以便订购零件、创造自己喜爱的模型——表面上是入侵与违规。
- **方法论的使用**: 既不追究也不放任（跳出"惩罚/默许"的二选一），转而开发一套软件让玩具迷尽情打造新模型，把入侵者正式变为共同创造者。
- **结论**: 协同不是妥协；当你把对方当"人"而不是"问题"，冲突可以从对抗转为共创，并可能诞生原先谁都没想到的新商业模式。
- **结果**: 公司赢取众多顾客成为"设计师"，与他们共同创造产品，开启了全新的商业模式。疗效来自**放弃**对势力范围的守卫，而不是更强势的争取。

### 案例 2: 休假分歧（海边还是山里）
- **问题**: 夫妻为休假去海边还是去山里争执不下，双方各自坚持自己的方案。
- **方法论的使用**: 不停留在二选一，而是深入沟通，挖掘各自方案背后真正想要的东西（安静、陪伴、省钱）——即第 2 步"界定成功的标准"。
- **结论**: 表层立场对立之下往往藏着共同的深层诉求；找到它，就能创造出不属于任何一方的第三条路。妥协是 1+1=1.5，统合综效是 1+1≥3。
- **结果**: 夫妇俩共同创造出一个双方都比各自原方案更兴奋的新方案。

### 案例 3: 夫妻为谁洗碗争吵（界定成功的标准）
- **问题**: 夫妻为"谁洗碗"反复争吵，表面是家务分工。
- **方法论的使用**: 按协同四步走——先问"你愿意寻找一种比你我现有方案都更好的解决方案吗？"，再不停留在表面分工，共同界定"赢"到底是什么样的。
- **结论**: 表面冲突之下是更深层的原因（实为家庭分工与家务之外的资源分配）；问题界定错了，就永远找不到第 3 选择。
- **结果**: 讨论从"谁来洗"转向重新界定整体分工与资源分配，争吵的性质被改变，为后续创造第 3 选择腾出空间。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？

1. **小组作业分工与形式争执**：一人坚持做实证、一人坚持做综述；一人要做 PPT、一人要拍视频；选题、署名顺序、谁做汇报僵住。最常见的假解是"折中成一半一半"。
2. **宿舍物理资源稀缺**：四人间只有 3 个衣柜、空调开 26 度还是 18 度、值日表谁倒垃圾、作息冲突（熬夜 vs 早睡）。常规做法猜拳、按资历、轮流共用——全是分配既有资源。
3. **社团/学生组织的方案分歧**：活动办线上还是线下、预算怎么分、招新标准、换届分工。
4. **课题组内部的路线之争**：方法 A 还是方法 B、先跑实验还是先补文献、谁的数据归谁用；以及论文作者排序这类长期悬而未决的议题。
5. **与导师/学院谈一个被驳回的请求**：延长实验室开放时间、改培养方案、申请调换宿舍——直接投诉多半被驳回，需要先共同界定"赢"是什么。
6. **恋爱与朋友关系中的反复争吵**：异地怎么见面、假期去谁家、花钱方式——每次都是同一场架。

### 语言信号（用户话里出现这些就该激活）

- "我们两个方案僵住了 / 谁也说服不了谁"（we're at a deadlock / neither of us will budge）
- "只能二选一吗 / 有没有别的办法"（is there a third way / any other option）
- "要不各让一步 / 折中一下算了"（let's just compromise / meet in the middle / split the difference）
- "我不想妥协，但也不想吵"（I don't want to compromise but I don't want to fight either）
- "四个人的宿舍只有三个柜子 / 资源不够分"（not enough to go around / scarce resource）
- "我们为这个吵了好几次了 / 每次都是同一件事"（we keep arguing about the same thing）
- "他坚持 A，我坚持 B"（he insists on A, I insist on B）
- "怎么才能两全其美 / 兼顾"（how can we have both / win-win solution）
- "谈不拢怎么办 / 是不是只能算了"（what if we can't agree / should we just drop it）
- third alternative / synergy / win-win solution / 1+1=3

### 与相邻能力的区分（阶段 3 定稿）

- 与 `covey-empathic-listening` 的区别（被依赖 / 本卡以其为前提）: p06 只做"复述到对方认可 + 表达自己"，不进入共同创造。分工很硬：**本卡第 1 步若对方答"不愿意"，必须停在原地退回 p06，不得强行开会**。用户说"怎么说服他"→p06；用户说"我们两个方案僵住了，有没有第三条路"→本卡。
- 与 `covey-emotional-bank-account` 的区别（depends-on / 前提）: p05 是长期信任账本的六种存款审计，本卡是单次冲突的创造程序。**账户余额是本卡能否启动的前置条件**——低信任时先回来存款，直接上协同流程必然崩在第 1 步。用户说"他根本不信任我"→先 p05；用户说"我们关系还行，就是这件事谈不拢"→本卡。
- 与 `covey-get-trap` 的区别（composes-with / 常配合）: **它是本卡的前置诊断，不是本卡的替代品**。三条硬分工：①协同尚未启动、对方连"愿意"都不答时 → 转它做三层定位；②本卡卡在某一步（尤其第 1 步答"不愿意"、第 3 步造不出选项）→ 转它；③三层都松了 → **把执行权交回本卡**。本卡内部只保留一句 GET 自测作为提醒，不重复展开三层处理细则。判据：用户还在问"怎么找到更好的方案"→本卡；用户已经在问"为什么就是谈不下来"→它。
- 与 `covey-win-win-audit` 的区别（contrasts-with / 二选一）: 双赢审计是**结构性判断**（五根支柱齐不齐、体系是否支持、该不该成交），产出成交/不成交的结论；本卡是**生成性程序**，产出具体方案。用户问"这事我该不该答应/该不该让步"→双赢审计；用户问"怎么才能让两个人都满意"→本卡。二者共用"无交易"出口，但审计判定它、本卡只是执行它；顺序是先用审计判题型与五支柱，判为可行且可做蛋糕时才交给本卡造方案。
- 与 `covey-find-your-voice` 的区别（contrasts-with / 二选一）: 它解决**一个人内部的方向选择**（对象是"我"），本卡解决**两人及以上意见冲突时的共同创造**（对象是"我们"）。用户说"我不知道该往哪个方向投入"→它；用户说"我和他两个方案僵住了"→本卡。
- 本卡自身的内部边界: **协同 vs 妥协**的自检——任何时候发现新方案能在两个原方案的坐标系里被定位，就说明你已经滑回妥协，必须退回第 3 步继续造选项，不得收工。

## E — 可执行步骤（Execution）

1. **我看見自己：确认自己是有独立判断的参与者**
   - 完成标准: 用一句话写下**我自己真正要的是什么**（需求，不是立场），并写下一句"我不需要靠'我对你错'来保卫自我"。若写不出自己的需求，说明你在等着对方给答案。
   - 判停条件: 若发现自己只能说出"我就是要他别那样"，那是情绪不是需求 → 转到 `covey-get-trap` 做情绪层定位，定位完再回来。

2. **我看見你：把对方从"障碍"重新标记为"人"**
   - 完成标准: 写出对方的一个具体处境（他现在被什么约束着、他在怕什么），而不是一个标签（"他就是懒/轴/自私"）。此步**不要求对方在场**，也不要求你同意他。
   - 判停条件: 若写出的仍然是标签 → 退回 `covey-empathic-listening`，先做一次复述把信息补齐；信息不足时不得进入下一步。

3. **我找到你：提出第 3 选择的问题，取得"愿意"**
   - 完成标准: 原话提问"**你愿意寻找一种比你我现有方案都更好的解决方案吗？**"，并主动澄清"**我不是要你妥协**"。闸门：对方**明确答"愿意"**才进入步骤 4，同时记录下对方答"愿意"的那一刻（张力释放是可观察的）。
   - 判停条件: 对方答"不愿意"，或反过来要求你先让步 → **停在步骤 3，退回 `covey-empathic-listening`，不得强行开会**。这一步的失败不是礼貌问题，而是问题框架没被接受——后面三步必崩。

4. **界定成功的标准：下探到深层原因，共同定义"赢"**
   - 完成标准: 双方**各能用一句话说出对方真正在意的是什么**，且这句话被对方认可（"对，就是这个"）。说不出的，不许进入步骤 5。
   - 判停条件: 若双方仍在争"谁的方案更好"而无法说出对方在意什么 → 说明还在立场层，继续下探（问"你这么坚持是因为怕什么/想要什么"）；连续两轮下探失败 → 转到 `covey-get-trap`。

5. **我和你发挥综效：创造第 3 选择**
   - 完成标准: 让两种对立的声音充分表达、**先不做评判**，产出**至少 3 个双方此前都没想到过的新选项**，并记下每个选项引入了什么新维度。数量闸门不得提前关闭——出现第一个"还行"的方案就停手是本步最常见的失败。
   - 判停条件: 卡住 / 任一方的反应强度明显超出议题本身 → 自检 GET 内核（**G**ain 执着利益 / **E**motion 被情绪或不安全感左右 / **T**erritory 死守势力范围）。任一项存在即"问题本身不难，难的是身份、安全感或势力范围正处于危险境地" → **转到 `covey-get-trap` 做三层定位，本卡不重复展开**。定位完再回来继续造选项。

6. **达成协同，或正式判"无交易"**
   - 完成标准: ①愤怒、戒备、沉默一去不返；②双方都认为新方案**优于各自原方案**；③**没有任何一方觉得自己在让步**。三条全中才算达成。同时做妥协判别：新方案在两个原方案的坐标系里能否被定位？**能定位即判定为妥协**（1+1=1.5），退回步骤 5 继续造。
   - 判停条件: 若三条中任一不满足且已做过一轮 GET 定位仍无进展 → 启用"**无交易**"出口：明确不成交，说清本次不达成的理由，并保持关系。**这优于勉强达成一个最终让双方都失望的协议**。判"无交易"时用 `covey-win-win-audit` 复核五根支柱是否确实不齐，避免把能力问题误判为结构问题。

## B — 边界（Boundary）★

### 不要在以下情况使用

- **对方答"不愿意"你还想继续谈**。第 1 步不通过就停，强行开会只会让对方把"你愿意吗"听成话术。
- **零和场景**：唯一保研名额、唯一 headcount、奖助学金名额、唯一的第一作者位。这类议题资源不可扩充，本卡的"创造新维度"无处可落——正确的动作是把排序规则制度化（由上位规则一次性结算），而不是继续协同。
- **对方正在实施实质伤害或处于明显恶意**（学术剥削、霸凌、欺骗）。协同假设双方都是善意且有独立判断的参与者；对恶意方开放共创只会让你被再次利用。
- **紧急决策**：ddl 前两小时的取舍、突发状况的处置。四步协同需要时间，紧急时先决策，事后复盘再考虑协同。
- **你尚未想清自己的需求**（步骤 1 做不出来）。此时走流程会直接滑向输赢——你会在第 4 步说出对方想听的话。
- **纯技术性分歧**（哪个库更快、哪种统计方法更合适）。这类问题有客观答案，应该查证而非协同。

### 作者在书中警告的失败模式

- **妥协（1+1=1.5）不是协同**: 柯维明确把妥协与统合综效对立。判别标准可当庭检验——新方案在两个原方案的坐标系里能否被定位？能定位（是两者的加权平均）即为妥协；定位不到（引入新维度）才可能是第 3 选择。校园里最常见的假第三选择是"轮流/按时间 share"（轮班值日、单双周轮流），它只是把同一个变量做了时序重排，没有引入新维度。
- **"无交易"也要纳入**: 谈不拢时明确不成交，优于勉强达成最终让双方都失望的协议。"如果你不能达成一个双赢的方案……那么选择'不成交'也是一种双赢。"
- **第 1 步不可跳过**: 先问"你愿意吗"，而不是先谈方案。绝大多数人的做法是"反正都谈了，继续谈"——这正是流程崩塌的起点。
- **第 2 步不许含糊**: "换位思考"不是态度要求而是一个可通过/不通过的闸门——说不出对方真正在意什么，不许往下走。
- **过早收敛**: 出现第一个可接受方案就停手。数量闸门（≥3 个新选项）存在的意义就是稀释这个本能。
- **把对方当"问题"而不是"人"**: 玩具公司案例的反面——一旦把对方标记为违规者/障碍，所有方案都会围绕"如何处置他"展开，第三选择不会出现。
- **负面协同**: 协同不只发生在正面，1+1 也可能远小于 2（吸烟 + 石棉）。不要假定"两个方案合并一定更好"，合并后必须实际检验。

### 作者的盲点 / 时代局限

- **权力不对等场景中"无交易"往往只对强势方开放**: 导师—学生、实习单位—实习生、辅导员—学生之间，弱势方说"不成交"要付真实代价（延毕、失去推荐信、被边缘化），而强势方说"不成交"几乎没有成本。柯维把"无交易"写成中性的、双方对称的退出选项，这在师门与实习场景里不成立。**弱势方使用本卡时，必须先把"我不能承受不成交"这一约束显式写出来**，再决定要不要进入流程；否则流程会在第 1 步被形式化地通过，而实质是你在被迫接受。
- **真正的零和场景里双赢不可得**: 唯一保研名额、唯一 headcount、奖助学金名额。柯维的"富足心态"（世界之大，人人都有足够的立足之地）在名额由制度硬性固定的场景里是错误描述。此时本卡的正确用法是承认零和、把分配规则制度化，而不是假装存在第三选择。
- **集体主义语境下"双赢"话语可能被用来压制合理的利益表达**: "我们要找共赢""你别太计较个人得失"这类话在中国高校语境里常被用作让弱势方让渡利益的话术。使用本卡时必须守住一条——**第 3 步的"愿意"必须是真实自愿的，任何一方都不得被道德压力推着答"愿意"**。
- **证据是轶事性的，因果叙事不可证伪**: 玩具公司、休假分歧、洗碗分工都是成功故事；书中没有"我们认真走了四步但依然失败"的样本。无法据此认定四步与协同结果之间存在稳定因果，第 3 步的"≥3 个新选项"也是经验值而非被验证的阈值。
- **线上文字沟通（微信群聊）适配不足**: 四步协同依赖同步对话与即时张力释放（第 1 步"对方答愿意时冲突张力释放"在文字里几乎不可观察）。群聊场景中"沉默"既可能是同意也可能是冷处理，第 6 步"愤怒、戒备、沉默一去不返"这条完成标准在异步文字里无法判定。需要显式改写为逐条确认（@ 对方并请其明确回"愿意/不愿意"）。

### 容易混淆的邻近方法论

- **妥协 vs 统合综效**: 妥协 1+1=1 或 1.5，是双方都不满意的次优解，且会在下一轮以更大反弹回来；统合综效 1+1≥3。硬性判据：**新方案能否在两个原方案的坐标系里被定位**。能定位 = 妥协，别把它叫综效。
- **讨好 / 输赢 vs 双赢**: 为了"达成共识"全盘接受对方方案是输赢，不是协同。检验：第 6 步"没有任何一方觉得自己在让步"——若有一方觉得让步，就是妥协或讨好。只做"我先理解你"而不表达自己，是退让（x34），不是第 3 选择的地基。
- **协同 vs 折中式的"资源整合"**: 把两个方案各取一半拼起来（"一半实证一半综述"）是妥协；真正的第三选择会引入原方案坐标系里不存在的维度（"短视频嵌入 PPT 作为开场"引入了'注意力机制'这个维度）。
- **统合综效 vs 一致同意**: 柯维原话是"如果两个人的意见相同，其中一人就是多余的"。协同的目标不是消除分歧，而是把差异当原料（"珍视差异——尊重它们，建立在优势之上，并对弱点进行补偿"）。
- **第 3 选择 vs 更聪明的说服**: 本卡的产出是新方案，不是让对方接受你的旧方案的更好话术。若你全程在想"怎么说他才会同意 A"，你没在走本卡。
