# 自我授权七级阶梯（从"坐等吩咐"到"只管去做"）

<!-- capability_id: cap.covey.self-empowerment | revision: 1 | 单元: f10 -->

## R — 原文（Reading）

> 1 坐等吩咐 2 询问 3 提建议 4 "我想做" 5 做后立即汇报 6 做后定期汇报 7 只管去做。
> 受害者就是那些放弃了自己前途的人。
> — 《高效能人士的第八个习惯》S3.5 尾舵精神与自我授权的七个等级

---

## I — 方法论骨架（Interpretation）

这套方法论处理的是"我在一段有上位关系的工作里，到底有多少自主权"。

它的核心主张是：**自主空间不是对方给的，是自己一级一级挣来的**。
柯维把这段距离拆成七级台阶——从"坐等吩咐""每次都问下一步做什么"，
一路到"不需批准即自行执行并担责"。每一级都有可观测的常态动作，
所以"我这个人被动"这种性格叙事，可以被翻译成"我现在稳定在第 2 级"这个技术判断。

三条规则是关键：

**一是"当前级 +1"限速**。禁止越级。在第 1–2 级就提出"我想独立做一个课题"（那是第 7 级的行为），
必然被打回并留下负面印象。最激进的正确策略恰恰是稳步升级。

**二是授权不由你的能力决定，而由对方的监督成本决定**。努力本身不产生授权，
产生授权的是让对方"不用管你也能放心"。因此三种降本手段是具体的：
降低不确定性（定期发四段式短报告）、降低纠错成本（小步交付 + 先写明验收标准）、
降低记忆负担（把五要素压成一句话书面备忘）。

**三是争取升级的最快动作不是多干活，而是先把对方的处境与顾虑复述到比他自己更清楚**——
这是用理解换空间，且可以在同一周内完成，与"用成绩证明自己"的直觉相反。

受害者心态是这套阶梯的反面教材：柯维的判据非常硬——"受害者就是那些放弃了自己前途的人"。
受害者叙事的代价不是情绪，而是**行动权的让渡**：一旦认定责任在外部，自己就没有下一步可执行的动作。

## A1 — 书中的应用（Past Application）

### 案例 1: A 君与暴躁老板（从自保到创造价值）
- **问题**: 一位 HR 经理入职即听闻老板脾气暴躁，又亲眼目睹老板训斥同事，从此谨小慎微，全部精力花在"避免出错"上，对公司毫无实质贡献——典型的最低级（坐等吩咐）+ 受害者姿态。
- **方法论的使用**: 不跳槽、不抱怨（先放弃受害者叙事），把注意力从"老板的问题"转向"我能提供什么价值"，并当面提出第 4 级的话术："我能做什么来帮您一起提高效率？我的任务本来就是为了让您的工作更轻松一点。"——先降低对方的负担，再换取空间。
- **结论**: 影响圈不在对方的性格里，而在自己的价值输出里；主动承担而非防御自保，可以重塑一段看似已经注定的关系。
- **结果**: 几次实际帮助之后，老板与他变成相互信任的上下级。

### 案例 2: 20 人小组游说（先理解决策者，再提方案）
- **问题**: 某保险总代理的 20 人抱怨公司培训无效，认定问题在别人、在高层，游说始终无果——集体性的受害者姿态，责任全部外推。
- **方法论的使用**: 柯维要求他们先**移情地描述决策人的观点与担忧**，且程度要**超过决策者自己对自己的理解**，然后再提方案。这正是本单元"用理解换空间"的核心动作：想被理解，先理解对方；真正的理解不是同意，而是能替对方把他的立场讲得比他自己更清楚。
- **结论**: 这也是从"坐等吩咐"升到自我授权高等级的动作——主动权来自你对上位者处境的掌握程度，而不是来自你的诉求有多合理。
- **结果**: 两名代表照做，公司高层非常满意，接受了他们的全部提议。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？
1. **刚进课题组 / 实验室**：每周被派零碎活（整理论文格式、报销贴票），常态是每周问"老师我这周做点什么"，渐渐不知道什么时候可以提"我想自己做一个小课题"。
2. **毕设 / 大创项目与导师的协作**：想按自己的想法推进，但每一步都要等导师点头，进度全卡在等待上。
3. **实习中的打杂困境**：实习单位给的活与面试时说的不一致（变成贴票、跑腿），想争取实质任务却不知道从哪一步开始。
4. **社团 / 学生会里的执行位**：部长逐条下指令、随时查岗，自己想独立负责一个活动，但提了两次都被驳回。
5. **从等老师布置到主动立项**（自主学习的核心场景）：习惯了"老师布置—我完成"的模式，进入需要自己找题目的阶段（毕设选题、科研立项、自学项目）后完全不知道如何起步。

### 语言信号（用户话里出现这些就该激活）
- "老师不给我派活 / 老师只回我一句'你自己看着办'"
- "老师是不是不重视我 / 我是不是被冷落了"
- "我每周都问老师下一步做什么，他越来越不耐烦"
- "什么时候可以提我想自己做一个课题？"
- "我不敢问 / 怕显得不懂事 / 怕被骂"
- "导师太忙了，我根本约不到他"
- "学校不行 / 导师不放 / 专业没前途 / 家里没资源"（受害者叙事，直接命中最低级）
- "实习就是在打杂，学不到东西"
- "My advisor never responds / I don't know what to do next"
- "How do I ask for more autonomy / take initiative?"

### 与相邻能力的区分（阶段 3 定稿）
- 与 `covey-circle-of-influence` 的区别（depends-on / 前提）: 影响圈解决**归因与边界**（这事归谁负责、能量放哪），本单元解决**升级路径**（我下一步具体做什么动作能拿到更大空间）。两者高度相关但落点不同：影响圈给出"这是我的事"的判断，本单元给出"从 2 级升到 3 级要改哪句话"。**若用户还停在受害者叙事里抱怨，先走影响圈**——不先把责任从外部收回来，就没有爬级的起点。
- 与 `covey-personal-mission` 的区别: 使命宣言产出**宪法**（我是谁、按什么原则行事），本单元产出**在一段具体关系里的行动级位**。前者是方向层，后者是关系层；用户问"我该成为什么样的人"走前者，问"我怎么在这段关系里争取空间"走后者。
- 与 `covey-weekly-first-things` 的区别: 周计划是**个人时间的排程**（我自己怎么安排一周），本单元是**有上位者时的授权争取**（对方的监督成本怎么降）。本单元产出的四段式短报告与验收标准会进到周计划里，但周计划不处理"对方放不放手"。
- 与 `covey-third-alternative` 的区别: 第 3 选择用于**双方意见冲突时创造更好的方案**（对象是方案），本单元用于**等级爬升**（对象是关系里的位次）。你和导师在选题上僵持 → 第 3 选择；你想从"等派活"变成"自己立项" → 本单元。注意顺序：关系尚未建立信任（情感账户为负）时，先按本单元存款升级，再谈协同。

## E — 可执行步骤（Execution）

1. **定位当前级（自检）**：挑一件正在进行的事（毕设、课题组任务、实习任务），按你的**常态动作**（不是最好那一次）判定：
   - **1 级 坐等吩咐**：只等导师 / 上级布置，不布置就不动。
   - **2 级 询问**：每次都问"下一步做什么"。
   - **3 级 提建议**：会给出两个做法并说明倾向，但等对方拍板。
   - **4 级 "我想做"**：会说"我想用两周把 X 做出第一版"，并自带验收标准，对方不回复则按此执行。
   - **5 级 做后立即汇报**：做完立刻主动汇报结果。
   - **6 级 做后定期汇报**：按约定周期（如每两周）主动汇报，不需逐次批准。
   - **7 级 只管去做**：不需批准即自行执行，并对结果负责。
   - 完成标准: 写出一个具体数字（当前在第 N 级），并附一条最近两周的实际行为作证。
   - 判停条件: 若你判定的级别来自"某一次我做过"，降级重判——判据是常态，不是峰值。
2. **设定"当前级 +1"为目标，禁止越级**，并写出该级对应的三个具体动作。
   - 完成标准: 三个动作都是可观测的行为（发一封什么样的邮件、在什么节点交付什么），不是"我要更主动"。
   - 判停条件: 若你想做的动作属于 N+2 级或更高（例如当前 2 级就想"独立立项"），**立即降级到 N+1**——越级索要会被打回并留下负面印象。
3. **话术升级模板**（把抽象态度换成可复制的句子）：
   - **2 → 3**："关于 X，我有两个做法：A 是……B 是……，我倾向 A，理由是……，您看呢？"（带上时间成本与交付物，让对方只需选一个）
   - **3 → 4**："我想用两周把 X 做出第一版，验收标准是……，如果您没回复我就按这个执行。"（自带验收标准 + 默认执行条款）
   - **4 → 5 / 6**：交付后主动发出含 **结果 / 偏差 / 下一步 / 需要的支持** 四段的短报告。
   - 完成标准: 存在至少一份四段式交付短报告（含上述四段，且真的发出去了）。
4. **用理解换空间**：在提出升级诉求前，先把对方的处境与顾虑复述一遍，**程度要超过决策者自己对自己的理解**。
   - 完成标准: 有一份书面记录（哪怕是自己备忘录里的一段），其中列出了对方至少两条具体顾虑（如"担心数据安排被打乱""担心我做不完影响中期"）以及你针对每条的降本方案。
   - 判停条件: 若你写不出对方的具体顾虑，说明信息不足——**先补信息（问、观察、问师兄），不要提交升级请求**。
5. **每接一项委托时维护五要素共识**：预期结果 / 指导方针 / 可用资源 / 责任归属 / 明确后果。把它压成一句话书面备忘发给对方。
   - 完成标准: 每项委托有一条一句话备忘，对方回过"是这个意思"。
   - 判停条件: **五要素模板的完整展开归 `covey-win-win-audit` 的协议支柱所有**——本单元只把它当作"让对方省事的工具"引用；若出现"这笔合作本身值不值得做"的争议（对方收益与你无关、规则不公），转 `covey-win-win-audit`。
6. **升级与降级**：在第 N 级连续三次稳定交付后，书面请求升到 N+1 级。
   - 完成标准: 请求是**书面的**且引用了三次交付记录；被拒时**降级重试而不是争辩**（回到 N 级再稳定交付三次，换个更小的范围重提）。
   - 判停条件: 连续两次被拒且理由模糊 → 停止升级请求，改用第 3 步的四段式报告继续积累信用，三个月内不再提。

## B — 边界（Boundary）★

### 不要在以下情况使用
- **不存在上位关系时**：自学项目、个人读书计划这类没有授权方的场景，七级阶梯没有对象——直接立项即可，不需要"争取授权"。
- **关系尚未建立、情感账户为负时**：先存款（稳定交付、守小承诺），不要提升级。账户透支时的任何诉求都会被听成索取。
- **权力不对等且对方明确不授权时**：导师—学生、雇主—实习生关系里，第 7 级"只管去做"往往在制度上不向你开放。此时上限可能是 4–5 级，硬爬会造成真实代价。
- **对方是控制型人格且无制度约束时**：本框架假定"降低监督成本就能换空间"，但有些上位者的控制需求与监督成本无关。
- **用户只是要情绪支持**（"导师今天又骂我了"）：先回应，不要立即上方法。
- **真正的结构性阻塞**（导师长期失联、实习单位违法用工）：这不是等级问题，是关系是否值得继续的问题——走影响圈切分与双赢审计。

### 作者在书中警告的失败模式
- **受害者心态**：典型表达是"学校不行、导师不放、专业没前途、家里没资源、行情太差"。柯维的判据很硬——"受害者就是那些放弃了自己前途的人"。代价不是情绪，而是**行动权的让渡**：一旦认定责任在外部，自己就没有下一步可执行的动作，于是进入等待—失望—再抱怨的循环。且抱怨具有社交传染性，会把整个宿舍 / 课题组拉进同一个死循环。
- **越级授权（把七级跳成"只管去做"却无能力支撑）**：这是本单元最需要守住的边界。"只管去做"是**结果**，不是起点；它要求你已连续在 6 级稳定交付、且后果由你承担。直接跳到第 7 级而能力 / 信用 / 资源都不支撑，产出的是"你为什么不早说"式的失控，而不是授权。
  - 另一面同样成立：上位者单方面宣布"你自己看着办"却没把五要素讲清，这不是授权，是**放任**（没有共识的信任就是放任）。学生若接下这种"授权"，最后背的是全部责任。
- **指令型授权（把人当物来管控）**：如果你自己是组长 / 部长，用逐条指令、随时查岗、要求抄送进度的方式管队友，就是"对物"的管理方式。对人只能充分授权——盯结果而非手段。
- **把"多干活"当成升级手段**：努力本身不产生授权，产生授权的是让对方"不用管你也能放心"。加班、揽活而不降低对方的监督成本，只会让你稳定停在第 2 级。

### 作者的盲点 / 时代局限
- **"充分授权"的前提是资源与容错空间，学生往往不具备**：第 7 级意味着"后果由你承担"，而学生承担的余地极小——一次失败的独立课题可能直接影响毕业、推荐信与保研。书中案例多来自企业组织（有预算、有岗位、有容错预算），其可迁移性被高估。
- **权力不对等场景中，"无交易 / 拒绝"与"争取授权"都只对强势方开放**：导师—学生、雇主—实习生关系里，你提出"我想按第 6 级执行"若被解读为"不服管"，代价由你单方面承担。书中对此缺乏诚实交代。应先问："如果我提这个，谁承担更大代价？"答案若是自己，就改为**低代价地扩大影响圈**（缩小承诺范围、延后而非正面对抗、寻找缓冲人）。
- **个人主义归因**：低估结构性约束（阶层、家庭经济、地域、培养方案、导师风格）。"自主权是自己挣来的"在导师本身不放权、实验室资源紧张、学院制度僵化的情况下并不成立——有时正确答案确实是换环境。
- **证据是轶事性的，因果叙事不可证伪**：凡争取到空间即归因于"七级阶梯用得好"，凡被拒即归因于"你还不够成熟"。设一个可证伪检验："如果 X 发生（如连续三次稳定交付后仍被拒且无理由），说明这套升级路径在此关系中无效"，X 发生时真的换策略（换导师、换组、换路径）。
- **柯维既布道又经销**：方法论与领导力课程 / 认证 / 咨询产品线存在利益耦合，可产品化的部分（七级模型、五要素模板）被反复强调，不可产品化的部分（权力不对等、退出成本、制度约束）被淡化。

### 容易混淆的邻近方法论
- **主动性 vs 越权**：两者的外在行为可能一模一样（都是"我先做了"），区别在于**是否在第 N+1 级、是否自带验收标准与后果承担**。在自己的职责范围内、按 +1 级推进并主动汇报 = 主动性；超出范围、跳级、不汇报、不承担后果 = 越权。判据：你有没有在事前把"我打算这么做、验收标准是 X、后果我承担"写清楚。
- **责任型授权 vs 指令型授权**：责任型盯结果、就五要素达成共识（人）；指令型盯过程、一步步吩咐（物）。学生组队时最常见的失败是组长用"管理物"的方式管理队友。
- **自我授权 vs 影响圈**：影响圈回答"这事归谁负责"（归因），自我授权回答"我下一步改哪句话"（路径）。受害者心态是两者的共同反面。
- **授权 vs 放任**：授权 = 五要素共识 + 盯结果 + 后果明确；放任 = 什么都不说 + 出事再说。上位者说"你看着办"而不给五要素，是放任不是授权。
