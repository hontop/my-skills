## R — 原文（Reading）

> 如果你不能达成一个双赢的方案……那么选择'不成交'也是一种双赢……这比勉强达成一个最终会让双方都感到失望的协议要好得多。
> 双赢者把生活看作一个合作的舞台，而不是一个角斗场……世界之大，人人都有足够的立足之地，他人之得不必就一定是自己之失。
> — 《高效能人士的七个习惯》S1.8 习惯四 双赢 / 双赢或不成交

---

## I — 方法论骨架（Interpretation）

这套方法论的核心主张很反直觉：**双赢不是意愿问题，而是结构问题。**

大多数人对双赢的理解停在道德姿态——"大家都各让一步""别太计较"。但柯维给出的是一张检查表：
一段合作要能真正互利，需要五根支柱同时撑住——
**品格**（我既有勇气说出自己的诉求，也有能力体谅对方的诉求）、
**关系**（双方情感账户有余额）、
**协议**（把预期结果 / 指导方针 / 可用资源 / 责任归属 / 明确后果五要素写成可验收的约定）、
**体系**（奖励机制真的系于合作成功）、
**过程**（按四步骤推进而非临场发挥）。

只有勇气是赢输，只有体谅是输赢，二者缺一，品格这根柱子就不成立。

关键在于第六格：**"双赢或不成交"**。当五根柱子中有一根撑不住、且无法修复时，
明确而友善地不做这笔交易，被判定为**优于**勉强达成的协议——它保护的是协议质量，不是让你逃避谈判。

结果是：这套工具的最大产出往往不是"谈成了"，而是**提前两周识别出这笔合作根本不成立**，
从而不再往里面投时间。高校里代价最高的几种失误（给导师无偿干活、小组作业被白嫖、社团任务被无限加码），
全部源于缺少这三层检查，而止损窗口通常在两周内关闭。

## A1 — 书中的应用（Past Application）

### 案例 1: 800 人年会上的 770 名失败者
- **问题**: 800 人的年会只有 30 人受奖，其余 770 人在同一个晚上被制度宣布为失败者，激励体系制造的是输赢而非共赢。
- **方法论的使用**: 柯维没有谈意愿，而是直接用**体系支柱**提问——"当初聘用这些人是想让他们成为赢家吗？"得到肯定答复后当面指出"可是今晚这里有 770 名失败者"，把问题定位到总裁的输赢思维方式本身；再给出修复方案：同每个组的每个人达成个人化的双赢薪酬协议，完成预期结果就算赢。
- **结论**: 邪恶在于具体的个人，成功在于整个系统。奖励体系若不支持宣称的价值观，再多的动员都是空转；双赢必须是制度化的，而不只是一种态度。
- **结果**: 总裁被当场点醒，承认"因为你的思维方式就是输赢的思维方式"，转向个人化的双赢绩效协议。

### 案例 2: 休假分歧（海边还是山里）
- **问题**: 夫妻为休假去海边还是山里争执不下，双方各自坚持自己的方案，看起来是典型的二选一死结。
- **方法论的使用**: 不停留在两个既有方案上互相让步（那只是妥协），而是先把**品格支柱**里的"体谅"做到位——深挖各自方案背后真正想要的东西，再据此创造新选项。同时这也演示了五支柱齐全时，"做大蛋糕"是可行的：安静、陪伴、省钱三项诉求可以同时被满足，结果变量是可扩充的。
- **结论**: 表层立场对立之下往往藏着共同的深层诉求；找到它，就能创造出不属于任何一方的第三条路。妥协是 1+1=1.5，统合综效是 1+1≥3。
- **结果**: 夫妇俩共同创造出一个双方都比各自原方案更兴奋的新方案。

## A2 — 触发场景（Future Trigger）★

### 用户会在什么情境下需要这个能力？
1. **进课题组 / 接导师横向项目**：导师口头承诺"表现好可以挂名""以后推荐你"，但不写任何书面约定，你不知道该不该投两个月进去。
2. **小组作业分工失衡**：组内有人长期不出活，你在"自己做完全部"和"撕破脸"之间反复，且截止日期还有两周。
3. **社团 / 学生会任务被无限加码**：部长不断追加临时任务，你不好意思拒绝，已经连续三个周末被占满。
4. **实习中的权责模糊**：实习单位给的活与面试时说的不一致（变成打杂 / 贴票），要不要提、怎么提、提了会不会丢转正机会。
5. **同侪之间的资源竞争**：两个好友竞争同一个唯一名额 / 同一个 headcount / 同一个评优指标，想找"双赢方案"却越谈越僵。
   - 识别要点：只要出现"名额只有一个"，第 1 步即判零和型，直接走无交易闸门，不要陪跑协同流程两周。

### 语言信号（用户话里出现这些就该激活）
- "老师答应给我署名 / 推荐，但没写下来，我要不要相信？"
- "组里有人不出力，我是不是只能自己扛？"
- "这个合作我总觉得哪里不对，但说不上来"
- "我不好意思拒绝 / 我不太会说不"

- "我做了三分之二，署名里没有我 / 功劳被拿走了"
- "名额只有一个 / 只招一个 / 就这一个指标"（零和型信号，立即跳过支柱审计）

- "no deal / 谈不拢 / 撂挑子"

### 与相邻能力的区分（阶段 3 定稿）
- 与 `covey-third-alternative` 的区别（contrasts-with / 二选一）: 第 3 选择是**创造程序**（问→定标准→造选项→达成），用于把蛋糕做大；本单元是**可行性审计 + 出口**。顺序是先用本单元判题型与五支柱，判为可行且可做蛋糕时，才交给第 3 选择去造方案；判为零和或支柱不可修复时，直接走无交易，不进协同流程。用户问"我该不该答应 / 该不该让步"→ 本单元；用户问"怎么才能让两个人都满意"→ 第 3 选择。
- 与 `covey-personal-mission` 的区别: 使命宣言是**宪法**（我在任何结果下按什么原则行事），本单元是**交易条款**（这笔合作值不值得做、条件怎么谈）。用户问"我该不该为了成绩做这件事"走前者，问"这件事的条件该怎么定"走后者。
- 与 `covey-circle-of-influence` 的区别: 影响圈解决"这件事归谁负责、我的能量该放哪"（归因层，五分钟出可行动项）；本单元解决"这个合作结构是否成立"（条款层）。若用户只是抱怨"导师不放人""室友不配合"，先走影响圈，不要直接上五支柱。
- 与 `covey-weekly-first-things` 的区别: 周计划解决"时间怎么排"，本单元解决"该不该把时间给这件事、以什么条件给"。被无限加码的人缺的不是排程技巧，缺的是协议支柱与无交易闸门。
  - 反向误判提示：若用户已经和对方在方案层面僵持（"我们都谈了两周了"），说明审计阶段被跳过了——此时应先回补第 1 步的题型判定，很可能一开始就是零和型，协同流程本就不该启动。
- **调用优先级提示**：本单元针对的是**还没签下的合作**与**正在变味但可止损的合作**；若伤害已经发生且不可撤销（成果已被署名、数据已被拿走），先保全证据与求助渠道，本单元不再是主工具。

## E — 可执行步骤（Execution）

1. **先判断题型（这一步决定后面走不走）**：判定此事是**共做型**（份额可变、蛋糕可做大，如小组作业、社团活动、联合申请）还是**零和型**（结果变量在制度上被固定为 0/1 且不可拆分，如唯一保研名额、唯一 headcount、唯一评优指标）。
   - 完成标准: 题型已明确写下；若为零和型，**直接跳到第 6 步**，不执行第 2–5 步的任何支柱审计。
   - 判停条件: 只要出现"名额 / 名额只有一个 / 只招一个 / 只有一个名额"这类表述，即判零和型，立即停止"我们找个双赢方案"的尝试（那条路会空耗两周且制造虚假期待）。
2. **品格支柱**：自问"我是否既有勇气说出自己的诉求，又有能力体谅对方的诉求"。
   - 完成标准: 勇气与体谅各写一条具体证据（我说出口了什么 / 我能复述对方的什么顾虑）。
   - 判停条件: 只有勇气（我要争到手）→ 判为赢输，先练表达；只有体谅（算了都听你的）→ 判为输赢，先做移情聆听。二者缺一，本支柱不成立，进入第 6 步。
3. **关系支柱**：估算与对方的情感账户余额——过去是否兑现承诺、是否在场外忠诚。
   - 完成标准: 余额给出明确判断（正 / 零 / 负）并附两条事实依据。
   - 判停条件: 余额为负 → **先存款再谈分配**，本轮不谈条件；交换条件在透支账户上永远谈不成。
4. **协议支柱**：把合作写成五要素明确的书面约定——**预期结果**（可验收）/ **指导方针**（边界与红线，不是步骤）/ **可用资源** / **责任归属**（谁被问责、何时汇报）/ **明确后果**（达成怎样、不达成怎样）。
   - 完成标准: 存在一份双方能**复述一致**的五要素书面约定（聊天记录里的一段话也算，但必须双方都回过"是这个意思"）。
   - 判停条件: 对方拒绝任何形式的书面约定 → 本支柱判为不可修复，进入第 6 步。
5. **体系支柱**：检查奖励机制——对方的实际收益是否真的系于合作成功。
   - 完成标准: 明确回答"如果我这件事做成了，对方多得到什么？如果没做成，对方损失什么？"
   - 判停条件: 若对方无论如何都拿固定收益（你的署名与否不影响他的考核、你做多做少不影响他的绩效），双赢在制度上不成立 → 提出修改规则；规则不可改则进入第 6 步。
6. **无交易闸门（启用条件与出口）**：
   - **启用条件**（满足任一即启用）：①第 1 步判为零和型；②第 2–5 步中任一支柱判为不成立且无对应修复动作；③对方拒绝把条件具体化。
   - **启用动作**：明确而友善地声明——"按现在的条件我无法承诺，我们是否可以调整条件，或者这次先不做，我保留下次合作的意愿。
   - **三项必备**：**善意**（不指责、不甩锅）+ **说明理由**（讲清是哪根支柱不成立，而不是"我不想"）+ **保留未来合作**（明示下次还愿意）。**缺一即为赌气退出，不是无交易。**
   - 完成标准: 五支柱逐根标注成立 / 不成立；不成立的那根有对应修复动作，或已按三项必备启动无交易；退出理由留有书面记录。
   - **零和型的专用下水口**（若第 1 步判为零和型）：①把"零和"严格限定在本次赌注上，把不涉及该赌注的部分（共享复习资料、互相模拟面试、互推联系人）留为非零和的长期账本，并**向对方公开说明这个分离**；②名额之外各自准备考研 / 秋招，把单点博弈改成多线并行；③向制度层提问（是否有团队类别、能否联合成果申报），这是零和场景里唯一还剩下的"做大蛋糕"位点，不成立则立即停止。
   - **权力不对等时的改道判停**：若对方是导师 / 实习单位 / 评审（你说"不成交"的代价远大于对方），**不启动正面无交易**，改为"低代价地扩大影响圈"——缩小承诺范围（"本学期先以课程项目合作"）、延后而非正面对抗、寻找缓冲人。
   - 完成标准的最后一条：退出理由必须留有**书面记录**（自己备忘录里的一段也行），因为两周后的争执里，没有记录的一方会被记为"当初说好的"。

## B — 边界（Boundary）★

### 不要在以下情况使用
- **结构性零和场景**：名额、职位、录取唯一且不可拆分时，双赢不可得。第 1 步判定后直接转竞争策略与风险分散（多线并行、梯度择校、备选路径），不要启动协同流程。
- **权力严重不对等且你是弱势方**：导师—学生、雇主—实习生、评审—申请者。"无交易"选项实际上只对强势一方开放；弱势方使用即自伤（延毕、丢实习、失推荐信）。
- **纯信息查询**：用户只是问"小组作业一般怎么分工"，不需要五支柱审计。
- **对方根本没有谈判意愿或谈判资格**时（制度已定、无法改变），审计只会消耗情绪。
- **紧急止损优于审计**的情形：若伤害正在发生且不可逆（署名被抢、成果被侵占），先保全证据，再谈结构。

### 作者在书中警告的失败模式
- **赢输思维**：把互动当角斗场——小组讨论要"赢"、辩论要说服、分工要抢最出彩的部分。赢输是单次博弈的最优解，但你与同学 / 导师 / 同事是重复博弈；每次赢输都在对方账户里提款，赢的次数越多，愿意与你合作的人越少，最终你在需要协作时无人可用。输赢（讨好）只是它的镜像，同样失败。
- **匮乏心态**：认定"他人之得必是自己之失"，于是把可扩充的蛋糕也当成固定份额来争。这是赢输思维的底层范式，光改话术改不掉。
- **"无交易"被误用为"谈不拢就撂挑子"**：留下一句"那我不干了"退出群聊、冷战、甩手走人——这是赌气退出，不是无交易。真正的无交易保留关系、只放弃本次交易；在高频互动的学生环境（同班、同宿舍、同课题组）里，切断关系的成本极高，且会被旁观者记为"不好合作"。判据很简单：善意、说明理由、保留未来合作，三条缺一即为赌气。
- **"好人但拎不清"**：最好说话的人在账面上依然算输赢。只有体谅没有勇气，双赢不成立——你不是人好，你是没把诉求说出口。

### 作者的盲点 / 时代局限
- **真正的零和场景里双赢不可得**：名额 / 岗位 / 录取唯一时，体系给出的只有"无交易"，实操指导薄弱，而这恰好命中大学生最高频的焦虑源（保研名额、评优名额、唯一 headcount）。正确应对是竞争 + 分散，不是协同。
- **权力不对等场景中"无交易"只对强势方开放**：其有效性依赖两个前提——退出成本低、且退出是双向的。在不对等关系中这两个前提都不成立，于是"无交易"从保护性条款变成单方面的威胁工具。书中对此缺乏诚实交代，学生照搬会付出真实的制度性代价。
- **个人主义归因**：低估结构性约束（阶层、家庭经济、地域、培养方案）。在资源约束紧的情形下，"先存款再谈分配""争取修改规则"都需要余裕，而余裕本身分布不均。
- **证据是轶事性的，因果叙事不可证伪**：凡谈成即归因于双赢思维，凡谈崩即归因于对方不够成熟。建议设可证伪检验："如果 X 发生，说明这套审计对我无效"，X 发生时真的换策略。
- **柯维既布道又经销**：方法论与课程 / 认证 / 咨询产品线存在利益耦合，可产品化的部分（五要素模板、双赢话术）被反复强调，不可产品化的部分（结构性约束、退出成本、权力不对等）被淡化。
- **默认长期关系与对等话语权**：双赢与统合综效的论述以此为前提，但高校里大量合作是一次性的、且双方话语权悬殊。

### 容易混淆的邻近方法论
- **双赢 vs 妥协**：妥协是 1+1=1.5，双方都比原方案少拿一点，蛋糕大小不变；双赢要求先把蛋糕做大（共做型）或至少双方都比不合作时更好。判据：协议达成后，有没有任何一方觉得"我其实是被说服的"——有，就是妥协。
- **双赢 vs 讨好（输赢）**：讨好的外在表现是"都听你的"，双赢的外在表现是"我的诉求也说出口了，并且写进了协议"。判据：五要素里有没有你的那一份；没有，就是讨好。
- **无交易 vs 赌气退出**：见上（善意 + 说明理由 + 保留未来合作，三条缺一即为赌气）。
- **双赢 vs 统合综效**：双赢是**分配结构**（这笔交易双方都划算），统合综效是**创造结果**（产出一个谁都没想到的更好方案）。双赢审计判可行之后，才有空间做统合综效。
- **"无交易" vs "拒绝"**：拒绝只说"我不做"，无交易必须同时给出三项——善意、理由、保留未来合作。"不做了"三个字是拒绝，不是无交易。
- **体系支柱 vs 关系支柱**：关系支柱问"我们之间信任够不够"（人际层），体系支柱问"制度让他有没有动机"（结构层）。两者都可能让它不成立，但修复动作完全不同——前者靠存款，后者靠改规则；把体系问题当成关系问题来修（多请吃饭、多表忠心）是校园里最常见的错配。
