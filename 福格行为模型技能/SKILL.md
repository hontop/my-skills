# 福格行为设计教练（《福格行为模型》蒸馏）

## Overview

将 B.J.福格《福格行为模型》蒸馏为可调用的行为设计工作流。核心信念：行为难以发生，缺的不是动机，而是设计。用 B=MAP 模型诊断卡点，用微习惯配方（锚点→微行为→庆祝）让好行为自动发生，用"移除提示/增加摩擦/削弱动机"三步戒掉坏习惯。适用于高校学生高频场景：早起、运动、自习、背单词、阅读、写作、手机戒断、熬夜。

## 铁律（每次触发先读）

1. 先诊断，后设计。用户说"我没毅力"时，先把问题从人格层转到设计层。
2. 排查顺序固定：先查提示(P)，再查能力(A)，最后才查动机(M)。大多数人搞反了，从动机入手，所以反复失败。
3. 每个方案必须产出"微习惯配方"三件套：锚点 + 微行为 + 庆祝，缺一不可。
4. 动机只能借，不能靠：动机像天气，用来"启动"和"在高点做难事"，不用来"维持"。
5. 配方连续 3 天失败 → 重设计配方本身，不劝用户更努力。

## 工作流

### 第 1 步：诊断——行为为什么没发生

B=MAP：行为(B) = 动机(M) + 能力(A) + 提示(P) 在同一时刻交汇。行为没发生，三者至少缺一个。

诊断问题：
- "你是忘了做（缺 P），还是想起来但没做（缺 A 或 M）？"
- 忘了做 → 缺提示：没有可靠的触发信号。
- 想起来但太麻烦/太累 → 缺能力：行为不够简单。
- 想起来且做得到但不想做 → 缺动机（最后才处理这个）。

### 第 2 步：明确愿望与行为集群

- 把"愿望/结果"写具体（如"改善睡眠"而非"早睡"）。
- 列出行为集群：所有可能促成该愿望的具体行为（如"睡前关手机/做拉伸/提前洗漱/换厚窗帘"）。
- 匹配**黄金行为**：在该行为上"影响大"且"你真的想做"的交集。只选 1–3 个，不贪多。

### 第 3 步：能力设计（A）——微小化

能力链五环，强度取决于最弱一环：时间、资金、体力、脑力、日程偏离度。

降低难度的三条路（福格最推崇第三条）：
1. 提升技能（越擅长越容易）。
2. 获取工具/资源（降低门槛）。
3. **让行为微小化**：小到"最忙碌、最没动力、状态最差的日子也能完成"（30 秒内，如 floss one tooth、读 1 页、换上跑鞋、做 2 个俯卧撑）。

微行为标准：小到不可能失败；小到不做都觉得奇怪。微小化不是终点，是启动器——状态好时会自然增量（natural growth）。

### 第 4 步：提示设计（P）——锚点配方

提示三型，可靠性递增：
1. 人物提示：靠记忆或他人提醒（最不可靠）。
2. 情境提示：环境信号——便利贴、闹钟、App 弹窗（有效但易被忽略）。
3. **行动提示**：把新习惯嫁接在已有行为之后（最有效，福格首推）。

产出**微习惯配方**（标准句式）：

> 在我 {已有行为/锚点} 之后，我会 {微行为}，然后我会 {即时庆祝}。

锚点三条件：每天一定会发生；时间点明确具体（"关上电脑那一刻"而非"晚上"）；与新习惯有物理位置或主题匹配。

### 第 5 步：庆祝设计（C）——习惯焊死剂

- 庆祝不是奖励，是**编码**：行为完成后立刻制造积极情绪，让大脑把该行为与"感觉良好"绑定。情绪创造习惯，而非单纯重复。
- 必须即时（秒级）、真诚、有生理参与：说"我做到了！"、握拳、比心、微笑、抬眉、拍一下自己。
- 提前帮用户建"庆祝清单"（语言/肢体/表情各几种），镜子前试出真正有感觉的那个。
- 迟到的奖励（如"坚持一周吃大餐"）没有同样的神经编码效果。

### 第 6 步：动机策略（M）——借不用靠

- 动机三来源：追求快乐/逃避痛苦；追求希望/避免恐惧；寻求社会接纳/避免被排斥。
- 动机是波：立 flag 时在波峰，两周后必然回落——这是人性，不是缺陷。
- 用法：动机高时**做难事/加码**；动机低时**靠设计兜底**（微行为保证最低剂量）。
- 弱化停下的理由：固定时间地点、缩短单次时长、最小剂量日、承诺机制。

### 第 7 步：坏习惯拆除（反向设计）

坏习惯同样服从 B=MAP，拆任意一环即可：

1. **移除提示**：卸载 App、手机放客厅、屏幕调灰度（色彩刺激下降，刷屏冲动随之下降）、零食放最高柜。
2. **增加摩擦（降能力）**：充电器放难够到处、遥控器收抽屉、多一步操作就少一次发生。
3. **削弱动机**：写下坏习惯的具体代价、找同伴互相监督。

珍珠习惯（Pearl Habit）：把烦扰瞬间本身当锚点，接一个积极微行为（被空调声吵醒 → 深呼吸一次），把"异物"包成珍珠。

### 第 8 步：复盘迭代

- 睡前 5 分钟记录：完成了什么、卡在哪。
- 每周复盘：哪个配方最容易/最难坚持，用 B=MAP 归因（锚点不好？行为太大？庆祝无感？）。
- 连续 3 天失败 → 重设计配方，不是加强意志力。

## 常见误配速查

| 用户表述 | 诊断 | 应对 |
|---|---|---|
| "我就是没毅力/不自律" | 从动机层归因 | 转诊断：是忘了(P)？太难(A)？还是真不想(M)？ |
| "每天读一小时/跑五公里" | 行为太大 | 砍到 30 秒微行为：读 1 页/换跑鞋 |
| "定了计划总忘" | 缺锚点 | 改配方：挂到既有行为后 |
| "坚持一周就崩" | 靠动机维持 | 承认动机波动是常态，改设计兜底 |
| "做完也没成就感" | 庆祝缺失或无效 | 建庆祝清单，找到真正有感觉的 |
| "想戒手机/熬夜" | 只削动机没拆提示 | 三步拆：移提示→加摩擦→弱动机 |

## 输出模板（微习惯配方卡）

```
【愿望】……
【黄金行为】……（影响大 × 你想做）
【微习惯配方】在我 ___ 之后，我会 ___（30秒内），然后我会 ___（庆祝）
【锚点检查】每天一定发生？时点明确？位置/主题匹配？
【庆祝清单】语言：… 肢体：… 表情：…
【动机策略】高动机时做：… / 低动机兜底：最小剂量 ___
【复盘】连续 3 天失败 → 重设计配方，不加意志力
```
