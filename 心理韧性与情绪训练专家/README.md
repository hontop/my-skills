# 心理韧性与情绪训练专家（Resilience & Emotion Training Expert）

意识与心理韧性与情绪训练教练，服务高校学生。核心理念「先觉察，后调节」——没有被看见的情绪，只会用更强的方式回来：A 族意识基座练「看见」，B 族情绪工作练「接住」，C 族行动落地练「做到」。蒸馏意识训练（MBSR/元意识/注意网络/心流/神经可塑性）与心理韧性训练（CBT/REBT/ACT/Gross 情绪调节/压力接种/自我效能/成长型思维/斯多葛/创伤后成长/CBT-I/社交暴露/执行意图/深度工作/悲伤双程模型）两大传统为 16 张技能卡，以五框架（流程性思考=元引擎/系统思维/福格/刻意练习/PDCA）为训练内核，七阶段闭环服务，生成 8 周与 21 天双版个人化训练计划，33 个匿名案例场景匹配，台账驱动动态调阶。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **场景识别与基线评估**：提取触发事件/持续时长/身体信号/行为模式/自动化思维五维度，输出场景标签（含睡眠/社交/拖延/丧失/专注专项标签），确认目标变体（急救/缓解/成长/维持）聚焦其一
- **双版训练计划**：8 周系统版（每日 15–25 分钟）+ 21 天轻量版（每日 5–10 分钟），六要素齐全，容量校验（>1.2 强制三选一），按场景挂载专项加成模块，附微习惯配方火种
- **知识蒸馏技能卡**：16 张理论技能卡分三族——A 族意识基座 6 张（呼吸觉察/身体觉察/思维标记与记录/情绪命名/注意训练/心流设计）、B 族情绪工作 7 张（认知重构/接纳去融合/控制二分/情绪调节工具箱/压力接种与预演/意义重写与韧性档案/悲伤陪伴）、C 族行动落地 3 张（执行意图/社交暴露/睡眠重建），每张卡含机制、场景、动作、剂量、进阶、禁忌
- **五框架训练内核**：流程性思考（元引擎，七抓手）/ 系统思维（结构三件套+陷阱六项+杠杆点）/ 福格行为模型（B=MAP+微习惯配方）/ 刻意练习（四要素+3F+心理表征）/ PDCA（四栏复盘，A 栏必须物理变更）
- **案例匹配**：33 个匿名案例库（P01–P19 + A01–A14，12 场景簇），按场景标签检索 3 个相似案例
- **引导训练与动态调阶**：脚本化引导当次训练（四要素），周复盘 PDCA 四栏，升降阶/熔断/低谷日协议/结业判定全闭环，训练台账为唯一状态真源
- **安全边界**：不诊断不治疗；自伤自杀意念或持续功能受损转介；不承诺速成；持续失眠与延长哀伤优先转介专业资源

## 使用示例

- 最近压力很大、总失眠，想做心理韧性训练，从哪开始？
- 总是拖延、注意力集中不了，帮我设计 21 天心理训练计划。
- 社交场合就紧张、总怕别人怎么看自己，有相似案例和训练方法吗？

## 安装

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/psych-coach/
```

```bash
python3 scripts/register_expert.py <expert-dir>
```
