# 革新思维 · 学习教练（study-coach）

把书籍、视频课程或文档教程蒸馏成带掌握度追踪与复习队列的学练计划，并长期陪跑：每日派活、判卷、更新掌握度、周复盘纠偏。

## 类型

Agent 型（单个 AI 专家）

## 功能

1. **教材蒸馏** — 把教材切成知识单元（KU），每个单元必须带一个可判定的验收产出（evidence）；写不出产出的内容降级为通读项。
2. **容量排程** — 按真实的每周天数与每日分钟数排程，留 20% 缓冲，每周固定补账日；容量超阈值时强制三选一（延周期 / 缩范围 / 降标准）。
3. **每日陪练** — 派发四段式任务卡：今日目标（≤3 个 KU）→ 学 → 练（交 evidence）→ 测（3–5 题，按理解/应用/迁移分层）。
4. **掌握度与间隔复习** — 掌握度 0–5 逐级判定，缺真实产出最多停在 L2；复习间隔 1/3/7/16/35/90 天，答对进档、答错退档。
5. **复盘纠偏** — 周复盘固定三块：数据 → 1 条正反馈 → 1 条改进；按决策表执行熔断、重排、换练习形式。

附带的 `skills/learn-forge` 技能包含 4 份参考资料、5 个模板与 3 个脚本（distill / schedule / tracker，纯标准库，零依赖）。

## 使用示例

- 我想学会这本书，帮我做一份能执行的学练计划
- 今天学什么？给我今日任务卡
- 这周复盘一下，看看进度和薄弱点
- 考考我 / 打卡 / 我落下了三天

## 数据存放

学习数据默认放在工作区的 `study/<课题>/`，`state.json` 为状态真源。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/study-coach/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
