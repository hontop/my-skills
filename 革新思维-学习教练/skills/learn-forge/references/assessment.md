# 出题、判卷与掌握度

## 出题层次（按 KU 的 bloom 值）

| bloom | 考什么 | 题型 |
|---|---|---|
| 理解 | 能不能讲出来、辨得出 | 复述要点、辨析对错、给例子判断归属 |
| 应用 | 能不能对着场景做出来 | 场景题、改错题、按条件执行流程 |
| 迁移 | 能不能用到教材之外 | 新情境题、变条件题、"如果这个条件不成立怎么办" |

出题规则：

- 每个 KU 3–5 题，至少 1 题达到该 KU 的 bloom 层次
- 全部题目必须是**用户能当场作答**的形式，不出需要查资料的检索题
- 不出判断题凑数；判断题最多占 1/3
- 每题附评分点，判卷时按点给分，不按印象给分

## 判卷标准

| 结果 | 条件 |
|---|---|
| 通过 | 正确率 ≥80% |
| 模糊 | 60–79% |
| 未通过 | <60% |

判卷必须给出：**错在哪一个知识点**、**正确答案的关键一步**。只报分数等于没判。

## 掌握度 0–5

| 级别 | 名称 | 判定证据 |
|---|---|---|
| 0 | 未接触 | 未排入或已排未学 |
| 1 | 认得 | 能认出术语、说出它大概在讲什么 |
| 2 | 复述 | 闭卷能讲出要点，不看书能列出步骤 |
| 3 | 照做 | 对着真实场景做出来（代码跑通/题目解出/话术说出） |
| 4 | 变通 | 换条件、去掉提示仍做对 |
| 5 | 迁移 | 能教给别人，或用在教材之外的新问题上 |

## 升降级规则

**升级**（逐级，不可跳级）：

```
L1 → L2：闭卷复述通过
L2 → L3：自测 ≥80% 且 交出 1 次真实产出（evidence 落地）
L3 → L4：变条件题做对
L4 → L5：讲给他人听懂，或用在新领域
```

缺真实产出时，自测分再高也停在 L2。这条是硬约束。

**降级**：

- 复习自测 <60% → 降 1 级，`interval_idx` 归零，重走间隔序列
- 降级不算退步记录，算数据修正

## 常见误判与对策

| 现象 | 真实原因 | 对策 |
|---|---|---|
| 自测满分但停在 L2 | 只交了答案，没交产出 | 要 evidence 产物本体 |
| 看懂了讲不出来 | 输入型学习 | 强制闭卷复述，不允许多看一遍代替 |
| 讲得出做不出 | 缺练习环节 | 当次不升级，加一次实操 |
| 做过一次就以为会了 | 缺变式 | 下次复习换条件 |
