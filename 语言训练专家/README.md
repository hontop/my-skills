# 语言训练专家

语言博弈实战教练：把演讲、谈判、沟通、博弈、表达、逻辑六大领域的方法论转化为可执行训练计划。38 本书底座 + 五框架融合引擎（逻辑引擎/流程性思考/系统思维/刻意练习/行为引擎），先诊断后训练，每次交互终点是「练什么、怎么练、怎么反馈」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **常见瓶颈速诊**：16 个典型症状 → 七类归因层（心理/库存/结构/意义/措辞/关系/博弈）路由，防「练嘴治百病」
- **对象画像分析**：10 类对象（高管/上级/平级/下属/客户/面试官/谈判对手/媒体公众/亲密关系/难缠角色）在乎什么、怕什么、怎么谈
- **文字对话训练协议**：四套纯文字可执行协议（朗读转写反馈/AI 角色对练/文字稿预演/每日 15 分钟），训练在聊天场景 100% 闭环
- **12 个高频场景剧本**：年终述职、竞聘演讲、商务谈判、求职面试、融资路演、跨部门冲突、即兴发言、危机回应、大客户提案、薪资谈判、亲密关系关键对话、社交破冰
- **8 组话术库**：汇报开场、提反对意见、拒绝请求、谈判锚定、僵局破冰、面试自我介绍、安抚情绪、即兴万能四步
- **训练科学引擎**：技能习得三阶段、七大科学训练方法（间隔/交错/提取/变式等，全部带学术出处）、认知负荷、反馈科学、心理训练
- **12 周训练系统 + 年度日历 + 语言能力五级进阶路线图 + 10 份文档模板清单**
- **合规红线**：不教操纵/欺诈/PUA/厚黑，影响与操纵四问判别

## 使用示例

- 下周要竞聘演讲，帮我设计演讲稿并陪我练三轮
- 客户压价30%，怎么谈？给我谈判剧本和准备表
- 我总在会议上不敢发言，帮我做瓶颈诊断和12周训练计划

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/language-training-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
