# 提问力 — 跨书对照与术语表

> 本文件由 cangjie-skill 阶段 3（Zettelkasten 链接）产出，供总路由 `questioning-power` 使用。

## 一、三册定位

| 分册 | 核心主张 | 提问的**对象** | 提问的**目的** |
|---|---|---|---|
| 《关键7问》 | 少给建议、多问七个固定问题，把管理者从「替人解决」变成「让人自己长出答案」 | **人**（对话对象，或你自己） | 让对方自己想清楚 |
| 《问题即答案》 | 卡住时缺的不是答案而是问题；用一个 4 分钟「只问不答」的容器把旧问题重构为催化性问题 | **问题本身** | 换一种问法，改变答案的搜索空间 |
| 《学会提问》 | 用一套固定的批判性问题清单，把海绵式思维升级为淘金式思维 | **别人的主张／论证** | 判断它值不值得信 |

## 二、跨书相邻能力对照（防抢调用）

| 关系 | 能力 A | 能力 B | 怎么切分 |
|---|---|---|---|
| **最易混** | 少说多问 / 建议怪兽拦截（关键7问） | 广播 → 接收模式（问题即答案） | **看有没有对话对象**：有 → 关键7问；没有（阅读/独处/查资料）→ 问题即答案 |
| **易混** | AWE 追问（关键7问） | 问题风暴（问题即答案） | **看是逐个还是批量**：对话流里一句一句追问 → AWE；一次性 4 分钟批量产出 → 问题风暴 |
| **易混** | 焦点问题（关键7问） | 问题重构（问题即答案） | **看是收敛还是换框架**：在既有困难里挑出卡点 → 焦点；换一套问题表述 → 重构 |
| **方向相反** | 催化性问题配方（问题即答案） | 十大批判性问题清单（学会提问） | **创造 vs 检验**：构造进攻性问题 → 配方；评估别人的论证 → 清单 |
| 互补 | 战略问题 yes→no（关键7问） | 猴子优先（问题即答案） | 战略问题逼出**放弃什么**；猴子优先指出**先攻哪个** |
| 互补 | 战略问题（关键7问） | 灰度思维（学会提问） | 战略问题做取舍；灰度思维规范**最终结论怎么表述** |
| 相邻 | 让错误可见（问题即答案） | 挖出未说出口的假设（学会提问） | 前者让**自己的错误浮出来**（需他人参与、动态）；后者挖**静态论证的隐含前提**（书面） |
| 相邻 | 新习惯公式（关键7问） | 主动制造不适（问题即答案） | 前者改变**触发—反应回路**；后者改变**输入** |
| 相邻 | 替代原因（学会提问） | 问题重构（问题即答案） | 前者检验**因果方向**；后者改写**问题框架** |
| 同层 | TERA 系数（关键7问） | 提问绿洲（问题即答案） | 都处理安全感；TERA 拆成四个可干预旋钮，绿洲偏组织条件（已被淘汰为独立能力） |

## 三、典型场景的推荐路径

| 场景 | 路径 |
|---|---|
| 带学弟／带新人，对方说不清楚 | 关键7问：开场问题 → AWE 追问 ×3 → 焦点问题 → 懒惰问题 → 学习问题收尾 |
| 自己卡在一个课题上两个月 | 问题即答案：问题重构（换钥匙）→ 若还不够，开一场问题风暴 → 5 层 WHY 定焦 → 承诺推进一条 |
| 看到一条数据惊人的说法 | 学会提问：论证三件套 → 十大清单（重点第 6/7/8/9 项）→ 灰度结论 |
| 和别人争论不下 | 学会提问：挖出未说出口的假设 → 区分价值观/描述性 → 描述性假设做检验 |
| 想改掉「忍不住给建议」 | 关键7问：建议怪兽拦截（写触发清单 + <60 秒拦截句）→ 新习惯公式补挫折预案 |
| 写不出新东西、输入同质 | 问题即答案：舒适度检查 → 制造不适（挑 2 个训练法）→ 广播转接收（被动数据）→ 再开问题风暴 |
| 同时想做很多事、都不舍得放 | 关键7问：战略问题（两张「否」清单）→ 学会提问：灰度思维写条件化结论 |

## 五、三册共同的作者盲点（使用时必须自行补上的一半）

1. **前大模型时代的产物**：三本书（1978 / 2016 / 2018）都写于生成式 AI 普及前。2026 年**答案极度廉价**，
   真正的稀缺已从「产出问题」转移到「判断哪个问题值得追」。三册对「如何筛选／下注」着墨都很轻。
2. **信任能力缺位**：《学会提问》只教质疑，没教「该信谁」；《问题即答案》强调提问，
   没处理「AI 能瞬间生成上百个看似催化性的问题，但它们不知道你的真实约束」。
   判断标准应是：**这个问题有没有让你本人不舒服**——没有，它大概率是模板产物。
3. **低权力距离假设**：三册都默认平等、可自由提问的关系。在师门、强等级组织中，
   直接问「对你而言」「你对什么说了不」可能触发防御，需要改写措辞。
4. **理性主义偏差**：都假设人主要因「没看出逻辑漏洞」而被误导。实际上大量说服发生在
   情绪、身份认同与重复曝光层面——指出逻辑漏洞并不能消除一个好故事的力量。
