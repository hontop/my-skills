# 决策规则速查 — 问题即答案（Questions Are the Answer）

| 能力 | 一句话规则 |
|---|---|
| 问题风暴：4 分钟只问不答 | 2 分钟陈述挑战 → 前后各记情绪温度 → 4 分钟只问问题（不回答、不解释、逐字记）→ 挑 1–3 个 → 连问 5 层 WHY → 承诺推进一条新路径。 |
| 问题重构：换一把钥匙 | 把当前问题写成一句 → 圈出未经检验的限定 → 逐个松绑写出 ≥5 个候选问题 → 用猴子优先挑出该主攻的那个。 |
| 催化性问题配方 | 六种语法把温和问题改写成能溶解假设的问题：反事实／反转／时间位移／极端化／换主体／移除约束， 再做毒性与可答性检查。 |
| 主动制造不适：改变输入而不是更用力地想 | 想不出新问题不是不够聪明而是输入没变：先做舒适度检查，再从七个训练法里挑 2 个本周各做一次并记录。 |
| 广播模式 → 接收模式 | 从输出切到接收：装消音器按住即时判断，主动去「看、聊、试」收集被动数据，每天留出无输入无输出的留白。 |
| 让错误可见 | 把没人说出口的错误写下来 → 找一个框架不同的人不带议程地聊 → 停留一步问「这暴露了我哪个假设」。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
