# 《问题即答案》术语词典

> 术语定义采用**作者本人的用法**，不是字典定义。

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| **催化性问题** Catalytic Question | 通过挑战既有思维打破壁垒、产生新能量、踏上新征程的问题 | 不是「好问题」的同义词；判据是**它是否溶解了一个限制性假设** |
| **问题风暴** Question Burst | 4 分钟计时、只产出问题、禁止回答与解释、逐字记录的小规模重置 | 与「头脑风暴」相反：头脑风暴产出**答案**，问题风暴**禁止**答案与解释 |
| **三条规则** | ①不回答 ②不解释为什么问 ③逐字记录 | 第②条最反直觉——铺垫会被视为「引导别人按你的方式看问题」 |
| **情绪温度** Emotional Temperature | 风暴前后各写几个描述感受的词 | 不是情绪管理技巧，而是**方法生效的度量指标**：没变积极就说明该换人/改天 |
| **被动数据** Passive Data | 主动去「看、聊、试」，收集不经由自己提问而获得的信息 | 常识里数据是「查」来的；作者强调**在场**才能撞见意外 |
| **安全的「不安全空间」** | 安全到足以提问，又不确定到足以产生好奇的环境 | 不是「心理安全」的同义词——它要求**刻意保留不确定性** |
| **提问绿洲** Question Oasis | 在工作与生活中开辟的、允许提问发生的空间与条件 | 不是物理空间，是一组**可被设计的关系与规则条件** |
| **广播模式 → 接收模式** | 从「输出观点」切换到「接收信息」，给自己装消音器 | 与「少说多问」呼应，但扩展到**非对话场景**（阅读、独处、行走） |
| **猴子优先** Monkey-first | 先攻克任务中最难、最卡的部分，而非最容易的部分 | 反「先摘低垂果实」的常识；因为低垂果实摘完了任务仍不成立 |
| **非毒性问题** Non-toxic | simple, tough, but non-toxic（简单、尖锐、但无毒） | 尖锐但不针对人——区分「挑战假设」与「攻击持有者」 |
| **惊奇 / 分心 / 冲突** | 走出舒适区的三种收益 | 不是要做苦行，而是**改变输入**以产生新问题 |
| **安乐椅** | 舒适本身对提问肌肉的静默腐蚀 | 你不会察觉自己在退化，只会觉得「最近没什么好问的」 |
| **5 层 WHY** | 对选出的关键问题连问 5 次「为什么它重要」 | 目的不是找根因，而是**把好奇转化为意志与行动承诺** |
| **权力距离** | 人们对权力不平等状况的接受程度 | 越大越没人提问——作者用它解释组织为什么抑制提问 |
| **让错误可见** | 把「大家心里知道但没人说」变成白纸黑字 | 可视化本身会改变问题——写下来才发现它指向一个没检查过的假设 |

## 与另两本书的术语对照（跨书链接用）

| 本书术语 | 《关键7问》 | 《学会提问》 | 关系 |
|---|---|---|---|
| 广播 → 接收模式 | 少说多问 / 建议怪兽拦截 | — | **相邻但场景不同**：本书作用于无对话对象的接收场景；关键7问作用于对话中 |
| 问题风暴 | AWE 追问 | — | 都「产出更多问题」；风暴是批量一次性，AWE 是对话流内逐个追问 |
| 问题重构（换钥匙） | 焦点问题（对你而言） | — | 重构是**换框架**；焦点是在既有困难里**收敛** |
| 猴子优先 | 战略问题 | — | 猴子优先指出**先攻哪个**；战略问题逼出**放弃什么** |
| 催化性问题配方 | — | 十大批判性问题清单 | **方向相反**：配方**构造进攻性问题**，清单**评估别人的论证** |
| 让错误可见 | — | 挖出未说出口的假设 | 假设卡挖**静态论证的隐含前提**；错误可见是让**自己的错误浮出来**（需他人参与） |
| 主动制造不适 | 新习惯公式 | — | 前者改变**输入**，后者改变**触发—反应回路** |
| 提问绿洲 | TERA 系数 | — | 都处理「安全感」；TERA 拆成四个旋钮，绿洲是一组可设计的条件 |
