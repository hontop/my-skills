## I — 自述

本能力解决一个具体的困境：**你想不出新问题，不是因为你不够聪明，而是因为你的输入没变。**

提问的原料来自你接触到的东西。如果你每天见同样的人、走同样的路、读同样类型的内容、待在同一个圈层，你的问题必然在既有轨道里循环——再怎么努力思考也只是在同一批素材上重排。

作者的解法不是「更努力地想」，而是**改变输入**。他给出三类收益：
- **惊奇（surprise）**：意外事件会打断你的自动化处理，逼你重新提问
- **分心（distraction）**：适度的分心会让大脑建立远距离联想
- **冲突（conflict）**：与你观点相左的人和观点，是最高效的问题发生器

七个具体动作（去远方生活 / 走陌生路线 / 甩掉随从 / 直面批评 / 乘坐经济舱 / 适度 / 检查舒适度）的共同点是：**它们都改变了你的物理或社交处境**，而不是改变你的思考方式。

「可怕的安乐椅」是作者的警告：**舒适本身会腐蚀提问肌肉**，而且过程是静默的——你不会察觉自己在退化，只会觉得「最近没什么好问的」。

## A1 — 书中案例

**网络安全公司的重构（语料 S4，与第4章呼应）**：一家网络安全公司一直被黑客问题困扰，因为攻击方案在不断升级。他们始终在问「怎么造更高的墙」。直到发现一个从没意识到的错误假设——创始人说「**不可能有一堵足够高的墙，能把所有的坏人都挡在外面**」。把问题重构为「**黑客已经攻破墙、进入内部时，如何实时应对威胁**」，最终用机器学习模拟黑客工作习惯做出实时方案，**获软银 1 亿美元投资**。这个突破的前提是他们**愿意停留在一个令人不舒服的错误上**。

**AT&T 的哈利·尼奎斯特（语料 S4）**：公司最有创造力的人，唯一共同点是都和这个思维活跃、特别爱提问的人吃过饭。**冲突与惊奇来自人**——主动接近一个会挑战你的人，比任何训练方法都有效。

## A2 — 触发（未来）

**什么时候用**：
1. 你连续一段时间想不出新问题，感觉思维「钝了」。
2. 你发现自己的信息源高度同质（同一批公众号、同一批人、同一类书）。
3. 你在一个圈层里待太久，所有人看法都差不多。
4. 你想做点创新的东西，但反复产出的都是旧思路的变体。
5. 你意识到自己很久没有被反对过了。

**语言信号**：「最近没什么灵感」「想不出新东西」「感觉在原地打转」「看到的都是一样的内容」「圈子太窄」「没人反对我」「输入不够」。
中英关键词：`舒适区` / `comfort zone` / `自寻不快` / `主动寻求不适` / `惊奇 分心 冲突` / `输入侧` / `信息茧房` / `安乐椅` / `走陌生路线`。

**与相邻能力的区分**：
- vs **问题风暴**：问题风暴改变的是**处理素材的方式**，本能力改变的是**素材本身**。输入没变时，先做本能力再做风暴。
- vs **广播→接收模式**：那个是**接收姿态**（倾听、不输出），本能力是**输入的多样性**。两者互补：接收模式让你接得住，制造不适让你接收到不一样的东西。
- vs **新习惯公式（关键7问）**：那个改变**触发—反应回路**，本能力改变**你遇到什么**。

## E — 执行步骤

1. **先做一次「舒适度检查」**（这是作者给的第七个方法，也是最该先做的）。回答三个问题：
   - 我上周见的人里，有几个是第一次见？
   - 我上周读/看的内容里，有几成是我平时不会碰的？
   - 我上一次被明确反对是什么时候？
   *三个答案都接近 0 → 你已经在安乐椅上。*
2. **从七个方法里挑 2 个，本周各做一次**（不要全挑，挑不动）：
   - **走陌生路线**（成本最低，当天可做）：换一条从没走过的路去常去的地方
   - **甩掉随从**：独自去一个通常需要结伴的地方（独自吃饭、独自看展、独自出差）
   - **去远方生活**（成本最高，假期可做）
   - **直面批评**：主动找一位会反对你的人，请他挑你一个具体想法的毛病
   - **乘坐经济舱**：主动进入你平时不会处的环境
   - **适度**：给自己设一个不适的频率上限，避免变成自我感动
   - **检查舒适度**：即第 1 步，周期性重复
3. **做完立刻记录**：写下「今天遇到的、和我预期不一样的一件事」——**不记录等于没做**，因为不适会被大脑迅速合理化掉。
4. **把记录转成问题**：那件不一样的事，说明了什么？我原来的假设哪里错了？
5. **节奏**：每月至少 1 次中等强度的不适（直面批评 / 独自出行），每周 1 次低成本的（陌生路线）。

**完成标准**：完成舒适度检查 + 本周执行 ≥2 个训练法 + 每条记录转出 ≥1 个问题。

## B — 边界

**不要用的时候**：
- **你正处于高压/危机/情绪低谷**——此时需要稳定而非不适，强行自寻不快会消耗本已稀缺的资源。
- **不适已经过量时**（长期处在不安全环境的人）——本能力默认读者**舒适度过量**；如果你的日常已经充满不确定，要做的恰恰相反（增加稳定）。
- **用不适替代真正的休息**——「一直给自己加压」不是本方法，作者明确列出了「适度」这一条。
- **涉及安全与健康的冒险**——不适指认知与处境，不是物理风险。

**书中警告的失败模式**：
- **自我感动式吃苦**：把「我今天坐了经济舱」当成成就本身，而没有产生任何新问题。判据是：**有没有记录下来、有没有转成问题**，没有就是白做。
- **不适过量**：作者专门列出「适度」一条，警告过度追求不适会耗尽精力，反而降低提问能力。
- **只做不舒服的事，不做不舒服的对话**：七个方法里效果最强的是「直面批评」，但也是最常被跳过的。

**作者盲点（来自阶段 0 批判）**：第5章在中文语料中**仅有目录条目**，七个训练法的展开细节无法核验，本卡的 I 段与 E 段是基于目录 + 已知机制（惊奇/分心/冲突）的合理重建，**不是逐字转述**。此外，作者的受访者多为企业高管与创业者，「去远方生活」「乘坐经济舱」这类方法的成本假设偏高；对学生群体，可替换为低成本版本（换一条通勤路线、去一次完全不相关的讲座、主动请一位不同专业的同学挑刺）。
