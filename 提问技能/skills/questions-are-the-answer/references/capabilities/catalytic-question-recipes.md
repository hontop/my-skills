## R — 原文

> 催化性问题：通过挑战既有思维打破壁垒，从而产生新的能量，踏上新征程的问题。
> —— 《问题即答案》第1章定义（语料 S4 引书中原文）

> Try to ask simple, tough, but non-toxic, questions.
> —— 《Question Burst Toolkit》（语料 S5，作者一手）

催化性问题示例（语料 S7，MIT Sloan）：
> If tomorrow we were legally prohibited from selling our current products to our current customers, how would we make money next year?
> What would happen if we did the opposite of what we're doing right now?
> What if we had not already implemented this process? Would we do it again today?
> What if we shrink our existing product line by 50%? 75%?

## I — 自述

「好问题」不是措辞漂亮的问题，而是**能溶解一个限制性假设**的问题。这就是催化性问题的判据。

它的典型特征：说出口的瞬间，往往**既出人意料又立刻显而易见**——因为它把你一直默认、但从没检查过的东西摆到了台面上。

六种可复用的**配方**（从原书示例与 Toolkit 规则中提炼）：

| 配方 | 语法 | 溶解什么假设 |
|---|---|---|
| **反事实** | 「如果 X 被禁止/不存在，会怎样？」 | 「现状是必然的」 |
| **反转** | 「如果完全反过来做会怎样？」 | 「当前方向是对的」 |
| **时间位移** | 「如果今天才第一次做这件事，还会做吗？」 | 「路径依赖是合理的」 |
| **极端化** | 「如果把它砍掉 50%？75%？」 | 「规模不可压缩」 |
| **换主体** | 「如果是 X（完全不同的人/组织）来做，会怎么做？」 | 「只有我们能做、只能这样做」 |
| **移除约束** | 「如果钱/时间/审批不是问题，会做什么？」 | 「约束是给定的」 |

**"non-toxic" 是硬边界**：问题要针对**假设**，不能针对**持有假设的人**。区分方法——如果这个问题会让某个人当场难堪，它就是毒性的，重写。

## A1 — 书中案例

**Debbie Sterling / GoldieBlox（语料 S9）**：朋友抱怨工程界女性太少，Sterling 问出「**为什么所有了不起的搭建玩具都是给男孩的？**」——换主体 + 反事实，直接溶解了「玩具市场就是这样」的假设，催生了 GoldieBlox。

**Richard Thaler（诺奖得主，语料 S9）**：「**如果我们不再假装人是理性的，经济理论会改变吗？**」——移除一个学科的基础假设，催生了行为经济学。

**Jeff Bezos（语料 S9）**："Getting the right question is key to getting the right answer."——把问题置于答案之前，这是本书全部方法的信念基础。

**AT&T 创造力研究（语料 S4）**：公司调查最有创造力的员工有什么共同点——宗教、教育、肤色、家庭全都找不出共性。**唯一相同的是：他们都和一个叫哈利·尼奎斯特的人吃过饭**——那人思维活跃、特别爱提问，能引发别人发现问题、纠正误区。这说明催化性问题具有**传染性**，靠近一个好提问者比独自苦练更有效。

## A2 — 触发（未来）

**什么时候用**：
1. 你产出了问题，但发现都很温和、都在既有思路里打转。
2. 你需要在讨论里扔出一个能打破僵局的提问。
3. 你想检验某个「大家默认如此」的前提到底成不成立。
4. 你写出了问题但觉得「问了也白问」——通常是问题太安全。
5. 你在准备访谈/调研/开题，需要几个有穿透力的核心问题。

**语言信号**：「我的问题太普通」「问不出有深度的问题」「大家默认就是这样」「从来没想过还能这样」「这个问题问了也白问」「想要一个犀利的问题」。
中英关键词：`催化性问题` / `catalytic question` / `好问题` / `犀利的问题` / `打破假设` / `challenge assumptions` / `what if` / `反事实` / `non-toxic`。

**与相邻能力的区分**：
- vs **问题风暴**：问题风暴是**产出问题的流程**（4 分钟、只问不答），本能力是**写问题时的措辞语法**。两者常连用：风暴负责数量，配方负责质量。
- vs **问题重构（换钥匙）**：重构改写**整个问题的框架**，配方改写**单个问题的措辞**。重构是战略层，配方是战术层。
- vs **十大批判性问题清单（学会提问）**：那个是**评估别人的论证**，本能力是**构造自己的进攻性问题**。方向相反。

## E — 执行步骤

1. **先写出一个安全版本**。把你真正想问的先直白写出来（通常很温和）。
2. **找出它里面隐藏的假设**。问自己：「这句话成立，需要默认什么？」——通常能找出 1–3 个（如「默认是我们在做」「默认是现在这个规模」）。
3. **对每个假设套用配方**，各写出 1 个版本：
   反事实 / 反转 / 时间位移 / 极端化 / 换主体 / 移除约束。
4. **毒性检查**（必做）。逐个问：这个问题会让某个在场的人当场难堪吗？会指向人而不是假设吗？如果是 → 改写为针对**做法或前提**（把「为什么你当初要这么定」改为「这个做法当初是基于什么前提定的」）。
5. **可答性检查**。问：这个问题**有没有可能被回答**？（「人生的意义是什么」不可答，不构成催化性问题）。不可答的要么具体化、要么删掉。
6. **挑 1 个最让你不舒服的**。作者的经验：**让你觉得不同、甚至有点不舒服的问题**才是指向新路径的——太舒服的问题只是复述既有思路。

**完成标准**：产出 ≥4 个经过毒性检查与可答性检查的催化性问题，并明确指出每个问题溶解了哪一个假设。

## B — 边界

**不要用的时候**：
- **关系尚未建立、信任很低时**——催化性问题会被理解为挑衅。先建立安全感。
- **对方是权威且你处于明显弱势**（学生面对答辩委员会）——原配方（「如果反过来做会怎样」）在权力距离大的场合风险高，需软化措辞（「我有个不成熟的设想……」）。
- **需要的是信息不是洞见**（「这个参数是多少」）——别用配方装饰简单问题。
- **已经有明确答案的事实性问题**——不适用。

**书中警告的失败模式**：
- **毒性问题**：把「挑战假设」做成「攻击人」。作者明确要求 non-toxic，这是硬规则不是建议。
- **为了尖锐而尖锐**：一个让人尴尬但溶解不了任何假设的问题，只是噪音。
- **不可答的宏大问题**：作者在第9章讨论「宏大的问题」，但那需要配套的资源与长期投入；在具体问题上使用宏大问法是逃避。

**作者盲点（来自阶段 0 批判）**：书中示例几乎全部来自**企业创新与创业**场景（产品、市场、战略），在**个人学习与研究**场景的迁移未经验证。此外，2026 年大模型能批量生成看似「催化性」的问题，但它们通常**并不溶解你真实的约束**——因为它们不知道你的实际处境。判断标准应当是：**这个问题有没有让你（而不是模型）不舒服**，如果没有，它大概率是模板产物。
