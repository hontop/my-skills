# 关键7问（The Coaching Habit） — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 紧急／危机场景需要直接下指令（有人要出事、系统宕机、deadline 在分钟级）
- 对方缺的是必要知识而不是思考机会（新人第一次做、完全陌生的领域）
- 纯技术故障排查与事实查询（「这个 API 怎么用」「这个参数是多少」）
- 需要检验一个论证／数据／观点是否可信 → 用《学会提问》分册
- 需要为一个卡住的问题批量产出新角度 → 用《问题即答案》分册
- 组织文化建设、团队心理安全感搭建（超出本册的个体可执行范围）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 少说多问：想给建议的冲动（建议怪兽）是本能，必须靠预设的问题拦截，不能靠临场意志力。
2. 第一个答案不是唯一答案：连问三次「还有什么吗」，3–5 个答案才够。
3. 「对你而言」是焦点问题的魔力所在：把抽象难题收拢成这个人当下的卡点，同时能识别「教练幽灵」（谈第三方）。
4. 一个没有「不」的「是」没有形状和边界：战略问题逼出省略的否与委托的否。
5. 看似最软弱的「我可以如何帮助你」是最有力量的授权；真正懒惰的是冲上去替人解决问题的那个人。
6. 知道七个问题毫无价值，除非它变成习惯：新行为必须 <60 秒 + 有可观察触发 + 预设挫折预案。
7. 用「对你而言什么最实用」收尾，借峰终定律把一次对话沉淀成可迁移的能力。

## 边界与判停

- 对方连续两次回答「没了／想不出来」→ 停止追问，改用焦点问题，继续追问会变审讯
- 对方给出的「真正挑战」指向外部不可控因素 → 转入战略问题或《问题即答案》的问题重构
- 本册路由表与 capability-index.md 都无法命中的意图 → 明确告知超出范围，不硬套
