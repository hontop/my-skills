## 1. 结构 (Structural)

### 类型
实操手册型方法论书。结构高度程式化：每章 = 一个问题 ×（机制说明 + 「科学」佐证 + 「艺术」用法 + 「进修课」练习）。

### 一句话主旨
**少给建议、多问七个固定问题，把管理者从「替人解决问题的人」变成「让人自己长出答案的人」。**

### 骨架（主要论点及其关系）

1. **问题是组织的病因**：管理者习惯给答案、习惯救火，下属习惯等指令，形成过度依赖 / 不堪重负 / 迷失意义三个互相强化的恶性循环。
2. **病因是「建议怪兽」**：想跳进去解决问题的冲动是本能，善意却有害——它剥夺对方的思考空间，且你的建议未必对。
3. **解药不是更多理论，而是一个可复制的对话结构**：七个固定问题，覆盖「打开—聚焦—目标—求助—取舍—沉淀」的完整路径。
4. **前四问负责看清**（开场 / 追加 / 焦点 / 基础），后三问负责行动（懒惰 / 战略 / 学习）。
5. **知道不等于做到**：用「新习惯公式」把七个问题焊进肌肉记忆——识别触发、替换旧习惯、定义 <60 秒的新行为、计划挫折。
6. **底层机制是神经科学与行为经济学**：TERA 系数解释为什么提问能提升安全感与投入度；峰终定律解释为什么要用学习问题收尾。

**论点之间的关系**: **递进**——从诊断（1–2）到方案（3–4）到落地机制（5）到科学解释（6）。第 4 条内部是「看清 → 行动」的**对比分区**。

### 作者要解决的核心问题
「如何让一个忙得要死的管理者，**不需要人格改造、不需要学复杂教练理论**，就能在每天 10 分钟的碎片对话里真正带人？」

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 建议怪兽 Advice Monster | 面对他人问题时，大脑本能地想跳出来给答案、证明自己有价值的冲动 | 常识把「乐于助人」当美德；作者把它命名为需要被**关进笼子**的障碍 |
| AWE 问题 And What Else | "还有什么吗？"——反复追问以越过第一个表面答案 | 常识追问是「获取信息」；作者用它**同时**做两件事：给对方挖选项 + 给自己争取忍住不说的时间 |
| 焦点问题 | "对你而言，这里真正的挑战是什么？" | 关键在 **"for you"（对你而言）**——把抽象难题收拢成「这个人当下的卡点」，而非客观问题本身 |
| 懒惰问题 | "我可以如何帮助你？" | 名字反讽：看似示弱/偷懒，实则是**最有力量的一次授权**——把责任交还对方 |
| 战略问题 | "如果你对这件事说了『好』，那你对什么说了『不』？" | 不是问「有什么风险」，而是逼出**取舍结构**：省略的否（被挤掉的选项）与委托的否（必须停掉的事） |
| 新习惯公式 | 「当 X 发生时，不做旧的 Y，改为做新的 Z」，新行为需 <60 秒 | 常识谈习惯靠意志力；作者要求**可观察的触发点 + 微型行为 + 预设挫折应对** |
| 3P 模型 | Projects 项目 / People 人 / Patterns 模式——判断谈话重心落在哪一层 | 不是优先级排序工具，而是**对话开局的定位器** |
| TERA 系数 | Tribe 部落 / Expectation 期望 / Rank 排名 / Autonomy 自主——大脑每秒五次在无意识扫描的四个安全感维度 | 把「心理安全感」拆成四个可干预的旋钮，而非笼统的「氛围好」 |
| 戏剧三角 | 拯救者 / 迫害者 / 受害者三种面具 | 作者特指管理者最常滑入「**拯救者**」——而拯救正是建议怪兽的表演形式 |
| 双回路学习 | 不只解决眼前问题，还在过程中创造一个可迁移的学习时刻 | 区别于「单回路」的任务闭环；由学习问题触发 |

### 核心命题（用自己的话）

1. 大多数管理者的忙碌是自找的：他们替下属解决问题，于是下属越来越依赖，自己越来越忙——这是一个会自我强化的循环。
2. 想给建议的冲动是生理性的、即时的、善意的，必须靠一个**预设的问题**来拦截，而不是靠临场意志力。
3. 第一个被说出来的问题，通常不是真正的挑战。要连问三次「还有什么吗」才能越过表面。
4. 「对你而言」是焦点问题的魔力所在：没有它，谈话会退化成抽象讨论或第三方八卦（教练幽灵）。
5. 人们通常不知道自己想要什么，也说不清、不敢要——所以「你想要什么」会让人像金鱼一样张嘴，这时需要奇迹问题与沉默来接住。
6. 「我可以如何帮助你」把请求的具体化成本推回给对方，同时防止自己在信息不全时过度承诺。
7. 没有「不」的「好」没有形状和边界——战略问题让承诺变成真实的取舍，而不是含糊的善意。
8. 用「对你而言什么最实用」收尾，利用峰终定律把一次对话压缩成一次可迁移的能力沉淀。
9. 知道七个问题毫无价值，除非它变成习惯；习惯的养成依赖触发点 + 微型行为 + 重复 + 预设挫折。
10. 提问提升安全感（TERA）与自主性，这是它在神经科学层面有效的机制，不只是话术。

### 论证链
作者的路径是：**现象（管理者又忙又累，团队又不成长）→ 归因（不是能力问题，是行为模式问题：建议怪兽制造了三个恶性循环）→ 反直觉主张（少说多问，且是七个**固定**问题）→ 逐问拆解（每问配一个心理学/神经科学机制作证据）→ 落地（新习惯公式 + 10 分钟/天）→ 终局（自驱型个人与组织）**。
证据类型：神经科学（TERA、大脑每秒五次的安全扫描）、行为经济学（认知偏差）、作者在世界 500 强的咨询实践、以及刻意设计的重复结构（把七问刻进肌肉记忆）。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 原版写于 2016，是**前大模型时代**的管理语境。当时「信息/答案稀缺，好问题稀缺」；2026 年答案极度廉价（随手可问 AI），**问题的价值不降反升**——这一点反而强化了本书，但书中没有任何关于「和 AI 协作时如何提问」的内容，需要下游补充。
- 全书默认**科层制组织 + 面对面/语音同步对话**的场景。远程异步、文字沟通（群聊/文档评论）下，「深呼吸不说话再等三秒」这类技法直接失效，需转译。
- 「每天 10 分钟」的成本估算建立在管理者对下属有**稳定可支配时间**的假设上。

### 作者的立场盲点
- **教练/咨询从业者视角**：作者靠教「教练式提问」谋生，本书天然会高估「提问」的适用边界、低估「直接给答案」在某些情境下的正确性与效率。
- **英语文化 + 北美企业语境**：TERA 中的 Rank（排名/相对重要性）、Autonomy（自主）带有明显的个人主义假设；在高权力距离文化中，「你想要什么」和「对什么说不」的直接问法可能触发防御而非开放。书中第2章虽提到「提问中的文化差异」（见同系列书《问题即答案》），本**书自身并未处理**这一点。
- **管理者视角，非被管理者视角**：书假设「被问的人是愿意且能够自己想清楚的」。对能力不足、信息不对称、或正处于危机中的下属，反复追问会变成折磨。

### 未被证明的假设
1. 「让对方自己找到答案」总是比「给一个好答案」产出更好的结果——**未证明**。新手在陌生领域缺的不是思考机会，而是必要知识。
2. 七个问题的顺序是普适最优路径——**未证明**。它更像作者的经验性编排，缺少对照证据。
3. 「建议怪兽」需要被驯服的程度是普遍一致的——**未证明**。不同人格（如天然倾向倾听者）可能问题相反：不敢给建议。
4. 10 分钟/天足以形成并维持习惯——**未证明**，且与习惯养成研究的常见结论（差异极大，median 数十天）相比偏乐观。
5. 提问能提升 TERA 从而提升绩效——相关性论述多，因果证据弱。

### 最强反对意见
> **「这是一套被包装成方法论的话术，且其效果是单向归因的。」**
> 反驳要点：(a) 七个问题的效果高度依赖**提问者的真实好奇**——如果内心仍在赶时间、仍在评判，问出来就是审讯，对方感受到的是被套路而非被赋能；(b) 书中缺少失败率的诚实交代与边界条件（什么情况下**不该**用七问）；(c) 把复杂的能力建设问题简化为「问七个问题」，可能让管理者误以为已经完成了培养人的工作，反而**延迟**了真正的投入（给资源、给反馈、给示范、做决策）。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容
- [x] **AWE 追问**（还有什么吗）——最高频、最独立、最易原子化
- [x] **焦点问题 / 「对你而言」**（从一堆抱怨里锁定真正的卡点）
- [x] **战略问题**（用「你说了 yes，那对什么说了 no」逼出取舍）
- [x] **懒惰问题**（把「我帮你」换成「我怎么帮」，防止过度承诺）
- [x] **开场问题 + 3P 定位**（对话开局定位）
- [x] **基础问题 + 奇迹问题 / 沉默三秒**（对方说不清想要什么时）
- [x] **学习问题 / 双回路收尾**（把一次对话沉淀成能力）
- [x] **新习惯公式**（把任何「知道但做不到」转成可执行替换）
- [x] **建议怪兽识别与拦截**（元能力，可独立触发）
- [ ] TERA 系数（偏解释性，更适合作为其他能力的「为什么」注脚）

### 不适合 skill 化的内容
- 附录的书单与视频推荐（纯资源）
- 作者的公司案例与荣誉客户列表（纯宣传）
- 「带人组合拳」「主餐型问题 6 方面」——语料不足，仅见目录，不足以支撑独立能力卡
- 每章的「科学/艺术/进修课」三段式体例本身（结构，非方法）

### 预估 skill 数量
**约 6–8 个能力**（最终由阶段 1.5 三重验证 + 1.6 晋级门决定）

### 优先级排序（按「最能赋能普通人」的角度）
1. **AWE 追问** —— 独立于管理场景，任何对话/自我追问都可用，触发面最广
2. **焦点问题（「对你而言」）** —— 解决「聊了半天没聊到点子上」的高频痛点
3. **战略问题（yes→no 取舍）** —— 决策与承诺场景刚需，可独立验证
4. **建议怪兽拦截 / 新习惯公式** —— 元能力，是前三个能否真正落地的前提
5. 懒惰问题 —— 高价值但与「战略问题」在意图上有部分重叠，需靠 B 段切分
6. 开场问题 + 3P —— 价值中等，偏向「对话开局」的窄场景
7. 学习问题 / 双回路收尾 —— 价值中等，依赖「已有一次对话」的前提
8. 基础问题 + 奇迹问题 —— 语料细节不足（金鱼问题/奇迹问题仅见目录），优先级最低
