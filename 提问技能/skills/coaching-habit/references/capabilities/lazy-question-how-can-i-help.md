> "How can I help?"

> 保持好奇，保持「懒惰」。
> —— 第5章标题后半（语料 S1 目录）

> 戏剧三角：人际关系的 3 种「面具」。／剝掉谈话的一切装饰。／「请容我考虑一下……」

## I — 自述

「我可以如何帮助你？」看起来是最示弱的一句话，实际上是**一次有力的授权**。

它做两件事：
1. **把请求具体化的成本推回给对方**。一个含糊的「你帮我看看呗」如果直接被答应，你会按自己的猜测去做，做完很可能不是他要的。这一问迫使对方把「我要什么」说清楚。
2. **防止自己在信息不全时过度承诺**。你不再需要猜测他想要什么，你只需要听。

名字里的「懒惰」是反讽：表面上的偷懒，实际避免了大量无效劳动。书中反过来指出，**真正懒惰的是那个冲上去替人解决问题的管理者**——他懒得让对方自己想，因为那样更快、更显得自己有用。

配套的自我保护工具：如果对方的要求让你为难，书里给的缓冲句是「**请容我考虑一下……**」——先不答应，给自己留出判断空间。

配套识别器是**戏剧三角**：人在压力对话中会滑入三种面具——拯救者（我来帮你解决）、迫害者（都是你的问题）、受害者（我也没办法）。管理者最常滑入**拯救者**，而拯救正是建议怪兽的表演形式。

## A1 — 书中案例

**「打破工作狂模式的第一步」（第5章）**：作者把懒惰问题定位为打破工作狂模式的第一步——工作狂的本质不是干得多，而是**替别人干得太多**。当你停止自动接活、改为先问「我怎么帮」，你才第一次有机会判断这件事是否真的需要你。

**戏剧三角中的「拯救者」（第5章 + 语料 S5）**：书评中记录的典型链条——对方迷茫时，你选择做「拯救者」，把他暂时当成需要被拯救的对象，开始忙碌地拯救；长此以往，他就真的成了「受害者」。懒惰问题是打断这个链条的开关。

## A2 — 触发（未来）

**什么时候用**：
1. 有人向你提出一个含糊的请求（「这个你帮我看看呗」「有空帮我改一下」）。
2. 你正准备说「我来做吧」，但还没搞清楚对方到底要什么。
3. 你发现自己承接了别人的活，而且越接越多（过度承诺的信号）。
4. 你想帮忙，但不确定该帮到什么程度、帮多久。
5. 对方在诉苦但你听不出他是否真的要你行动。

**语言信号**：「帮我看看呗」「你有空的话……」「这个怎么办啊」（无具体请求）、「你能不能帮我……」（范围不清）、「我来吧」（你自己正要脱口而出）。
中英关键词：`我怎么帮你` / `How can I help` / `懒惰问题` / `lazy question` / `过度承诺` / `戏剧三角` / `拯救者` / `Drama Triangle`。

**与相邻能力的区分**：
- vs **战略问题（yes→no）**：战略问题处理「**这件事值不值得做**」，懒惰问题处理「**我该介入到什么程度、以什么形式帮**」。先用懒惰问题把请求具体化，再用战略问题算代价。
- vs **建议怪兽拦截**：那个是「忍住不给建议」的内向动作，这个是「把请求推回给对方」的外向动作。两者常连用。
- vs **焦点问题（对你而言）**：焦点问题找卡点，懒惰问题定协作方式。

## E — 执行步骤

1. **原样接住**：对方提出请求后，先回一句「我可以如何帮助你？」——不要先说「好的我来做」。
2. **要求具体化**。如果对方的回答仍然是含糊的（「就……帮我弄一下」），继续逼具体：
   - 「你希望我做到什么程度？」
   - 「你希望什么时候拿到？」
   - 「哪部分是你自己会做的、哪部分需要我？」
3. **剥掉装饰**。听到「如果你方便的话」「要是你不太忙」这类包装时，把它当成真实请求处理——直接问「所以你是希望我做 X 吗？」
4. **判断后作答**，有三种合法答案：
   - 答应，但**明确范围**（「我做 A 部分，B 你自己来，周三前给你」）
   - 部分答应（「我可以帮你看一遍提意见，但不会替你重写」）
   - 用缓冲句争取时间（「请容我考虑一下……」）
5. **检查自己是否滑入戏剧三角**。如果你心里出现「算了还是我来吧，跟他解释更麻烦」——那是拯救者面具，停一下，回到第 2 步。

**完成标准**：对方的请求被转写成一句**含交付物、含时间、含边界**的明确请求，且你的答应（或不答应）是针对这句话做出的。

## B — 边界

**不要用的时候**：
- **请求已经足够具体**（「帮我把这份 PDF 转成 Word，明天中午前」）——再问一遍是浪费时间，直接答 yes/no。
- **紧急/危机**——先行动。
- **明显该由你负责的事**（你的本职、你承诺过的）——问「我怎么帮」是把自己的责任外包给别人，会引起反感。
- **对方处于明显弱势、求助已经很艰难时**（如下属鼓起勇气求助）——这一问会让他更难开口。此时应直接接住，再逐步澄清。

**书中警告的失败模式**：
- **把「我怎么帮」问成拒人千里**：如果语气是「你想让我怎么帮你啊（我可没说我会帮）」，它就变成了冷漠的挡箭牌，而不是授权。
- **滑入拯救者**：问完「我怎么帮」，对方还没说完你就全接了——这一问白问了。
- **滑入受害者**：「我能怎么办啊，我也没办法」——戏剧三角的另一角，同样无效。

**作者盲点（来自阶段 0 批判）**：本能力假设双方是**平等的成人对成人关系**。在强等级关系（学生面对导师、新人面对上司）中，「我可以如何帮助你」可能被理解为推诿或不够积极，需要根据关系调整措辞（如改为「您希望我从哪部分入手？」）。此外，作者默认「把请求具体化的成本推回对方」总是好的——但当对方因能力所限**确实说不清楚**时，反复追问会变成折磨，此时应先给一个选项让他挑选（「你是需要我 A 还是 B？」）。
