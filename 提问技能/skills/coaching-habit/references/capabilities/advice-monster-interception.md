## I — 自述

「建议怪兽」是作者给一种本能起的绰号：当你听到别人遇到问题时，大脑会立刻跳出来给方案、证明自己有用。这个冲动是**生理性的、即时的、出自善意的**——但它的代价是：剥夺了对方的思考空间，让对方越来越依赖你，而你自己越来越忙（这正是书中「过度依赖 / 不堪重负」两个恶性循环的发动机）。

关键洞察是：**你不能靠意志力关住建议怪兽**。作者在世界 500 强的培训中反复观察到，管理者学完教练技巧后，一回到压力场景就自动退回指挥控制模式。真正有效的做法是**用预设的问题去拦截本能**——不是「我下次要克制一点」，而是「当 X 出现时，我会说固定那一句」。

所以建议怪兽拦截是一个**元能力**：它本身不解决问题，它是让 AWE 追问、焦点问题、懒惰问题这些工具**真的能被用出来**的前提。

## A1 — 书中案例

**Box of Crayons 的培训失效观察（语料 S3 + 作者介绍）**：作者为联合利华、葛兰素史克、花旗等公司做教练培训，发现这些培训普遍过于理论化、脱离现实，管理者在压力下很容易退回原本的指挥控制模式。这个反复出现的失效，正是他后来设计「新习惯公式」和「固定七个问题」的直接原因——**把方法压缩成一句话的长度，才能在压力下达得到**。

**Facebook 的开场惯例（语料 S5）**：管理者常问「你最近遇到什么问题吗」，给下属思考空间，让他侃侃而谈——一个可复用的固定问句，比「记得要多提问」这样的原则有用得多。

## A2 — 触发（未来）

**什么时候用**：
1. 对方刚说完困难，你发现自己已经在心里组织方案了。
2. 你回想某次对话，发现全程是你在说、对方在点头。
3. 你被反复咨询同类问题，开始感到「怎么什么事都要我来」。
4. 有人明确说「你直接告诉我怎么做吧」，但你判断他其实需要自己想清楚。
5. 你想改掉一个「知道不对但总改不掉」的沟通习惯。

**语言信号**：「我一听就想给建议」「我忍不住直接上手做了」「他一问我我就开始讲」「每次都是我替他想的」「说了多少次还是改不掉」。
中英关键词：`建议怪兽` / `Advice Monster` / `忍不住给建议` / `总是我来解决` / `少说多问` / `say less ask more` / `改不掉的习惯`。

**与相邻能力的区分**：
- vs **AWE 追问**：建议怪兽拦截是**识别与拦截机制**（元层），AWE 是被拦截后具体用的那句话（执行层）。本能力告诉你「什么时候该刹车」，AWE 告诉你「刹车时说什么」。
- vs **新习惯公式**：新习惯公式是**通用的行为替换程序**（可以换任何习惯），建议怪兽是它最典型的一个应用对象。想换掉的是「给建议」这个特定冲动时，用本卡；想换掉别的习惯时，用新习惯公式。
- vs **广播→接收模式（问题即答案）**：那个处理的是**非对话场景**（阅读、独处、行走时的信息输入），本卡处理**对话中的输出冲动**。

## E — 执行步骤

1. **识别触发点**（这是最关键的一步）。写下你的建议怪兽什么时候会出现：通常是「对方眼神迷茫」「对话出现沉默超过 2 秒」「对方说了『我不知道』」「我自己感到焦虑」。至少写 3 个具体触发场景。
2. **预设拦截句**。为每个触发点配一句固定的话，越短越好：`「还有什么吗？」`（最通用）、`「你先说说你怎么看的」`、`「给我 10 秒，我想想」`。
3. **把新行为压到 60 秒以内**。拦截动作必须短——「忍住不说并问一个问题」≤60 秒；如果是「我要做 20 分钟教练」，一定做不到。
4. **预设挫折**。写下你会失败的场景（比如赶时间、对方很焦虑），以及失败后怎么回到轨道（「下一次对话重新开始，不追溯」）。
5. **每次对话后自检一句话**：「这场对话里，是我说的多还是他说的多？」——这是唯一的度量。

**完成标准**：有书面的触发清单（≥3 条）+ 对应的拦截句 + 挫折预案；并且在接下来的一次真实对话里成功拦住了一次。

## B — 边界

**不要用的时候**：
- **对方要的是知识不是思考**（「这个 API 怎么用」「这个公式是什么意思」）——该给答案就给，憋着是另一种自我感动。
- **紧急/安全相关**（有人要受伤、系统要挂）——直接下指令。
- **对方能力明显不足且时间紧**（新人第一次做、明天就要交）——这时教练是奢侈的。
- **你自己是唯一知道答案的人**（有信息不对称）——把信息给出去比提问更有价值。

**书中警告的失败模式**：
- **伪问题**：「你不觉得应该先做 X 吗？」——这是伪装成提问的建议，比直接给建议更糟，因为它还剥夺了对方反驳的空间。
- **用提问逃避责任**：当决策本该由你做、后果本该由你担时，把问题抛回去是不负责任的。
- **过度教练**：把所有对话都变成教练，会让对方感到「你从来不肯直接帮我」。

**作者盲点（来自阶段 0 批判）**：作者是职业教练，靠教「少说多问」谋生，天然会**高估提问的适用边界、低估直接给答案的价值**。此外，把「乐于助人」命名为需要关进笼子的怪兽，容易走向另一个极端——让人在该出手时也不敢出手。判断标准应该是**对方此刻缺的是思考机会还是必要信息**，而不是一律少说。
