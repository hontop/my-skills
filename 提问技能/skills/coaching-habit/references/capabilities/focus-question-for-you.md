## I — 自述

焦点问题用来做一件事：**从一堆散落的抱怨里，收拢出那个真正的卡点**。

它的全部威力在 **"for you"（对你而言）** 这三个字上。去掉它，问题变成「这里的真正挑战是什么」——一个客观问题，对方会开始做分析、推责任、谈环境；加上它，问题变成「**这个人当下过不去的那个点**是什么」，对方不得不回到自己身上。

它同时是三种常见失效模式的解药：
- **挑战增多**（一次抛太多问题）→ 焦点问题强制只留一个
- **教练幽灵**（讨论第三方，「他们应该……」）→ "for you" 把主语拉回对方
- **抽象概括**（停在高层模糊讨论）→ "real challenge" 要求具体化

配套心法：以「是什么」开头，而不是「为什么」（「为什么」容易诱导辩护而非探索）。

## A1 — 书中案例

**「培养消防员」而非「灭火」（第3章）**：作者指出，管理者在带人时最常见的状态是「灭火」——下属抛出一个问题，管理者立刻扑上去解决。焦点问题把重心从「扑灭这一件事」转移到「让这个人以后能自己扑」。判断你是否在用焦点问题的标准是：谈话结束后，是事情被你解决了，还是这个人更清楚自己的卡点了。

**「对你而言」的魔力（第3章科学段，语料 S2）**：焦点问题帮助双方识别手头的核心问题——通常，首先被提出的那个问题并不是需要解决的真正挑战。

## A2 — 触发（未来）

**什么时候用**：
1. 对方（或你自己）已经说了一长串困难，但还停在「一堆问题」的状态，没收敛。
2. 讨论开始绕圈：换了好几个角度，每次都浅尝辄止，谁也说不清到底卡在哪。
3. 对方一直在谈「他们／环境／别人」怎么不好（教练幽灵的信号）。
4. 你自己有一堆待办/困扰，说不清楚哪件最要紧。

**语言信号**：「问题太多了不知道从哪下手」「反正就是很烦」「主要是他们那边……」「我也不知道为什么就是推进不下去」「一团乱」。
中英关键词：`真正的挑战` / `real challenge` / `对你而言` / `focus question` / `卡点` / `症结` / `核心问题` / `教练幽灵`。

**与相邻能力的区分**：
- vs **AWE 追问**：AWE 是「再多挖几个」，焦点问题是「从里面挑一个」。**必须先 AWE 后焦点**——还没挖够就问「真正的挑战」，对方只能把第一个答案重复一遍。
- vs **问题重构（问题即答案）**：问题重构是换一整套框架（「这个问题问错了」），焦点问题是在**现有这堆问题里做收敛**，不改变框架。
- vs **挖出未说出口的假设（学会提问）**：后者挖的是**论证的隐含前提**，焦点问题找的是**当事人主观的过不去的点**。

## E — 执行步骤

1. **先确认素材够不够**。如果对方只给出了 1 个答案，先用 AWE 追问到 3 个以上，再进这一步。
2. **原样提问**：「对你而言，这里真正的挑战是什么？」——**"for you" 不能省**，且用「是什么」而非「为什么」开头。
3. **识别并处理三种失效**：
   - 对方又列了一串 → 打断并收束：「这里面，哪一个是你最过不去的？」
   - 对方谈第三方 → 拉回来：「他们那部分我们先放一放，对你而言呢？」
   - 对方很抽象 → 要求具体：「能举个例子吗？最近一次是什么时候？」
4. **让他自己命名**。不要用你的话替他总结；如果一定要复述，用问句收尾：「我听到的是 X——是这个吗？」
5. **判停点**：如果对方给出的「真正挑战」仍然指向一个外部不可控因素（「就是领导不批」），说明焦点问题不够用，转入战略问题（「如果你对它说了好，你对什么说了不」）或问题重构。

**完成标准**：得到了一句**具体的、主语是对方本人的、只包含一个卡点**的陈述，且对方点头认可。

## B — 边界

**不要用的时候**：
- **问题本身还没定义清楚时**（连「到底发生了什么」都没搞清）——这时焦点问题会逼对方在错误信息上做收敛。先用 AWE 或论证三件套把事实摸清。
- **纯技术性故障排查**——「服务器为什么挂了」不适用 "for you"，它就是一个客观问题。
- **对方正处于情绪爆发期**——先接住情绪，收敛卡点是下一步的事。

**书中警告的失败模式**：
- **教练幽灵**：谈话变成讨论不在场的第三方，所有人都在分析别人，没有人在解决自己的问题。
- **挑战增多**：一次抛出一串问题，对方挑最简单的那个回答。
- **抽象概括**：停在「沟通不畅」「效率不高」这种层级就以为找到了答案。

**作者盲点（来自阶段 0 批判）**：焦点问题假设对方**有能力识别自己的卡点**。对自我觉察弱、或缺乏领域知识的人（如大一新生面对陌生学科），问「对你而言真正的挑战」可能只会得到沉默——这时应先给必要的知识框架，再谈卡点。另外，在高权力距离的关系里（学生面对导师），直接问「对你而言」可能触发防御，需要更迂回的措辞。
