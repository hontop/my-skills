## I — 自述

「还有什么吗？」是一个只有三个字的追问工具，它同时做两件不同的事。

**对外的那一半**：人给出的第一个答案，通常不是唯一的、也不是最重要的那个——它只是最先浮上来的那个。连问三次，能越过表层、把藏着的选项和真实的顾虑捞出来。经验值是追问到 3–5 个答案就够，再多会变成审讯。

**对内的那一半**（这是本书最反直觉的地方）：追问的主要作用不是从对方那里获取信息，而是**给自己争取缓冲时间**。当你想给建议的冲动（作者称之「建议怪兽」）升起来时，一句「还有什么吗」能让你把嘴闭上几秒，把思考的责任留在对方那里。所以 AWE 问题既是提问工具，也是自我管理工具。

判断你有没有用对：如果你问完立刻接上自己的看法，你就只是在走流程。

## A1 — 书中案例

**作者本人的「建议怪兽」（第2章）**：作者为联合利华、葛兰素史克、花旗等公司做教练培训时发现，管理者学完教练技巧后，一回到真实压力场景就会退回到指挥控制模式——直接给答案。他自己的解法不是「更有意识地克制」，而是准备一句固定追问（AWE），用预设的问题去拦截本能的冲动，而不是靠临场意志力。

**Facebook 的开场惯例（语料 S5）**：Facebook 的管理者常问「你最近遇到什么问题吗」，给下属一个很大的思考空间，让他抛开顾虑谈下去——追问之所以有效，前提是开局这个问题足够开放。

## A2 — 触发（未来）

**什么时候用**：
1. 对方只说了第一个理由就停下来，而你强烈怀疑那不是真正的理由（「我最近状态不太好」「这个项目我没什么想法」）。
2. 你自己正要脱口而出一个建议/方案/结论，想先缓 5 秒。
3. 讨论里出现「差不多就这样了吧」「主要是这个原因」这类收束信号，但事情显然还没谈透。
4. 你要在一对一、复盘、辅导、采访里，把对话的主导权交给对方。

**语言信号**：「我大概就是这样想的」「我想到的就这些」「主要是……」「怎么办啊」（带求助语气）、「你觉得我应该怎么做？」
反方向信号（用户自己想被追问）：「我都说完了但他还没明白」「聊不下去了」。
中英关键词：`还有什么吗` / `And what else` / `AWE` / `追问` / `第一个答案` / `建议怪兽` / `Advice Monster`。

**与相邻能力的区分**：
- vs **焦点问题（对你而言）**：AWE 负责「再多挖几个」，焦点问题负责「从一堆里挑出真卡点」。先 AWE 后焦点，顺序不能反。
- vs **问题风暴（问题即答案）**：问题风暴是**一次性批量产出**十几个问题（且禁止回答），AWE 是在**对话流里逐个追问**。前者是工作坊工具，后者是谈话工具。
- vs **论证三件套（学会提问）**：那是拆别人的论证，这是帮对方（或自己）生成更多素材。

## E — 执行步骤

1. **接住第一个答案，不要评价**。对方说完，只回一句「还有什么吗？」（或「还有呢？」），不追加解释、不补充你的看法。
2. **问满三次**。第一次通常还是表层的，第二次开始出现真东西，第三次之后往往出现「其实……」。3–5 个答案之间停手。
3. **你自己想说话时，也用这一句缓冲**。感到建议怪兽升起 → 先说「还有什么吗」→ 把注意力放回对方的回答。
4. **判停点**：如果对方连续两次回答「没了／想不出来了」，停止追问，改用焦点问题（「对你而言，这里真正的挑战是什么？」）切入；继续追问会变成逼供。
5. **收口**。把对方说出的 3–5 个答案原样复述一遍，问他哪个最要紧——这一步交给焦点问题。

**完成标准**：拿到了 ≥3 个彼此不同的答案，且你在整个过程中没有给出任何建议。

## B — 边界

**不要用的时候**：
- **紧急/危机场景**（有人要出事、系统宕机、deadline 在 10 分钟后）——这时候要给指令，不是给问题。
- **对方能力或信息明显不足时**（新人第一次做、完全不懂的领域）——他要的是必要的知识，不是更多提问。反复追问会变成折磨。
- **对方已经明确说「我不需要建议，你直接告诉我答案」**——尊重它。
- **权力落差极大且关系不安全时**（下属面对强势上级的追问会理解为审讯）。

**书中警告的失败模式**：
- **伪问题**：以提问为名的引导（「你不觉得应该先做 X 吗？」）。这不是追问，是伪装的建议，会直接掐死对话。
- **追问变审讯**：超过 5 次、或每次都追问同一个点，对方会感到被拷问。
- **只问不听**：机械重复「还有什么吗」但脑子在想自己的方案，对方感受得到。

**作者盲点（来自阶段 0 批判）**：本书默认对方「愿意且能够自己想清楚」。对能力不足、信息不对称或处于危机中的人，这一假设不成立。另外，AWE 在**文字异步沟通**（群聊、文档评论）中效果会显著衰减——没有即时停顿，追问会显得咄咄逼人。
