# 《关键7问》术语词典

> 术语定义采用**作者本人的用法**，不是字典定义。与常识不同之处已标出。

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| **建议怪兽** Advice Monster | 面对他人问题时，大脑本能地想跳出来给答案、证明自己有价值的冲动 | 常识把「乐于助人」当美德；作者把它命名为需要被**关进笼子**的障碍 |
| **AWE 问题** And What Else | "还有什么吗？"——反复追问以越过第一个表面答案 | 常识追问是「获取信息」；作者用它**同时**做两件事：给对方挖选项 + 给自己争取忍住不说的时间 |
| **焦点问题** | "对你而言，这里真正的挑战是什么？" | 关键在 **"for you"（对你而言）**——把抽象难题收拢成「这个人当下的卡点」，而非客观问题本身 |
| **基础问题** | "你想要什么？" | 不是问需求清单，而是要求对方**对自己的自由负责** |
| **懒惰问题** | "我可以如何帮助你？" | 名字反讽：看似示弱/偷懒，实则是**最有力量的一次授权** |
| **战略问题** | "如果你对这件事说了『好』，那你对什么说了『不』？" | 不是问风险，而是逼出**取舍结构** |
| **省略的否 / 委托的否** | 省略的否 = 说是自动挤掉的选项；委托的否 = 为了让是成立必须停止或改变的事 | 把「机会成本」拆成两个可列清单的具体问题 |
| **学习问题** | "对你而言什么最实用？" | 不是做总结，而是用**峰终定律**主动设置对话的结束时刻 |
| **新习惯公式** | 「当 X 发生时，不做旧的 Y，改为做新的 Z」，新行为需 <60 秒 | 常识谈习惯靠意志力；作者要求**可观察触发 + 微型行为 + 预设挫折** |
| **3P 模型** | Projects 项目 / People 人 / Patterns 模式 | 是**对话开局定位器**，不是优先级排序工具 |
| **TERA 系数** | Tribe 部落 / Expectation 期望 / Rank 排名 / Autonomy 自主 | 把「心理安全感」拆成四个可干预旋钮；大脑每秒五次无意识扫描这四个维度 |
| **戏剧三角** | 拯救者 / 迫害者 / 受害者三种面具 | 作者特指管理者最常滑入「**拯救者**」——拯救正是建议怪兽的表演形式 |
| **教练幽灵** | 讨论第三方而不是实际问题（「他们应该……」） | 焦点问题中 "for you" 是它的解药 |
| **伪问题** | 以提问为名的引导或反问（「你不觉得应该……吗」） | 比直接给建议更糟——它还剥夺了对方反驳的空间 |
| **金鱼问题** | 问「你想要什么」时，人常像金鱼一样鼓眼张嘴 | 描述的是**现象**（人们不知道/不敢要），不是一种提问技法 |
| **奇迹问题** | 假设性的提问，绕过「不知道想要什么」的僵局 | 属于焦点/基础问题的配套工具 |
| **双回路学习** | 不只解决眼前问题，还在过程中创造一个可迁移的学习时刻 | 区别于「单回路」的任务闭环 |
| **峰终定律** | 人对体验的记忆主要由峰值与结束时刻决定 | 用来解释**为什么**要用学习问题收尾 |
| **绩效教练 vs 发展教练** | 绩效教练聚焦解决具体问题（短期、任务导向）；发展教练聚焦处理问题的人（长期成长） | 本书主张**发展教练**，并用 3P 模型判断焦点 |

## 与另两本书的术语对照（跨书链接用）

| 本书术语 | 《问题即答案》 | 《学会提问》 | 关系 |
|---|---|---|---|
| 少说多问（Tell less, ask more） | 广播模式 → 接收模式 | — | **相邻但场景不同**：本书作用于对话中；后者作用于无对话对象的接收场景 |
| AWE 追问 | 问题风暴 | — | 都是「产出更多问题」，但 AWE 在对话流里逐个追问，问题风暴是批量生成 |
| 焦点问题（对你而言） | 问题重构（换钥匙） | — | 焦点在既有困难里**收敛**；重构是**换框架** |
| 战略问题（yes→no） | 猴子优先 | 灰度思维 | 战略问题逼出取舍；猴子优先指出先攻哪个；灰度思维规范结论表述 |
| 学习问题（双回路） | 被动数据 | — | 都强调「从非刻意处获得东西」 |
| 建议怪兽 | 学会不提问 / 效率与权力 | 弱势批判性思维 | 三者都描述「人被自己的惯性堵住」，但层面不同 |
| 新习惯公式 | 主动制造不适 | — | 前者改变触发—反应回路，后者改变输入 |
