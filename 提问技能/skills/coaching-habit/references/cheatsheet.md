# 决策规则速查 — 关键7问（The Coaching Habit）

| 能力 | 一句话规则 |
|---|---|
| AWE 追问：还有什么吗 | 对方给出第一个答案后什么都不评价，只回一句「还有什么吗」，连问三次到 3–5 个答案。 |
| 焦点问题：对你而言真正的挑战是什么 | 从一堆散落的抱怨里收拢出一个具体卡点：问「对你而言，这里真正的挑战是什么？」， 其中的「对你而言」不能省。 |
| 战略问题：说了「好」，对什么说了「不」 | 把含糊的「好」变成真实取舍：列出省略的否（被挤掉的选项）与委托的否（必须停掉的事）， 各 3 项，然后明确说出一个「不」。 |
| 建议怪兽拦截 | 想给建议的冲动不能靠意志力压住——为它写下 ≥3 个可观察的触发点，每个配一句小于 60 秒的拦截句。 |
| 懒惰问题：我可以如何帮助你 | 面对含糊请求先回「我可以如何帮助你？」，把请求具体化的成本推回对方，再决定答应到什么程度。 |
| 新习惯公式：把「知道但做不到」变成可执行替换 | 写成一句：当【可观察触发】发生时，我不做【旧行为】，而是【小于 60 秒的新行为】；再配一份挫折预案。 |
| 开场问题与 3P 定位 | 开口前用 3P（项目／人／模式）做一次定位，再用「最近有遇到什么问题吗？」直接进入对方真正在意的事。 |
| 学习问题与双回路收尾 | 对话结束前问「对你而言什么最实用？」，要求落到「哪件具体的事你会改」，并写下一句话记录。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
