# 《学会提问》术语词典

> 术语定义采用**作者本人的用法**，不是字典定义。

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| **海绵式思维** | 被动吸收、全盘接收、不质疑 | 不是「学习态度好」，作者明确指出其终局是成为「精神奴隶」；但承认它**获取信息轻松**的优点 |
| **淘金式思维** | 主动提问、筛选、评估、与信息源互动 | 不是「批判性思维」的同义词，而是其**操作形态** |
| **弱势批判性思维** | 用逻辑捍卫既有观点，目的是赢 | 常识里「有批判精神」常被理解为此；作者认为这**不是**批判性思维 |
| **强势批判性思维** | 用同一套严格标准审视所有主张，包括自己最珍视的 | 关键在「**包括自己的**」——这是它与弱势的分水岭 |
| **论题** | 讨论的问题；分**描述性**（是什么）与**规定性**（应该是什么） | 常识不区分；作者要求**先判定类型**，因为两类论题的评价标准不同 |
| **结论** | 作者想让你相信什么 | 「**结论本身毫无价值，关键在于理由**」 |
| **理由 / 证据** | 凭什么让你相信；理由是被断言的，证据是支撑理由的材料 | 常识混用；作者要求分开列 |
| **价值观假设** | 论证者未说出口的**价值优先级**（如自由>秩序） | 不是「偏见」；是**任何论证都必须有的**前提，问题在于它是否被看见。不可证伪 |
| **描述性假设** | 论证者对「世界本来是什么样的」未言明的信念 | 与价值观假设的区别：一个关于「应该」，一个关于「是」。**可以被检验** |
| **替代原因** | 同一结果的另一种可能解释 | 核心是打破「相关即因果」的默认联想 |
| **竞争性假说** | 与主流解释并列的、同样能解释现象的其他假说 | 要求**主动构造 3 个**，并给出**区分方法** |
| **灰度思维** | 用「是/不是」之外的方式回答复杂问题 | 不是「和稀泥」；产出的是**带条件的明确结论** |
| **慢思考** | 放慢速度以调动「理性脑」深入分析 | 作为**提问的前置动作**，不只是认知偏好 |
| **证据等级** | 直觉 < 个人经历 < 个案 < 专家意见 < 研究报告 < 有代表性的数据 | 不同类型要问**不同的问题** |
| **数据欺骗性** | 平均数陷阱、缺基数、相对/绝对混淆、图表误导 | 心法：**看到任何百分比，先找它的分母** |
| **谬误** | 人身攻击、滑坡、虚假两难、诉诸公众、诉诸权威、偷换概念等 | 本书只做常见枚举（语料所限），不展开完整清单 |

## 与另两本书的术语对照（跨书链接用）

| 本书术语 | 《关键7问》 | 《问题即答案》 | 关系 |
|---|---|---|---|
| 十大批判性问题清单 | — | 催化性问题配方 | **方向相反**：清单**评估别人的论证**（收敛/检验），配方**构造进攻性问题**（发散/创造） |
| 挖出未说出口的假设 | — | 让错误可见 | 假设卡挖**静态论证的隐含前提**（书面）；错误可见让**自己的错误浮出来**（需他人参与） |
| 论证三件套 | 焦点问题 | — | 三件套拆**文本/论述**，焦点问题收敛**对话中的卡点** |
| 替代原因 | — | 问题重构 | 替代原因检验**因果方向**；重构改写**问题框架** |
| 灰度思维 | 战略问题 | 猴子优先 | 战略问题逼出**取舍**；猴子优先指出**先攻哪个**；灰度思维规范**最终结论怎么表述** |
| 慢思考 | 沉默三秒 | 留白 / 安静思考时间 | 三者都要求「慢下来」，但作用点不同：对话中 / 阅读时 / 独处时 |
| 弱势批判性思维 | 建议怪兽 | 学会不提问 | 都描述「人被自己的惯性堵住」，层面不同：论证层 / 行为层 / 环境层 |
