# 决策规则速查 — 学会提问（Asking the Right Questions）

| 能力 | 一句话规则 |
|---|---|
| 十大批判性问题清单 | 对任何论证逐条过十个问题：定框架（1–2）→ 扫漏洞（3–6）→ 扫盲区（7–9）→ 出条件化结论（10）→ 反向自检自己的立场。 |
| 挖出未说出口的假设 | 从结论与理由之间的缺口倒推出没说出口的假设，分成价值观假设（不可证伪，只能澄清）与 描述性假设（可检验，推翻它整条链就垮），再反向检查自己。 |
| 替代原因与竞争性假说 | 把「A 导致 B」写成一句 → 查有没有对照 → 构造 3 个竞争性假说（反向／第三变量／巧合） → 为每个给出区分方法 → 输出降格结论。 |
| 论证三件套拆解 | 把任何论述拆成论题（判定描述性／规定性）、结论、理由+证据，写成三句话概括；写不出来就不要往下评。 |
| 证据效力与数据欺骗性 | 先给证据定级（直觉＜个人经历＜个案＜专家意见＜研究报告＜有代表性的数据）， 再对每个数字做四查：查基数、查平均、查口径、查图表。 |
| 灰度思维：条件化结论 | 拆掉「要么 A 要么 B」：列出 ≥3 个条件变量，给每个条件配明确判断，并标出无法判断区域及所需信息。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
