## R — 原文

> 论证拆解三要素（先抓框架）：1. **论题**：讨论什么问题（描述性/规定性）2. **结论**：作者想让你相信什么 3. **理由+证据**：凭什么让你相信
> —— 《学会提问》核心框架（语料 S3）

> 先明确对方到底在讨论什么（论题），以及他最终想让你相信什么（结论），这是所有判断的起点。
> —— 语料 S2 归纳的第 1 步

> **结论本身毫无价值，关键在于理由。** 你需要追问：理由是什么？理由能支撑结论吗？理由的可信度如何？
> —— 语料 S2 归纳的第 2 步

## I — 自述

这是所有批判性评估的**第 0 步**：在评价一个论证之前，先把它拆成三件套——**论题、结论、理由+证据**。

为什么必须先做这一步：如果你连对方在主张什么都不确定，后面所有关于漏洞、证据、假设的检查都会**打在错误的目标上**。这是批判性思维里最常见也最致命的错误——花大力气反驳了一个对方根本没提出的观点。

三个构件的关键点：
- **论题**：必须判定它是**描述性**（关于「是什么」，如「这项政策导致了什么」）还是**规定性**（关于「应该是什么」，如「该不该做这件事」）。这个分类**决定了后续的评价标准**——描述性论题看证据与因果，规定性论题还要看价值优先级。
- **结论**：作者想让你相信的那句话。注意区分结论与理由（结论是「所以要……」，理由是「因为……」）。
- **理由 + 证据**：凭什么。本书的立场非常明确——**结论本身毫无价值，关键在于理由**。

三件套的产出是一段不超过三句话的概括：「他在讨论【论题·类型】，主张【结论】，理由是【理由】+【证据】」。写不出这段概括，说明你还没读懂，不要往下走。

## A1 — 书中案例

**教材的体例设计（语料 S1）**：本书作为批判性思维领域的经典入门教材，结构上每一章对应一个批判性问题，读者既可整本读，也可在遇到任何论证时逐条调用。**三件套是这套体系的入口**——它对应全书最前面的两个问题（论题和结论是什么 / 理由是什么），后面所有检查都建立在它之上。

**「结论本身毫无价值，关键在于理由」（语料 S2）**：书中反复强调这一点。实践含义是：当你被一个惊人的结论吸引时（「XX 导致 YY」），正确的第一反应不是判断它「对不对」，而是去找「凭什么」。

## A2 — 触发（未来）

**什么时候用**：
1. 你面对一段较长的论述/文章/报告，不知道从哪里开始评。
2. 你和别人讨论了一阵，发现双方好像在谈不同的事。
3. 你读完一篇文章说不出它的核心主张是什么。
4. 你要写东西，想先确认自己的论证结构是不是完整。
5. 一段话让你很认同或很反感，但你说不清它在说什么（**这是最该用的时候**）。

**语言信号**：「这段在说什么」「他到底想表达什么」「核心观点是什么」「我们是不是在谈两件事」「总结一下这段话」「帮我理一下这个论证」。
中英关键词：`论题` / `issue` / `结论` / `conclusion` / `理由` / `reason` / `证据` / `evidence` / `论证结构` / `argument structure` / `描述性` / `规定性`。

**与相邻能力的区分**：
- vs **十大批判性问题清单**：本卡是清单的**第 1–2 项展开**，只做定位；清单做**完整体检**。**只要快速定位 → 用本卡；要全面评估可信度 → 用清单。**
- vs **挖出未说出口的假设**：本卡拆**明面**结构，那张卡找**暗面**前提。顺序上先本卡后假设。
- vs **焦点问题（关键7问）**：焦点问题用于**对话中帮对方收敛卡点**，本卡用于**拆解一段文本/论述**，无对话对象。

## E — 执行步骤

1. **找论题**。问：「这段在讨论什么问题？」写成一句问句。然后**判定类型**：
   - 「是什么 / 为什么 / 会不会」→ **描述性**
   - 「该不该 / 应不应该 / 要不要」→ **规定性**
   *判据：看作者最终想让你相信的那句话里有没有「应该」。*
2. **找结论**。问：「他最终想让我相信什么？」找关键词（因此、所以、可见、由此可见、我的看法是）。**如果找不到明确结论，明确记为「结论未明示」**——这本身就是一个重要发现。
3. **找理由和证据**。问：「凭什么？」把「因为／由于／鉴于／数据显示」后面的内容列出来，逐条编号。**区分理由（论断）与证据（支撑论断的材料）**。
4. **写出三句话概括**：`他在讨论【论题·描述性/规定性】，主张【结论】，理由是【①…②…】，证据是【…】。`
5. **判停点**：如果三句话里有任何一句写不出来 → 停下来，回去重读。特别地，**如果找不到理由，就不要再评估这个论证**——没有理由的主张不需要批判性思维，只需要一句话：「这只是主张，不是论证。」

**完成标准**：产出一段三句话的概括，其中论题已明确标注描述性/规定性，且理由被逐条编号列出。

## B — 边界

**不要用的时候**：
- **面对碎片化短内容**（一句话热搜、短视频标题）——常常没有完整论证，三件套拆不出来。此时应先溯源。
- **你已经知道论证结构，要做的是深度检查**——直接用十大清单，不必重复本卡。
- **纯信息类文本**（新闻事实报道、操作手册）——没有「主张—理由」结构，不适用。
- **文学作品/抒情文本**——不追求论证结构。

**书中警告的失败模式**：
- **跳到评价**：还没拆清结构就开始说「这个不对」——会打错靶子（稻草人谬误）。
- **把理由当结论**（或反过来）：导致你对着错误的对象做检查。判据是用「因为/所以」检验：结论前面能加「所以」，理由前面能加「因为」。
- **不区分描述性与规定性**：用证据标准去要求一个价值判断（或反之），是两类论题最常见的混淆。

**作者盲点（来自阶段 0 批判）**：本书假设存在一个**可追溯、完整、有作者的论证**。2026 年的现实是大量内容由算法分发或 AI 生成，**常常既没有明确作者也没有完整论证**——三件套的第一步就无从下手。本卡在这种情况下的正确输出是**第 5 步的判停**（明确告知「这不是一个论证，无法拆解」），而不是硬套出一个结构。此外，书中案例多为中性话题，对真正高风险领域（医疗、投资、宣传）的针对性练习不足。
