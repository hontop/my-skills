## R — 原文

> 有没有替代原因？（相关 ≠ 因果）
> —— 《学会提问》十大关键问题第 7 项（语料 S3）

> 发现替代原因与竞争性假说：很多因果关系并非只有一种解释，要主动寻找其他可能的原因，避免被单一结论误导。
> —— 语料 S2 归纳的第 7 步

## I — 自述

这个能力处理的是人类最根深蒂固的一种思维错误：**看到 A 和 B 一起出现，就默认 A 导致了 B。**

它的操作不是「保持怀疑」（那太弱了），而是**主动构造竞争性假说**——为同一个现象，想出至少 3 个不同的因果故事。为什么要 3 个：只有 1 个时你会爱上它；有 2 个时你会二选一；有 3 个时你才会开始问「怎么区分它们」。

三类最常见的替代原因：
1. **反向因果**：不是 A 导致 B，而是 B 导致 A（「成绩好的学生都爱阅读」→ 也可能是阅读好的学生更容易取得好成绩，或者只是聪明孩子两者都做）
2. **第三变量（共同原因）**：C 同时导致了 A 和 B（「冰淇淋销量越高溺水越多」→ 共同原因是「夏天」）
3. **巧合/选择偏差**：样本本身有问题（「创业成功者都辍学了」→ 你只看到了成功的那些）

关键判据（这是本能力的核心）：**相关不等于因果，但也不等于「没有因果」**。正确的输出不是「这个结论错了」，而是「这个结论**还没有被这个证据支持**」——需要什么证据才能区分这几个假说。

## A1 — 书中案例

**书中对「相关 ≠ 因果」的处理（语料 S2 + S3）**：本书把它列为十大关键问题之一，并明确要求「主动寻找其他可能的原因，避免被单一结论误导」。两处独立来源的归纳都强调**主动性**——不是等别人给出替代解释，而是读者自己构造。

**与数据欺骗性的配套（语料 S2）**：书中把「替代原因」与「数据有没有欺骗性」列为相邻但独立的两项——前者处理**因果归因**，后者处理**数字呈现**。实践中两者常一起出现（一个被操纵的百分比 + 一个错误的归因）。

## A2 — 触发（未来）

**什么时候用**：
1. 有人用一个相关性来支持因果主张（「用了 X 的人成绩更好，所以要用 X」）。
2. 你看到一个「A 导致 B」的说法，觉得太顺了、太符合直觉。
3. 你要解释一个现象（「为什么最近状态差」），第一个想到原因就想停。
4. 你要做研究/写论文，需要排除竞争性解释。
5. 一个成功经验被总结成方法论（「成功的人都做 X」）。

**语言信号**：「因为A所以B」「研究表明X的人更……」「说明……」「可见是……导致的」「用了之后明显变好」「这说明了」。
中英关键词：`替代原因` / `alternative causes` / `相关不等于因果` / `correlation is not causation` / `竞争性假说` / `confounder` / `第三变量` / `反向因果` / `归因`。

**与相邻能力的区分**：
- vs **十大批判性问题清单**：本卡是清单**第 7 项的展开**。只查因果归因 → 用本卡；完整体检 → 用清单。
- vs **证据效力与数据欺骗性**：那张卡检查**数字是否被操纵**（口径、基数），本卡检查**因果方向是否成立**。同一个论证常需要两张卡，但问的问题不同：先问「数字对不对」（数据卡），再问「因果成不成立」（本卡）。
- vs **挖出未说出口的假设**：描述性假设里常藏着一个因果信念（「努力就会成功」）——本卡是检验这类信念的具体工具。

## E — 执行步骤

1. **把因果主张写成一句明确的话**：「A 导致 B」。只写「A 和 B 有关」的主张不适用本卡（那已经是相关性表述了）。
2. **问出第一个关键问题**：「**有没有对照？**」——没有对照组的相关性，几乎不能支持因果。这一步常常就能结束检查。
3. **构造 3 个竞争性假说**（必须写满 3 个）：
   - 反向：B 导致 A？
   - 第三变量：有没有 C 同时导致 A 和 B？
   - 巧合/偏差：样本是怎么选出来的？有没有只看成功案例？
4. **为每个假说问「怎么区分」**：如果 A 真的导致 B，我应该还能观察到什么？如果 C 才是原因，我又该看到什么？——**能给出区分方法，才是真正的分析**；给不出的假说只是怀疑。
5. **给出结论的恰当强度**。**不要说「这个结论错了」**，要说：
   - 现有证据**只能支持相关性**，不能支持因果 → 降格表述
   - 若要支持因果，还需要【对照/时序/机制】中的哪一项
6. **反向自检**：对你自己的因果信念（「我状态差是因为熬夜」）做同样的三步——这一步最常被跳过。

**完成标准**：产出 3 个竞争性假说 + 每个假说的**区分方法** + 一段经过降格重述的结论。

## B — 边界

**不要用的时候**：
- **主张本来就是相关性**（「这两者相关」）——不需要反驳因果。
- **有严格实验设计**（随机对照试验、自然实验）——因果已经处理过，重复检查是浪费。
- **机制已经很清楚**（物理、化学的确定性因果）——不适用。
- **时间紧迫需要快速判断**——本能力是深思工具；此时应直接采用领域共识。

**书中警告的失败模式**：
- **停在「相关不等于因果」这句口号**：这是本能力最常见的退化——说完这句话就结束了，没有构造任何替代假说。**判据是你能不能列出 3 个**。
- **走向另一个极端**：因为「相关不等于因果」就否定一切因果推断。正确做法是**降格**，不是否定。
- **只构造不区分**：列出一堆假说但说不出怎么验证，这等于把「有洞见」伪装成了「有怀疑」。

**作者盲点（来自阶段 0 批判）**：本书对因果推断的处理停留在科普层级（相关≠因果 + 找替代原因），**没有涉及现代因果推断的工具**（混淆控制、DAG、工具变量、断点回归等）。对于要做研究的用户，本卡只能作为**第一道粗筛**，不能替代方法论训练。此外，本书的理性主义假设（人主要因为「没看出逻辑漏洞」而被误导）在这里最脆弱——大量因果错觉来自**叙事吸引力**而非逻辑缺陷，指出逻辑漏洞并不能消除一个好故事的力量。
