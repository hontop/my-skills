# 提问技能

把三本提问主题的书，蒸馏成 **4 个可直接调用的 AI Skill（20 张能力卡）**，外加一套把这些卡片练到身上去的骨架与 21 天计划。

| 分册 | 提问的对象 | 一句话分工 |
|---|---|---|
| 《关键7问》 | 人（对话对象或你自己） | 跟人说话：少给建议，多问七个固定问题 |
| 《问题即答案》 | 问题本身 | 自己卡住：换一种问法，改变答案的搜索空间 |
| 《学会提问》 | 别人的主张／论证 | 判断真假：用固定清单把海绵式思维升级为淘金式思维 |

**一句话分流：跟人说话 → 关键7问；自己卡住 → 问题即答案；判断说法真假 → 学会提问。**

## 骨架

先记住这一张图，20 张卡全挂在它上面。

```
              遇到一个「该问什么 / 怎么问 / 信不信」的时刻
                              |
        +---------------------+---------------------+
        |                     |                     |
    跟人说话               自己卡住             判断真假
  《关键7问》8 张      《问题即答案》6 张    《学会提问》6 张
```

判据按顺序判断，不要跳：

1. 有没有对话对象？**有** → 《关键7问》
2. 没有，是自己在卡住、要换个问法 → 《问题即答案》
3. 没有，是拿到一个说法要判真假 → 《学会提问》

**不必平均用力**：critical 6 张练到条件反射，high 6 张要能想起来，medium 8 张知道存在、用时能查。20 张全练到自动化是 20 个 66 天，不现实。

## 安装

把 `skills/` 下四个目录复制到 WorkBuddy 的技能目录即可：

```bash
cp -r skills/* ~/.workbuddy/skills/
```

装好后这四个入口会被自动发现：`questioning-power`、`coaching-habit`、`questions-are-the-answer`、`asking-the-right-questions`。

## 怎么用

**日常**：直接描述你遇到的场景，路由会自动分流。比如「学弟每次都说状态不太好就没话了，我该怎么跟他聊」会命中《关键7问》的 AWE 追问。

**内化**：按 `LEARNING_PLAN.md` 走 21 天。每天 25 分钟，固定结构——

- **忆（5 分钟）**：闭卷回忆到期的卡，想不起来先硬想 30 秒
- **学（10 分钟）**：读新卡的触发信号，先自己想怎么用，再读步骤对照
- **用（10 分钟）**：当天必须在真实场景用一次，并记一句话结果

**知识库页面**（可选，可交互，带自动复习队列和自测）：

```bash
python tools/build_kb.py     # 解析能力卡 → knowledge-base/knowledge.json
python tools/inject.py       # 注入模板 → knowledge-base/index.html
python tools/gen_plan.py     # 生成 LEARNING_PLAN.md
```

## 三个需要用的时候自己补上的盲点

三册共同的局限，蒸馏时已识别但书里没给答案：

1. **都写于前大模型时代**（1978 / 2016 / 2018）。2026 年答案极度廉价，稀缺的已从「产出问题」变成「判断哪个问题值得追」，三册对「如何筛选／下注」着墨都很轻。
2. **信任能力缺位**。《学会提问》只教了质疑，没教「该信谁」。这一半需要自己补。
3. **低权力距离假设**。三册都默认平等、可自由提问的关系。面对导师、上级、评审时，直接问「对你而言真正的挑战是什么」可能触发防御，需改写成中性措辞。

## 诚实披露

- 三本书**均无本地文本**（无 PDF/EPUB），语料由网络检索构建（8 / 11 / 5 个来源）。能力卡 R 段引用策略为「英文原句（可得时）+ 中文版章节位置」，**未伪造页码**。
- 提取阶段淘汰了 3 个单元（《关键7问》基础问题+金鱼／奇迹问题、《问题即答案》提问绿洲搭建、《学会提问》谬误手册），理由分别是语料仅见目录、接近心理安全感常识、仅有名称枚举。
