# 流程性思考 · 案例库

> 蒸馏自王新宇《流程性思维课》。按主题索引，每个案例含「情境 → 流程拆解 → 启示」。
> 用途：回答用户问题时，可快速找到同类案例做类比论证。

---

## 一、生活流程：从使用者动作流程重新看问题

### 1.1 装修（第 1 集）
- **情境**：住久了才发现家里处处不舒服
- **流程拆解**：按使用者动作流程逐环捋——进门（门把手位置是否别扭）→ 换鞋（鞋放门外还是门内，装修时就要留位）→ 老人是否有坐下换鞋需求（凳子放哪）→ 挂衣服 → 开灯
- **启示**：按使用者流程捋一遍，能立刻发现现在装修中让你不舒服的地方。住久了会习惯不舒服（衣服扔沙发），但习惯不等于合理——门口有个挂衣架，乱扔衣服的概率就会降低

### 1.2 婚礼（第 1、2、21 集）
- **情境**：怎么办婚礼不出遗漏
- **流程拆解**：多角色场景（新郎、新娘、双方父母、证婚人、伴郎伴娘、嘉宾、主持人、供应商），以新娘为主流程（角色覆盖法）。四种目标对应四种流程：广而告知 / 收钱 / 给长辈交代 / 给女方美好回忆
- **启示**：按流程梳理，遗漏可能性大幅降低；目标不同，请谁、怎么办完全不同

### 1.3 北方冬季酒店办大型论坛（第 1 集）
- **情境**：上千人论坛，冬天，北方酒店
- **流程拆解**：模拟参加者动作流程——进门 → 脱外套 → 衣服放哪？档次高的酒店会专门隔出存衣处（南方基本没有这个需求）
- **启示**：按动作流程可以预判需求——很多"没想到"是因为没走过别人的流程

### 1.4 找教室/引导牌（第 1 集）
- **情境**：学员早上找上课教室费劲
- **流程拆解**：到大厦 → 找广告牌 → 排队（分高低层）→ 电梯 → 出电梯左右看 → 签到 → 进教室。广告牌应以"去几楼"为主而非讲师介绍；排队位置要标识
- **启示**：引导牌往那一戳是表象上把事情做完；从使用者感受出发，改进空间巨大

### 1.5 让上级舒服的本质（第 1 集）
- **情境**：什么样叫让领导舒服
- **流程拆解**：模仿上级的动作流程，替他把每一个环节想得细致周到
- **启示**：不是拍马屁——本质是能从对方的动作流程视角重新看问题

### 1.6 马尔代夫旅行（第 8 集）
- **情境**：去玩四五天怎么准备
- **流程拆解**：产品流程 = 在岛上玩的 3-5 天；项目流程 = 行前准备。每个岛就是一家酒店，药、护肤品岛上买不到，只带钱不够
- **启示**：先捋产品流程（玩几天怎么玩），再捋项目流程（准备什么支持它）

### 1.7 旅行打包（第 21 集）
- **情境**：以前按小红书清单准备
- **流程拆解**：从出门开始捋全程——锁门 → 宠物寄养 → 花草浇水 → 关灯 → 交通工具 → 证件 → 落地先干什么（冬天去三亚，冬装全塞进行李箱，穿着棉袄在机场蹲着）
- **启示**：从日常习惯捋是短流程；从出门开始捋才是全流程。捋完，背包带什么、托运什么自然分明

## 二、管理沟通：排序即逻辑

### 2.1 被同事背后告状（第 2 集）
- **情境**：同事告恶状，上级看法转差
- **流程拆解**：先定目标——a) 纠正上级对自己的看法：给上级足够事实依据证明没做错，别纠缠"告状者不是个好人"；b) 让上级对告状者印象变差：告对方的状，不用自证清白
- **启示**：目标不同，与上级沟通的流程完全不同。第一反应哭诉"他不是好人"，两个目标都达不到

### 2.2 员工闹事先谈谁（第 4 集）
- **情境**：七八个员工闹事要降薪/开除，两个挑头
- **流程拆解**：不能先谈最乖的（没影响力，回去被一弄又反水）；不能先谈拿不住的挑头者。先问"挑头的人能不能拿得住"——能，先谈挑头；不能，从容易谈的开始。节奏：快速、连续、不留间隔、信息隔开（防串供）。团队仅三人时谁都不谈，出事有证据再谈
- **启示**：谈话顺序是典型隐含逻辑——环境变化（团队人数），结论顺序也变

### 2.3 老大开会发言顺序（第 4 集）
- **情境**：高管会讨论重大决策，老大什么时候发言
- **流程拆解**：需要定调子 → 最先说（先定形式和程序）；没想明白或想看大家想什么 → 最后说；中间说（几人讲下来后决心下了，直接按自己基调走）
- **启示**：发言顺序是管理手段，不是随意发挥

### 2.4 县长书记谁先讲（第 4 集）
- **情境**：分公司开业，当地党政班子都来了
- **流程拆解**：虽然平时跟县长打交道更多，但这个场合书记先说
- **启示**：场合决定排序——跟人的亲疏无关

### 2.5 定工作计划先沟通还是先写（第 5 集）
- **情境**：年底定明年计划，要不要先找主管领导
- **流程拆解**：取决于上级风格——控制欲强、不信任下级 → 先沟通再写；浑浑噩噩型 → 先有想法再找
- **启示**：下意识认为"汇报就该这么做"（适用于所有场景）是有问题的

### 2.6 绩效面谈谁先说（第 6 集）
- **情境**：绩效反馈面谈
- **流程拆解**：必须员工先说，上级无论满意还是不满意都不能先说。上级先说 → 员工陷入辩解争论，反馈完全失控。员工自己说出缺点 vs 你指出缺点，完全是两码事
- **启示**：绩效反馈极重要原则。流程：事先通知 → 说明目的 → 认真倾听 → 自己说 → 达成一致 → 改进提升

### 2.7 空降任职（第 11、12 集）
- **情境**：总部派你去外地管业务（天津调黑龙江，业务涉吉林辽宁）
- **流程拆解**：先辨总部四种目的（做业绩/裁员/背锅/接班站脚跟）→ 去之前：找总部主管部门要资料、找其他地区管同类业务的领导了解（无利益冲突，信息客观）、查资料 → 到任：先跟总经理谈（打消"你来抢位子"的戒备）→ 跟直接下级谈 → 跟业务骨干/关键岗位/代表性员工（新老员工）聊（建业务全貌 + 交叉验证 + 判断部门负责人是否隐瞒）→ 拜访客户/供应商/合作伙伴 → 向总部要支持和资源 → 逐步展开
- **反面清单**：跳过老大直接执行（丢关键环节）；约满腹怨气的离任副总（负面信息无价值，除非贪污/案件）；上来就 SWOT/PEST；上来直接跟不熟的总经理深聊（被影响，产生先入为主的偏见）；以业务员角色做管理者的活

### 2.8 领导不耐烦怎么办（第 18、20 集）
- **情境**：领导最近对我态度不耐烦
- **流程拆解**（分类思维）：a) 与你无关（其自身情绪，忍/哄等状态过，别较劲）b) 与你有关 → 利益冲突（无意中动了奶酪 → 妥协：调整决定让利益回归原状再沟通）vs 非利益冲突（沟通）
- **启示**：定位准，手段才精准；送礼请咖啡对利益冲突毫无用处

### 2.9 领导聊着不爽（第 20 集）
- **情境**：汇报半小时，前面正常，聊着聊着感觉很不爽
- **流程拆解**：用流程回忆汇报内容，找到情绪开始变化的节点——那往往就是不满意的地方

## 三、业务经营：流程、环节与可控性

### 3.1 饭店三列表（第 9 集）
- **情境**：开饭店，精力有限投哪
- **流程拆解**：迎宾 → 引座 → 点餐 → 下单 → 后厨 → 传菜 → 上菜 → 用餐服务 → 结账 → 送客。三列：环节 / 承担职位 / 产出可控性。关键环节 = 点餐（销售）、后厨、用餐服务
- **启示**：迎宾产出"客人收到招呼"完全可控；用餐服务、送客只能算可影响（客人不按你的来）；出现完全不可控环节 = 业务不可控

### 3.2 大厨博弈与预制菜（第 9 集）
- **情境**：大厨难管、预制菜兴起
- **流程拆解**：大厨三核心环节（刀工、配料、火功）训练时间长、难找 → 老板需求强度高只能忍。预制菜裁掉切、配只留颠勺（甚至微波炉）→ 技能要求降低、人好找、大厨贬值、工作难找
- **启示**：预制菜 = 对饭店流程的重新裁造，打掉关键环节。降低员工谈判溢价能力的本质 = 降低自己对其环节的需求度

### 3.3 景区饭店（第 10 集）
- **情境**：火车站/景区饭店又贵又难吃
- **流程拆解**：关键环节根本不在服务链条上——在拉客。战略是宰一次，不是回头客战略，后面所有环节都不是关键环节
- **启示**：相似流程，战略不同，关键环节完全不同——不要盲目模仿

### 3.4 培训审批链（第 10 集）
- **情境**：谈企业培训，对方审批链：培训主管 → 培训经理 → 人力总监 → 董事长
- **流程拆解**：8-10 万培训（含董事长在内的所有高管）→ 董事长是关键；主管是新来的 → 经理是关键；主管是经理带进来的 + 金额不大 → 主管是关键；控制欲强的经理 → 主管和经理只是信息提供环节
- **启示**：关键环节不要基于经验照搬——同一客户换业务，关键环节就变；每次重新梳理

### 3.5 房地产关键环节变迁（第 18 集）
- **情境**：同一家房企不同年代
- **流程拆解**：黄金年代 = 拿地、销售、银行贷款；"活下去"之年 = 销售 + 银行回款（放款速度决定现金流）
- **启示**：关键环节随时期变化，绝不固化

### 3.6 电销团队业绩下降（第 10 集）
- **情境**：电销整体业绩下降，员工没变化
- **流程拆解**：目标客户名单 → 拨打 → 沟通 → 二次沟通 → 成交执行。**分析倒着来**：二次沟通到成交执行的转化率从 3% 降到 1% → 问题定位。**解决顺着来**：前面做得很烂，后面再好也烂——先把前面的解决
- **启示**：销售漏斗就是流程性思考的梳理

### 3.7 网店主流程（第 3 集）
- **情境**：开网店以谁为主流程
- **流程拆解**：角色有店家、客户、平台、供应商——没有任何角色的流程能覆盖其他。客户给钱 → 以客户为主流程；品类很少时也可按物品流转设计，品类多就不行
- **启示**：主流程方法与业务复杂度匹配

### 3.8 海底捞竞争力曲线（第 12、13 集）
- **情境**：为什么海底捞做炒菜必败
- **流程拆解**：横轴环节、纵轴竞争力（高/中/低）。海底捞：迎宾高（曾推洗车服务——场地成本高增值低，撑不过半年）、等位（美甲）、引座好（过饭点仍开放区域）、点餐好（可点半份、服务员劝够吃 vs 中巴楼硬销——三人点八菜两汤，要求退菜被回应"给您换一个"）、后厨薄弱（频频被曝）、用餐服务最猛（免打扰服务）、结账有授权（服务员八八折权限——客户感受好，成本增加）、送客到位（送到门口、抹零痛快）。一般饭店曲线尖峰（个别环节高）；海底捞全环节高 → 成本撑不住 → 做炒菜几个月即挂
- **启示**：竞争力曲线=组织特征；全环节高竞争力意味着成本必崩。另：一袋瓜子案例——服务员多装瓜子"走时拿着方便"，客人感觉赚了主动走人，翻台零怨气（海底捞翻台率曾达 6.27，一般饭店 3，五星级 >0.5）

### 3.9 七天酒店逐环节对标（第 14、15 集）
- **情境**：七天为何崛起、又为何式微
- **流程拆解**：住店流程：定房 → 入住 → 放行李 → 挂衣 → 上网 → 午晚餐 → 洗澡 → 睡觉 → 早餐 → 退房 → 综合评价。定房（很早用携程+互联网自动化，vs 电话定房查无记录）、入住（快捷 vs 高档繁琐、小旅馆给钱给钥匙）、上网（很早免费，vs 五星级 2011 年还收 80/天）、洗澡（"10 秒出热水"）、早餐（商务客人没来过城市需求强度高——曾取消早餐遭大量投诉后恢复）、隔音（一塌糊涂）。亚朵/秋果靠床品、隔音、拖鞋品质、自动连网、早餐崛起
- **启示**：客户需求会变（网速从无到刚需、年轻人早餐在意度升高、一次性拖鞋从无到有）——服务没跟上 = 资源白投。改良式创新 = 在客户关注的环节上超越紧盯的对手

## 四、创新：从动作不适点出发

### 4.1 咖啡杯盖（第 14 集）
- **流程拆解**：平盖（喝完残留蹭衣服）→ 出现斜坡喝口 → 外卖需要加密封盖 + 气孔
- **启示**：一点点变化的积累就是创新——改良式创新

### 4.2 苹果手机（第 15 集）
- **流程拆解**：智能手机看照片从一级级菜单选 → 双指放大缩小。乔布斯晚年研究一个字："手"——让手上动作最舒服
- **启示**：颠覆式创新也符合人性中最舒服的动作流程

### 4.3 白板（第 15 集）
- **流程拆解**：玻璃白板——圆角（防撞）、笔槽（窄不掉但宽好拿放，权衡成本与剐蹭）、轮子（搬运）
- **启示**：观察自己动作流程中不舒服的地方，创新点自然涌现；但找到创新点不一定做（看性价比）——至少要知道为什么不做

### 4.4 儿童反向拉链（第 15 集）
- **流程拆解**：童装拉链固定端与插入端与成人相反——因为大人给孩子拉更方便
- **启示**：从"谁来做这个动作"出发的流程化创新

### 4.5 水表缴费（第 15 集）
- **流程拆解**：抄水表 → 打手电看数字 → 算出水费 → 缴费。改进：打开手电筒的同时水费已算出（数字标准化、计算规则清晰），确认后直接从话费扣——一个动作完成
- **启示**：高频打低频。运营商没做成是因为内部流程复杂（跟财务、自来水公司结算）——除非给折扣券

### 4.6 头脑风暴（第 15 集）
- **启示**：极其低效，出结果成功率低。每个环节微小创新的积累才是巨大变化；每个人从自己环节入手

## 五、趋势预判：画行业全链条

### 5.1 互联网链条演进（第 16、17 集）
- **流程拆解**：PC 时代：电脑 → CPU（Intel/IBM）→ 操作系统（微软）→ 桌面 → 浏览器（网景被微软灭）→ 中文输入法（搜狗 PC 端曾 90% 份额）→ 搜索引擎（百度因谷歌被封兴起）→ 2B 阿里 / 2C 腾讯 = BAT。360 在操作系统启动后嵌入（杀毒）——越往前机会越多。移动互联网：手机 → 高通 CPU → 苹果/安卓（两分天下）→ 运营商 → 输入方式变化（手写/语音）→ 应用分发（豌豆荚被内置取代）→ 2B/2C = TMD（头条/美团/滴滴）。百度掉队（搜索在 App 内完成，不再需要网页端）。远期：可穿戴设备（眼镜、腰带比手机更必备）可能替代手机 → 全链条再变
- **启示**：画行业全流程链条，看自己所在环节的前途。为可危环节提供服务的公司，自身可危（为中文输入法提供服务的公司 vs 语音输入崛起）

### 5.2 运营商与星链（第 16 集）
- **流程拆解**：三大运营商控制上网端，但陷于垄断超额利润未觉危机。星链可绕过骨干网直连个人用户（政策壁垒在控制）
- **启示**：控制关键环节不等于安全——不思考环节前途，壁垒说没就没

### 5.3 无人驾驶卡车（第 16 集）
- **流程拆解**：技术上无人驾驶可行，但 1000 万+卡车司机涉及 3000-4000 万人口生计 → 国家不会允许快速应用（社会不稳定）
- **启示**：技术推理 + 社会背景 = 趋势只延长、不改变。相关行业者思考如何安全退出，而不是继续投入

### 5.4 滴滴（第 16 集）
- **流程拆解**：无人驾驶由车企掌握 → 用户直接去厂家 App → 平台被绕过；国家不灭它是因数百万就业（政治角色），但司机慢慢脱离 → 社会影响力越小死得越快（护城河没了）

### 5.5 头条的突破口（第 17 集）
- **流程拆解**：2B 与 2C 的交集（如支付）并未涵盖所有业务——新闻资讯在两者之外偏 C 端。头条从这里产生足够粘性 → 向 C 端延伸同时向 B 端延伸 → 对腾讯（C 端）的威胁大于对阿里
- **启示**：从流程链条和价值链条中发现突破点；组织成长必然侵蚀已形成的利益格局

### 5.6 在线教育（第 16 集）
- **流程拆解**：疫情期间认为线上必替代线下；疫情一过线下立即恢复。原因：注意力集中（一个人学习易被干扰）、互动（看不到眼神与表情，无法现场调整案例）、反应速度（线上讨论慢）、身体姿态信息
- **启示**：基于流程做行业预判只给大方向；准确率非 100%（保密技术突袭如 ChatGPT）

### 5.7 预判三依据（第 16 集）
1. 历史规律：摩尔定律（18 个月性能翻倍价格减半 → 据说缩到 11 个月）
2. 技术相互带动：画质提升 → 带宽需求 → 算力需求
3. 人性规律：结婚率走低 → 全智能机器人（满足懒惰——干活、贪婪——不花钱、无威胁——不打你不顶嘴、快乐——陪聊）

## 六、失误与教训

### 6.1 中巴楼硬销（第 13 集）
- **情境**：三人被推销点了八个菜两个汤，第三个菜就明确吃不下；要求退菜，经理回应"给您换一个"
- **启示**：点餐是销售环节，但把客人当流量竭泽而渔，倒闭是必然。海底捞同环节反着做（劝你够吃、可点半份）

### 6.2 塑料铅封（第 21 集）
- **情境**：为省钱买塑料铅封；东北同事揭秘：冬天塑料脆，轻轻掰开热水一烫能复原，仓库灯光昏暗看不出——货物被盗都不知道
- **启示**：风险判断靠经验；反向验证要问"这个环节有没有我想不到的被钻空子的方式"

### 6.3 网课掉线（第 16 集）
- **情境**：2020 年线上课掉线，对着空气讲了一小时，学员到处打听"王老师没事吧"
- **启示**：线上场景的失效环节；现场感受不可替代

### 6.4 买土豆故事变体（第 21 集）
- **情境**：经典故事：甲买土豆回来说卖完了；乙问遍三家汇报价格和明天到货。新条件：老板晚上要吃炒土豆丝。丙只问了两家就买回来了——因为炒土豆丝要老土豆（脆不脆看泡不泡水），目标清晰时不需要穷尽所有摊位
- **启示**：听案例要想其他可能性——知道可以这么做而选择不做，与不知道，是两回事

### 6.5 三轮车半小时选点标准（第 20、21 集）
- **情境**：2002 年建汽车运输网络，选点标准之一："骑三轮车半小时内一定能找到卖菜的地方"
- **流程拆解**：仓库 24 小时连吃带住、地处郊区、没外卖 → 得有人做饭（选个做饭好的员工加几百块）→ 买菜开车来回两小时没人干 → 配三轮车
- **启示**：这条标准是从仓库员工的动作流程里捋出来的，不是拍脑袋定的
