# 流程性思考 · 方法论详解

> 蒸馏自王新宇《流程性思维课》（21 集）。本文件是技能的完整参考，SKILL.md 只保留主干。

---

## 一、定义与定位

**流程性思考**：以时间顺序对思路进行系统性梳理，发现规律、找到解决问题办法的思维模式。核心是"捋这根时间线"——正向捋，也反向捋。

### 1.1 它是本能，不是新学问

动物听到声音抬头、饿了去进食，都是流程性反应。训练目标是把本能变成下意识的思维习惯：处理绝大多数问题时，能下意识地先捋时间线。

### 1.2 与演绎、归纳的分野

| 推理类型 | 路径 | 出错方式 |
|---|---|---|
| 演绎推理 | 一般 → 特殊 | 前提不全部为真；前提不完整 |
| 归纳推理 | 部分 → 整体 | 部分无法代表全部 |
| **流程性思考** | **沿时间线捋环节** | **前后环节缺乏必然联系** |

课堂练习（体会"手段对≠结论对"）：
- 比价后得出"京东最便宜" → 归纳（局部推整体）
- 警察凭一堆证据定凶手 → 归纳
- "男人没有一个好东西" → 归纳（没穷尽所有男人）
- "30 多岁男员工头发掉了还不走，说明公司给钱多" → 归纳

**关键认知**：推理手段的正确性不能代表结论的正确性。人际交往中"我的推理明明没错，结论为什么不对"——因为前提条件或推理过程缺少了信息与影响因素。

流程性思考的应对：核心是**寻找前后环节的必然联系**，确保环环相扣，提高判断准确性。它背后也会用到推理，但主线是捋时间线。

### 1.3 为什么叫"流程性思考"

不叫"流程思考"，因为"流程性"指的是：很多事物背后的潜在顺序并不明显，需要主动梳理——这种梳理能力本身就是思维水平。一个思维能力强的人，能把背后的潜在逻辑梳理出来。

**流程入手是思考的原点。**

## 二、五步工作流

### 第 0 步：目标先行

先定目标，再定流程。流程是实现目标的途径；不同目标底下，流程可能有巨大区别。

练习与案例：
- 开高端饭店 vs 开小吃店，流程区别巨大
- 同一门线上课：目标是"卖线上课"还是"把学员引流到线下"，流程不同
- 被同事背后告状、上级看法转差：目标可能是 a) 纠正上级对自己的看法 → 给上级事实证据证明没做错；b) 让上级对告状者印象变差 → 告对方的状。目标不同，与上级沟通的流程完全不同。常见错误：第一反应是找上级哭诉"告状者不是个好人"——两个目标都没达成
- 婚礼的目标至少四种：广而告知（宾客越多越好，前男友前女友都请来）/ 收钱（挑支付能力强的、查过往礼金记录、收款处布置得又大又亮又鲜艳，甚至有唱票、电子屏播礼金）/ 给长辈一个交代 / 给女方留下美好回忆。目标不同，请谁、怎么办、环节设计全不同
- 空降到新地区任职，先判断总部四种目的：a) 去把业绩做起来；b) 去裁员；c) 去背锅（又分：用这种方式让你走人 vs 死马当活马医顺其自然）；d) 去接班——短时间站住脚跟、让总经理信任你比做业绩更重要。目的不同，到任后的工作安排差异巨大
- 典型失误：把不同目的揉在一起（计划里既有做业绩的动作，又有"先查账"这类自保动作）——成功率只能靠赶巧

### 第 1 步：判定主流程

多角色场景下，从主流程入手。四种方法：

| 方法 | 判据 | 典型案例 |
|---|---|---|
| A 角色覆盖法 | 该角色的动作包含绝大多数其他角色的动作 | 婚礼 → 以新娘的流程为主线条（新娘流程最复杂） |
| B 服务对象法 | 服务的角色是谁 | 课堂 → 以学员流程为主（不是讲师） |
| C 物品/信息流转法 | 所有角色都为同一物品或信息服务，按物品/信息经过的环节设计流程 | 顺丰：发货人、快递员、分拨、干线、配送、收货人——所有角色都为包裹服务 |
| D 多主流程并存 | 两类角色流程差异大、交集小 | 滴滴：乘客端 + 司机端两个主流程，还要考虑两端之间的逻辑契合 |

方法 C 与 B 的选择取决于复杂度：开网店，品类少（只卖激光笔、翻页器）可按物品流转设计；品类多则适合以客户（付钱的人）为主流程。

多主流程并存（D）复杂度高——做起来非常困难，好处是一旦做成别人极难突破（滴滴下架一年余，对手仍未能替代）。

### 第 2 步：列环节、排顺序

流程中的每个步骤称为一个环节。

**硬逻辑**：别无选择只能如此——先有食物才能吃；先有工作才有工资；扫码、核酸、疫苗等法律法规要求。硬逻辑之间制约关系清晰，生活经验和常识就会告诉你，通常不需要刻意学习。（注意：违法违规地打破硬逻辑，结果通常很糟糕。）

**软逻辑**：可以设计、可以优化，是学习重点。分两种：
- **明显逻辑**：可以直接观察或意识到的环节顺序——先洗脸再刷牙还是先刷牙再洗脸，是个人偏好（省水省毛巾），无明显对错，一眼可辨
- **隐含逻辑**：见第三节

环节排序案例：
- 课程安排：主办方产品介绍放课前还是课后？课后放人都走了——所以放前面效果更好
- 发言顺序、谈话顺序、请谁先讲话，都是排序问题（见下）

### 第 3 步：产品流程与项目流程

两类流程：**产品流程**（最终要的结果本身）与**项目流程**（为达成产品所做的准备与执行）。

铁律：**产品流程在前，项目流程在后；产品流程决定项目流程。**

- 手机：先有使用流程（产品），再有开发流程（项目）
- 婚礼：先想清楚婚礼怎么办（产品），再定酒店（项目）。西式/中式婚礼对酒店选择有影响；先交钱定了酒店，产品设计就被资源锁死——这是按"时间发生顺序"（提前一年定酒店）而非"逻辑顺序"办事的典型错误
- 马尔代夫之行：玩的 3-5 天是产品流程，行前准备（岛上药、护肤品买不到，只带钱不够）是项目流程
- 大型会议：领导来到走的全程服务是**产品的一部分**。只关注"领导来讲啥"，就是把领导当工具人——用人朝前、不用人朝后，下次凭什么帮你
- 考虑角色时不只看单一动作，要看**前后的动作**：证婚人的名字是生僻字（怎么念）、停车卡/免停车费（重要来宾几辆车应该谈下来）、离席时有人送至门口——这些前后动作都是产品的一部分
- 培训午餐是产品内容的一部分（5980 的课就该管饭）

### 第 4 步：关键环节与资源投入

环节太多，不可能每个都精雕。用三列表分析：

| 列 | 内容 |
|---|---|
| 第一列 | 环节（从流程起点到终点逐一列出） |
| 第二列 | 该环节由哪个职位完成 |
| 第三列 | 该职位产出的可控性：√ 完全可控 / ◐ 可影响 / × 完全不可控 |

前提：任职者能力和态度都满足要求。**不要把人的因素提前放进去**（否则任何业务都做不起来——前台和保安都能把公司业务搞慌）。

判读：
- 出现完全不可控环节 = 无论其他环节多努力，业务结果依然不可控，正常业务流中不应出现
- 大量"可影响"环节 = 事情做起来非常困难，但一旦做成，别人超越你也很难
- 全勾 = 容易 = 竞争激烈 = 行业利润率一定不高（创业前必做此分析）
- 可控性可细分三档：基本可控 / 中等可控 / 基本不可控（滴滴早年极高的估值与其多主流程、多"中等可控"环节的复杂度有关）

**关键环节**：对问题解决或目标实现起重要或主要作用的环节。三条推论：
1. 资源投在关键环节上，产出更好
2. 解决问题从关键环节入手，成效更高
3. 相似的流程，目标不一样、实际情况不一样，关键环节也可能不一样

关键环节的动态性：
- 海底捞 = 用餐服务；街边香菜馆 = 后厨；火车站/景区饭店 = 拉客（战略是宰一次，不是回头客）——别抄作业
- 大企业培训审批链（培训主管→培训经理→人力总监→董事长）：8-10 万的高管培训（含董事长本人）→ 董事长是关键；主管是新来的 → 经理是关键；主管是经理带进来的、私交好、金额不大 → 主管是关键；经理控制欲极强 → 主管和经理都只是信息提供环节。**同一客户，换了业务，关键环节就变；每次解决问题前重新梳理**
- 房地产：黄金年代 = 拿地、销售、银行贷款；"活下去"之年 = 销售 + 银行回款（放款速度决定现金流）

关键环节任职者与博弈地位：
- 饭店关键环节若只在后厨：大厨技能三大核心（刀工、配料、火候），训练时间长、市场上难找——老板需求强度更高，只能忍（忍耐度原理：谁对谁的需求强度更高，谁让步）
- 若关键环节在用餐服务：服务员人多，无法形成利益一致体，永远是服务员对老板需求强度更高——海底捞不怕服务员叫板
- 预制菜 = 对饭店流程的重新裁造：裁掉切、配，只留颠勺（甚至微波炉加热连炒都省）→ 对技能要求降低、市场上更好找、大厨贬值。**降低员工谈判溢价能力的本质，是降低自己对其环节的需求度**

提升路径：提升业绩/技效从关键环节入手；两个关键环节同样重要，先从流程靠前的入手；关键环节在不同时期会变化，不要固化。

## 三、隐含逻辑体系（课程核心）

### 3.1 两种隐含逻辑

1. **应该存在但未能被发现的环节**——因为没有遇到意外、没有遇到问题，所以没意识到它需要存在。例：签到台没写课程名、参加者没有对接联系人。没遇到问题时，你根本感受不到这个环节的存在
2. **不同场景下，各环节之间可以有更好的排序，但没意识到哪种排序效果更好**。例：定明年工作计划，先跟主管领导沟通再写，还是先写完再沟通？取决于上级风格：控制欲强、对下级没什么信任 → 先沟通；浑浑噩噩型 → 先有想法再找。**大多数人下意识认为"汇报就应该这么做"——适用于所有场景的顺序，是不存在的**

### 3.2 隐含逻辑案例库（排序即逻辑）

- 老大开会发言顺序：需要定调子时最先说（先定形式和程序，你们知道该怎么说了）；没想特别明白、或想看看大家都在想什么 → 最后说；中间说（几个人讲下来后决心下了，直接按自己的基调走）
- 员工闹事（七八人，两个挑头）先跟谁谈：不能先谈最乖的（没影响力，回去被一弄又反水）；不能先谈拿不住的挑头者（谈完发现自己揉不住）。先问自己"挑头的人能不能拿得住"——能，先谈挑头的；不能，从容易谈的开始。时间安排：快速、连续、不留间隔、信息隔开（防止串供）。团队只有三人时谁都不谈，出事有证据再谈
- 全公司大会老大老二老三发言顺序：按职务顺序，不能"我来说两句"式随意——对这些隐含逻辑，体制内经历多的人下意识就知道，没经历的人一脸蒙
- 县长 vs 书记谁先讲话：场合决定（虽然平时跟县长打交道更多）
- 空降上任先跟谁谈：先跟上司谈——a) 感受完全不同（先跟员工聊完再找总经理，像纪委）；b) 框架只有总经理能给，员工给的零碎。跳过硬直接执行 = 丢关键环节
- 约离任副总聊：价值很低（走得憋屈、满腹怨气、信息负面、新人做好了反衬其无能——不合人性），除非特殊情况（贪污、业务案件要搞清楚）
- 上来就做 SWOT/PEST：太早——先了解总部和总经理之后再谈
- 直接跟不熟的总经理深聊：容易被影响，产生先入为主的偏见

### 3.3 隐含逻辑 → 明显逻辑 五法

1. **比较法**：两种做法摆在一起比较效果。例：视频做完后先剪辑再加字幕 vs 先调文字再剪辑——后者改的内容最后被删，白做。比较法带团队时帮助员工提升认知最直接有效
2. **向专家学习**：观察法（蹲在专家边上看他干活；淘宝店铺的使用视频演示"先做什么再做什么"）+ 请教法（直接问）。**提问三要点：有哪些环节？哪个环节在前？为什么这个环节在前？**——快速了解一个行业的重要方法
3. **总结法**：查材料、问人都不便时用。例：互联网产品逻辑（试错型：上线-修改-上线-修改）vs 制造业（搞得定定的基本不出问题再上线）——源于生产成本高低与变化速度快慢的差异。跨行业的人常意识不到自己行业的逻辑不能简单套用
4. **复盘**：按流程、从不同角度和角色复盘，专找"什么顺序效果更好"。例：妻子兴致勃勃做了"鸡蛋烧西瓜"，直接批评打击热情——"预议先扬"（先表扬赞同，再谈看法），话还是那些话，顺序反过来效果完全不同
5. **借助数据分析**：从数据挖掘使用逻辑。淘宝/银行 App 首页菜单按使用频率自动上移，省去用户进下级页面寻找的动作

### 3.4 水平的分野

- 在别人看来是隐含逻辑，对你而言显而易见 = 你水平更高（你已不需要讨论就可以这么做）
- 一群人讨论时差异不明显 = 大家在同一个水平上（要差一起差，要好一起好）
- **管理者的要务：让自己的明显逻辑变成下级的明显逻辑**。常见错误：用自己的标准替代别人的标准（"这种事情还需要我教吗？"——下属就是不知道）
- 网红"小张"教坐高铁、看病、买咖啡爆火 = 把某类人群的隐含逻辑变成他们的明显逻辑
- 考察员工：让他讲工作计划，着重听**做事的顺序**

## 四、三种思维模式：流程 · 分类 · 验证

课程总结的六字要诀。流程是主轴，分类和验证是两翼。

### 4.1 分类思维

- 意义：逻辑梳理与问题定位；定位越准，手段越精准
- 案例：领导最近不耐烦 → a) 与你无关（大姨妈/情绪，忍一忍等状态过，别较劲）b) 与你有关 → 利益冲突（无意中动了奶酪，如开掉了领导关系的供应商 → 妥协：先调整决定让利益回归原状，再沟通；送礼请吃饭没用）vs 非利益冲突（沟通解决）
- 两纪律：**分类有层次**（一层层递进找到问题）+ **每层完整分类**（有关/无关、利益/非利益都是完整分类）。思维严谨体现在每一层分类都清晰
- MECE（麦肯锡）：穷尽所有、没有交叉
- 并形分类（各类独立无大小关系）易遗漏：运输方式分铁路/公路/航空/海运——漏了蓄力运输（茶马古道）、航天运输。串形分类（按流程分段，如年龄段 1-20/21-40/41-60/60+）基于流程性思考，不易遗漏
- 王新宇加码：**分类层次尽可能少**（计算机到 U盘：三次分解 vs 两次分解；层次越少定位越快）
- 隐含分类：案例没明说但存在的分类依据（裁员案中绩效、法律属性——超 12 年按无固定期合同处理）。隐含分类与经验和学习有关，体现重点把握能力
- 无意义分类示例：裁员按学历（进来时有用，裁时无用）
- **搜索能力 = 分类能力**：组合关键词维度（名字+公司+职业+地区）一次命中，而不是反复换词瞎搜
- 学习 = 构建领域分类库的过程；分类越多，处理问题时越能快速找到有效分类

### 4.2 流程与分类的先后

理论上都可以（先流程再分类：月份→产品线→销售环节；先分类再流程：产品线→销售季节→流程环节）。选用规则：

- **越熟悉的领域，越适合直接分类**
- **越陌生的领域，越适合流程性思考**（先流程再分类）
- 例：领导聊着聊着不爽 → 用流程回忆汇报内容，找情绪开始变化的节点；招不到人 → 捋流程：职位设置是否合理→广告有没有问题；女朋友生气 → 从微信对话里找节点

### 4.3 验证模式

**正向验证 = 分角色验证**：把流程中每种角色的流程各走一遍，发现缺失。
- 婚礼角色清单：新郎、新娘、双方父母、伴郎伴娘、证婚人、男方/女方家人朋友、主持人、花童、供应商（酒店）。酒逆子发小喝高了会拉架——安排到女生桌、不劝酒，他就不会醉
- 时间成本高，看情况做：关系一般的同学/同事不必详细疏离
- **核心区别：这件事没做，是因为盘算后觉得没必要（可控）；还是没意识到要做（碰巧）。**思维强的人达到"思考之后决策不做"，而不是碰巧没出事

**反向验证 = 特例性验证**：按流程倒退，在每个环节上问"如果出问题，前端有没有应对手段"——即项目管理中的风险管理。
- 直播：网络问题（提前问有没有准备）、摄像机故障（背一台备份）
- 风险三问：① 概率（地震概率极小影响极大 → 不准备）② 影响（茶点不满意概率高但影响小 → 不考虑）③ 应对代价（老师早上挂了，再找个同背景备份老师成本太高 → 算了）
- 风险判断靠经验：塑料铅封冬天变脆，掰开用热水一烫能复原，仓库灯光昏暗看不出——货物被盗都不知道。为省钱买塑料铅封的教训

## 五、训练清单（把本能变习惯）

1. 每天拿一件小事问：目标是什么？主流程是什么？按流程走一遍会漏什么？
2. 遇到"该谁先"的问题，写下两种顺序，推演各自后果
3. 听到一个做法，问：这是明显逻辑还是隐含逻辑？适用边界是什么？
4. 复盘时只问一句：哪个环节换个顺序，效果会更好？
5. 旅行打包：从出门开始捋全程（锁门、宠物寄养、花草浇水、关灯、交通工具、证件、落地先干什么）——捋完，背包带什么、托运什么自然分明。对比"小红书清单"式准备差在哪
6. 判断一门课/一本书：看目录——能看出流程或分类 = 可用性高；两者都看不出 = 可用性低
