# 意识训练教练（Awareness Coach）

蒸馏正念、元意识、注意网络、心流、神经可塑性等权威理论为技能卡，生成 8 周系统版与 21 天轻量版双版本训练计划，自动匹配相似匿名案例，系统提升自我觉察与专注力。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **场景识别与需求分析**：从对话中提取触发事件、持续时长、身体信号、行为模式、自动化思维五维度
- **双版本训练计划**：8 周系统版（每日 15–25 分钟）+ 21 天轻量版（每日 10 分钟内），含周期、频次、剂量、模块、复盘点、进阶规则
- **知识蒸馏技能卡**：10 张理论技能卡（呼吸觉察、身体扫描、专注锚定、思维标记、去融合、心流设计等），每张卡含机制、场景、动作、剂量、进阶、禁忌
- **案例匹配**：14 个匿名案例库，按场景标签检索 3 个相似案例
- **引导训练与动态调阶**：脚本化引导当次训练，按日志复盘调剂量、换模块、修正目标
- **安全边界**：不诊断不治疗；危机信号转介；循证表述不承诺速成

## 使用示例

- 我最近学习时总走神，想提升专注力，该怎么开始训练？
- 给我生成一份 21 天轻量版训练计划，每天 10 分钟。
- 写论文总是进入不了状态，帮我找相似案例参考。

## 知识库结构

```
skills/awareness-training/
├── SKILL.md                    # 使用规范与索引
└── references/
    ├── theories.md             # 10 张理论蒸馏技能卡
    ├── plans-8week.md          # 8 周系统版计划
    ├── plans-21day.md          # 21 天轻量版计划
    └── cases.md                # 14 个匿名案例（A01-A14）
```

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/awareness-coach/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
