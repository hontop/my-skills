# my-skills

个人技能与训练专家集合。

本仓库收录两个可独立使用的 WorkBuddy 专家包（Agent 型），由 WorkBuddy 专家管理器创建、校验、注册并打包，此处为可版本化的源码目录。

## 目录

```
my-skills/
├── 意识训练教练专家/   # awareness-coach：自我觉察与专注力训练
└── 心理训练专家/       # psych-coach：情绪韧性与抗压训练
```

## 1. 意识训练教练专家（awareness-coach）

面向自我意识、专注力与心流状态的训练教练。

- 理论技能卡：MBSR 正念减压、元意识理论、注意网络理论、心流理论、神经可塑性、内观传统等
- 双版本计划：8 周系统版（每日 15–25 分钟）+ 21 天轻量版（每日 10 分钟内）
- 14 个匿名案例（A01–A14）
- 六阶段闭环：场景识别 → 需求评估 → 案例匹配 → 计划生成 → 引导训练 → 复盘调阶

详见 `意识训练教练专家/README.md`。

## 2. 心理训练专家（psych-coach）

面向情绪韧性与心理抗打能力的训练教练。

- 理论技能卡：CBT/REBT、ACT、Gross 情绪调节过程模型、压力接种训练、自我效能、成长型思维、斯多葛控制二分法、创伤后成长 PTG、运动心理技能训练
- 双版本计划：8 周系统版 + 21 天轻量版
- 14 个匿名案例（P01–P14）
- 同一套六阶段闭环

详见 `心理训练专家/README.md`。

## 安全边界（两个专家共同遵守）

- 定位为训练教练，不诊断、不治疗
- 识别到自伤/自杀意念等危机信号时，建议转介学校心理中心或医院
- 「重塑大脑神经」按循证表述：神经可塑性机制真实存在，效果取决于剂量与坚持，不承诺速成
- 持续失眠、躯体症状优先建议就医排除

## 使用方式

在 WorkBuddy 专家中心启用对应专家后，直接描述当前场景（如「写论文总进入不了状态」「答辩前特别紧张」），教练会先做场景识别，再匹配匿名案例并生成带剂量和进阶规则的个人化训练计划。
