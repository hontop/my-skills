# 自我觉察训练 · 16 张技能卡（七段式）

> 每张卡含：理论来源 / 核心机制 / 适用场景 / 训练动作 / 剂量方案 / 进阶规则 / 禁忌与边界。
> 七大体系映射：Jung=J、IFS=I、Polyvagal=P、ACT=A、Siegel+Barrett=W、Kegan=K、Wilber=Q。层级：L0–L5。

---

## A 族 · 觉察基座（练「看见」）

### A1 神经状态判读（体系 P / L0）
- **理论来源**：多迷走神经理论（Porges）——三层神经状态对应不同行为可用性。
- **核心机制**：腹侧迷走（安全/社交，可真实觉察）｜交感（战斗逃跑，激活态）｜背侧（冻结/麻木，关机态）；身体信号先于内容。
- **适用场景**：任何对话开场、深度探索前、用户情绪上头时。
- **训练动作**：用 3 个身体指标判断——呼吸（浅快/深慢）、肌肉（紧绷/松弛）、温度/手心（冷/暖）；输出状态标签〔腹侧/交感/背侧〕。
- **剂量方案**：每日晨起 1 次判读，30 秒；急救时随扰动即时做。
- **进阶规则**：能凭 1 个信号即判状态 → 能预判「今天哪个时段易崩」→ 建立个人状态节律表。
- **禁忌与边界**：不在交感/背侧态下做深度挖掘；背侧麻木态只做落地不分析。

### A2 生理落地与共调（体系 P / L0）
- **理论来源**：多迷走神经理论——慢腹式呼吸激活腹侧迷走，重建安全基线。
- **核心机制**：延长呼气（吸 4 秒/呼 6 秒）提升心率变异性；命名安全线索（脚下地面/靠背支撑）共调。
- **适用场景**：状态判读为交感或背侧时；焦虑发作、睡前、重大事件前。
- **训练动作**：双脚踩地 + 慢腹式呼吸 ×3–5 轮 + 一句「我在这里，是安全的」；可加 5-4-3-2-1 落地（看 5 物/触 4 物/听 3 声/闻 2 味/尝 1 味）。
- **剂量方案**：每次 3 分钟；低谷日只留此 1 个微行为。
- **进阶规则**：从需要引导 → 自主 30 秒完成 → 在真实应激事件中即时启动。
- **禁忌与边界**：背侧态不要求「振作」，只做落地；躯体症状持续超 2 周优先就医。

### A3 注意轮扫描与 SIFT（体系 W / L1）
- **理论来源**：Siegel《觉察的漩涡》注意轮（Hub-Rim）+ Mindsight 的 SIFT 四问。
- **核心机制**：觉知本身（Hub）vs 四域经验（Rim：身体感/意象/情绪/想法）；SIFT=Sensation-Image-Feeling-Thought。
- **适用场景**：日常觉察训练、情绪命名前、睡前大脑停不下来时。
- **训练动作**：2 分钟注意轮——先感受「觉知本身」，再逐一掠过四域；SIFT 四问各写一句：现在身体有什么感？浮现什么意象？什么情绪？脑子里什么想法？
- **剂量方案**：每日 1 轮 2 分钟；W2 起叠加命名日记。
- **进阶规则**：从跟随引导 → 自主扫描 → 在扰动中即时用 SIFT 拉开距离。
- **禁忌与边界**：不评判浮现内容；走神后拉回即训练，不计失败。

### A4 高粒度情绪命名（体系 W / L1）
- **理论来源**：Barrett 情绪粒度理论 + Lieberman「name it to tame it」。
- **核心机制**：情绪词越精确，前额叶调节越强；命名本身降低杏仁核激活（强度可 0–10 自评）。
- **适用场景**：任何情绪出现时；「我很烦/不开心」等粗粒度表达时。
- **训练动作**：用情绪轮细化——「不开心」→「被轻视的羞耻」/「无力的委屈」；给不出名字时给 3–5 个候选词让用户选。
- **剂量方案**：每日命名日记 3 条；每条标强度 0–10。
- **进阶规则**：词汇库从 8 个 → 30+ 个；能从身体感反推情绪词。
- **禁忌与边界**：不在交感态逼命名；命名不替代接住。

### A5 思维标记与观察自我（体系 A / L3）
- **理论来源**：ACT 认知解离 + self-as-context（观察自我）。
- **核心机制**：想法是「在脑中播放的内容」，不是「我」；观察者（天空）与内容（云）分离。
- **适用场景**：反刍、睡前大脑停不下来、被自动化思维占据时。
- **训练动作**：给想法贴类别标签（计划/回忆/担忧/评判/想象）；默念「我注意到我有一个关于……的想法」；「我是天空不是云」。
- **剂量方案**：每日 3 条思维标记；与 B6 解离句式配合。
- **进阶规则**：从识别明显反刍 → 识别隐蔽的自我叙事 → 在情绪中保持观察位。
- **禁忌与边界**：标记不是压制；不评价「不该有这想法」。

### A6 日常觉察锚点（体系 W / L1）
- **理论来源**：注意训练日常化——把觉察嵌入既有行为流。
- **核心机制**：高频低耗的微觉察比偶尔长冥想更易形成神经习惯。
- **适用场景**：日常分心、没时间做主训练时；建立觉察节律。
- **训练动作**：刷牙/走路/喝水/等电梯时，1–3 分钟全程注意动作感受（水温/脚触地/吞咽），不做别的。
- **剂量方案**：每日 2–3 次微锚点，每次 ≤3 分钟（不计入容量）。
- **进阶规则**：从固定锚点 → 任意动作可启锚点。
- **禁忌与边界**：不做成「必须完美完成」的任务；做不做都行。

## B 族 · 内在工作（练「对话」）

### B1 部分识别（体系 I / L2）
- **理论来源**：IFS（Schwartz）——「我」是多部分系统，无单一自我。
- **核心机制**：管理者（控制/批评）/救火者（冲动/逃避）/流放者（承载伤痛）各有保护功能。
- **适用场景**：内在冲突、被某种冲动/想法反复占据时。
- **训练动作**：把冲突双方分别命名成部分，各写一句职责；画部分地图初稿（谁常在、对什么触发）。
- **剂量方案**：W4 建初稿；后续每次扰动识别主导部分。
- **进阶规则**：从识别对立两方 → 看见部分间的保护链 → 地图覆盖多数高频场景。
- **禁忌与边界**：绝不消灭任何部分；不把部分等同于「坏的我」。

### B2 Self 能量 8C 对话（体系 I / L2）
- **理论来源**：IFS 的 Self 能量与 8C（平静/好奇/慈悲/清晰/勇气/联结/信心/创意）。
- **核心机制**：以 Self（非部分）的能量靠近部分，部分才卸下极端角色。
- **适用场景**：与某部分对话、自我否定、内在批评家时。
- **训练动作**：先做 30 秒 Self 连接（慢呼吸 + 「我在这里」）；用 8C 之一（如慈悲）开场问部分「你想保护我免受什么？」；原样记录不评判。
- **剂量方案**：每周 1 次 8C 对话；冲突期可加频。
- **进阶规则**：从需要引导进入 Self → 能在冲突中即时召回 Self 能量。
- **禁忌与边界**：不替部分下结论；保护者值得感谢而非驱逐。

### B3 保护意图探问（体系 I / L2）
- **理论来源**：IFS 保护意图原则——每个极端行为背后是保护。
- **核心机制**：问「你想保护我免受什么？」让部分从防御转为可被对话。
- **适用场景**：自我否定、过度控制、原生家庭议题、任何「明知不好但停不下」的行为。
- **训练动作**：锁定主导部分，单问保护意图；写下答案；不评判、不反驳。
- **剂量方案**：每日 1 次（W5）；原生家庭加成时重点。
- **进阶规则**：从表面保护（怕出错）→ 深层保护（怕不被爱）。
- **禁忌与边界**：不问「你为什么要这样」等指责式；保护意图不等于纵容行为。

### B4 阴影投射识别（体系 J / L2）
- **理论来源**：荣格阴影与投射——我强烈厌恶/嫉妒的，常是我否认的自身面向。
- **核心机制**：情绪强度 > 事件本身时，入口在投射；软语气指认不替用户定性。
- **适用场景**：对某人某种特质强烈厌恶/道德义愤、人际敏感。
- **训练动作**：定位投射入口（「似乎这份强度不只对对方」）；给一个反思问题「若这特质也是我的一面，它在保护/满足我什么？」。
- **剂量方案**：人际敏感/投射加成时触发；S01、S05 用例。
- **进阶规则**：从识别他人触发 → 看见自身对应面向 → 能量收回为自觉。
- **禁忌与边界**：不说「你就是小气」等诊断；不强迫原谅对方；不用评判语气。

### B5 阴影整合（体系 J / L2）
- **理论来源**：荣格个体化——阴影能量转化为意识拥有。
- **核心机制**：被接纳的阴影从「占据我」变为「我可调用的一面」。
- **适用场景**：识别投射后、自我攻击、对特质既渴望又排斥时。
- **训练动作**：写「这个特质的三个用法」；问「若这也是我的一面，它在保护/满足我什么」；记录能量变化。
- **剂量方案**：每周 2 条阴影日记（W6）。
- **进阶规则**：从抗拒 → 承认存在 → 能在该面向出现时自我觉察。
- **禁忌与边界**：整合不是合理化伤害行为；不要求立刻接纳。

### B6 认知解离（体系 A / L3）
- **理论来源**：ACT 认知解离（Hayes）——想法是语言事件，非事实。
- **核心机制**：给想法加前缀「我注意到我有一个想法…」，拉开与内容的融合。
- **适用场景**：反刍、灾难化思维、被「我做不到」等叙事占据时。
- **训练动作**：三句句式当场用——「我注意到我有一个关于……的想法」「我的大脑在播放『……』的故事」「这是一个想法，不是事实」。
- **剂量方案**：每日 1 次解离练习（W3）；反刍加成时加频。
- **进阶规则**：从念句式 → 自然在念头起时标注「这是想法」。
- **禁忌与边界**：解离不替代接住情绪；不用于回避真实问题。

### B7 接纳与价值澄清（体系 A / L3）
- **理论来源**：ACT 接纳 + 价值方向——不抵抗内在体验，按价值行动。
- **核心机制**：抗拒消耗能量；价值（vs 目标）是持续的方向，区分他人期待与自身价值。
- **适用场景**：自我否定、重大决定迷茫、重大决定加成、内耗。
- **训练动作**：价值罗盘问「如果没有任何人知道你的选择，你会怎么选？」；把答案浓缩成一句价值陈述；带着不适做一件价值小事。
- **剂量方案**：W6 接纳练习；重大决定/价值加成时重点。
- **进阶规则**：从识别他人期待 → 写出个人价值句 → 以价值校准日常选择。
- **禁忌与边界**：接纳不是认命；不替用户定价值。

## C 族 · 整合行动（练「整合」）

### C1 主体→客体转化（体系 K / L4）
- **理论来源**：Kegan 成人发展——成长 = 把占据我的东西变成可观察的客体。
- **核心机制**：主体（我被它占据，看不见）vs 客体（我能观察、选择）；转化即自由度提升。
- **适用场景**：被某种情绪/身份/他人目光「占据」、重复困境、方向迷茫。
- **训练动作**：探问「也许你正被____占据，而不只是拥有它」；列「主体→客体清单」：哪些曾是我的牢笼现在成了我的工具。
- **剂量方案**：W7 清单；原生家庭/迷茫加成时重点。
- **进阶规则**：从识别单一占据 → 多层占据同时可见。
- **禁忌与边界**：转化不靠顿悟，靠反复练习；不催促「放下了」。

### C2 四象限全景定位（体系 Q / L5）
- **理论来源**：Wilber AQAL——个体内/外 × 个体/集体 四角。
- **核心机制**：任何议题拆入四角，避免单一归因（尤其集体内象限常替人决定）。
- **适用场景**：重大决定、方向迷茫、自我叙事、关系议题。
- **训练动作**：把议题放入四角各写一句——个体内（感受/信念）/个体外（行为/身体/习惯）/集体内（关系/家庭/文化期待）/集体外（制度/环境/经济）。
- **剂量方案**：W7 一次议题四象限；重大决定加成时重点。
- **进阶规则**：从四角填空 → 看出哪一角在替用户决定 → 主动重选。
- **禁忌与边界**：不替用户做加权；四角平等呈现。

### C3 承诺行动与能力迁移（体系 A / L3 + 长期整合）
- **理论来源**：ACT 承诺行动 + 迁移理论——带着不适按价值行动；同一工具换场景。
- **核心机制**：觉察需落到行动才有整合；迁移让单点能力扩散到生活。
- **适用场景**：结业前、维持期、新场景出现时。
- **训练动作**：带着不适做一件价值小事；把已熟工具（如解离句式）从考前迁到人际/决策场景。
- **剂量方案**：W8 形成个人维持方案（每周 3–4 次、每次 15–20 分钟）。
- **进阶规则**：从单一场景熟练 → 跨场景迁移 → 成为默认应对。
- **禁忌与边界**：行动以不伤害为前提；不要求「克服一切」。
