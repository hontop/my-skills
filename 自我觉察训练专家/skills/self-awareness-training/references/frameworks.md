# 自我觉察训练 · 五框架训练内核

> 五框架各治一种「训练失效」。协作总原则：诊断用系统思维找结构，启动用福格降门槛，单次训练用刻意练习保质量，每周用 PDCA 保改进，长期用流程性思考让训练长在生活里。

---

## 一、流程性思考（元引擎，管「训练逻辑」）

全程捋一根「从被占据到能观察」的时间线。

1. **目标先行**：先确认目标变体——急性急救（单次扰动能接住）/ 症状缓解（指标下降）/ 能力成长（觉察变快）/ 境界维持（日常稳定）——聚焦其一，不把多个目的揉在一起（如「既要治好焦虑又要提升灵性」）。
2. **主流程判定**：以「从被占据到能观察」为主线（信号→命名→接住→选择→行动），不照搬模板。
3. **环节三分**：硬逻辑 = 先稳状态再觉察、先觉察后整合；明显逻辑 = 风格偏好；隐含逻辑追问「放之四海而如此，还是只适用此情此景？」。
4. **产品流程在前**：先想清「觉察用在哪」（哪个真实场景要用这个能力），再排训练日历——不为训练而训练。
5. **关键环节每次重定位**：周复盘不抄上周作业，本周数据最差的环节就是下周资源投向。
6. **双验证**：正向——分角色把本周流程走一遍（我执行/你设计/场景匹配三个视角），专找缺失环节；反向——按流程倒退问「出问题前端有无应对」（崩了→状态判断够不够；看见了接不住→工具熟练度；接住了不行动→C 族缺口）。
7. **分析倒着来解决顺着来**：诊断从后往前找断点，改进从前往后补齐。

## 二、系统思维（管「诊断」：结构不是意志）

把「我总是焦虑」「我停不下反刍」看作系统结构问题，而非意志或悟性问题。

- **结构诊断三件套**：增强回路（越焦虑越反刍、越反刍越焦虑）/ 存量枯竭（睡眠/精力/社会支持耗尽）/ 调节回路缺失（没有刹车）。
- **陷阱六项**：反应迟缓 / 目标侵蚀 / 公地悲剧 / 转嫁负担 / 政策阻力 / 垄断。
- **杠杆点排序**：信息流 > 规则 > 目标 > 自组织。
- **诊断纪律**：「拆掉哪个结构，问题就不治自愈？」只治标（逼自己别想）会怎样越治越糟。

## 三、福格行为模型（管「启动」：B = MAP，先提示再能力最后动机）

行为没发生时，禁止问「你怎么又没坚持」，按固定顺序诊断：

1. **先查提示 P**：是忘了做吗？设计行动锚点，把训练挂到每天必发生的行为之后（「在我 ___ 之后，我会 ___」）。
2. **再查能力 A**：是想起来但太难吗？微小化到「最忙、最累、最没动力的日子也能完成」（30 秒内），小到不可能失败。
3. **最后才查动机 M**：前两步都到位仍不做，才处理动机（换黄金行为）。

动机只能借不能靠：动机高点做难事，动机低谷靠微行为兜底。

**微习惯配方（火种）**：锚点 → 微行为 → 即时庆祝。
- 锚点三条件：每天一定发生、时点明确具体、与训练场景匹配；
- 微行为 ≤30 秒，小到不可能失败；
- 庆祝必须秒级、有生理参与（握拳说「我做到了」/比心/微笑），是编码不是奖励。
- 配方连续 3 天失败 → 重设计配方（换锚点/砍微行为/换庆祝），不问罪、不加意志力。

## 四、刻意练习（管「进步」：每次训练是一张练习卡）

四要素：
1. **单一改进点**：本次只练一个具体点（如「胸闷后 10 秒内命名」而不是「更觉察」）；
2. **专注**：单次觉察训练 5–25 分钟无干扰；
3. **即时反馈**：日志字段（时长/拉回次数/主观难度/情绪强度），分钟级，迟到的反馈会固化错误；
4. **拉伸区**：难度略高于当前水平，成功率目标 0.7–0.8；出现无聊或焦虑都调任务不加时长。

**层级诊断三问**（每次服务至少做一次）：当前练习是「天真的练习」（重复已会的、无具体目标、无反馈）/ 有目的的练习 / 刻意练习？用户说「我再逼自己狠一点」时，直接引用「换着法子试（try differently），不是更努力（try harder）」纠偏。

**长期主线**：构建心理表征——个人「觉察档案」三库：身体信号库（我焦虑前下巴紧）、触发场景库（什么场景引出哪个部分）、有效工具库（哪张卡对我哪类扰动有效）。表征越清晰，觉察越快。

## 五、PDCA 循环（管「循环」：A 栏必须物理变更）

- **P** = 场景识别 + 基线 + 计划（六要素 + 嵌入点 + 配方）；
- **D** = 执行（脚本化引导 + 日志字段）；
- **C** = 周复盘（数据栏看趋势不看单点）；
- **A** = 处理（物理变更三选一：改剂量/改模块/改锚点 + 有效动作固化为个人方案 + 遗留问题进下一轮 P）。

**三个反模式必须点名**：循环空转（C 栏只记数据不改计划）、表演式努力（打卡很满但指标不动）、只 A 不 C（凭感觉调阶没有数据依据）。「下次注意」不算改进。

---

## 三条公理（贯穿所有训练）

1. **先稳状态，再觉察**：没有腹侧迷走状态就没有真正的觉察（多迷走地基）。
2. **先看见，后整合**：没有被看见的内在，只会用更强的方式回来（觉察柱石）。
3. **成长 = 从主体到客体**：把曾「占有我」的东西变成「我可观察」的东西，才是真正的自由。
