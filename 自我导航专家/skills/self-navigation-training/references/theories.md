# 自我导航 · 16 张技能卡（七段式）

> 每张卡含：理论来源 / 核心机制 / 适用场景 / 训练动作 / 剂量方案 / 进阶规则 / 禁忌与边界。
> 六层映射：动机=M、自我认知=C、执行=E、发展=D、叙事=N、系统=S、横切=T。

---

## A 族 · 测绘（练「看清位置」）

### A1 多源基线（层 C / 强）
- **理论来源**：Nisbett & Wilson 1977（内省错觉）；Wilson 2002（适应性潜意识）；Schraw & Dennison 1994（MAI 元认知）。
- **核心机制**：人无法可靠内省真实动因；自评须与外部行为、他评交叉校验。
- **适用场景**：首次接诊、重大转向前、任何"我到底怎么了"的提问。
- **训练动作**：自评（NISE+需要满足含挫伤分量+MAI）+ 他评（3–5 位跨情境者评外显特质）+ 两周行为/美好时光日志；三源矛盾处即盲区。
- **剂量方案**：立项时 1–2 周建基线；之后季度刷新。
- **进阶规则**：从三源收集 → 能标出"我自认 X 但他人评 Y"的偏差带 → 建个人基线档案。
- **禁忌与边界**：不可用单次内省当真相；他评匿名化、跨情境取。

### A2 需要诊断（层 M / 强）
- **理论来源**：Ryan & Deci 2017《Self-Determination Theory》；Slemp 等 2024 元分析（88 万样本）。
- **核心机制**：自主/胜任/归属三需要同时被支持时动机最优；"需要满足"与"需要挫伤"是不同变量（近十年修正）。
- **适用场景**：动力枯竭、半途而废、被迫感、拖延。
- **训练动作**：对每个推进领域问——自主从哪来？胜任是否最优挑战区（非太易非太难）？归属由谁见证？把"必须"改写成"我选择……因为……"。
- **剂量方案**：持续；每次规划前做一次三需要对齐。
- **进阶规则**：从逐条改写 → 能预判"哪类目标天生缺自主、易弃" → 提前补动机配方。
- **禁忌与边界**：不自恋外部奖励；不替用户定"应该"的目标。

### A3 偏差登记（层 C+E / 强）
- **理论来源**：Kahneman 系统 1/2（注明复制争议）；Dunning-Kruger 1999；预测-结果对账范式。
- **核心机制**：低反馈、低可评估处盲区最大；系统性高估/低估需显式台账捕获。
- **适用场景**：重要判断前、事后复盘、高置信决策。
- **训练动作**：维护预测-结果台账（写"我预测__，置信__%"→回填实际→标偏差方向）；标出系统性高估领域。
- **剂量方案**：每月对账；重大判断即时记。
- **进阶规则**：从单条记录 → 提炼"我常在__类判断上偏高"模式 → 进偏差库。
- **禁忌与边界**：不为记而记；偏差用于校准，不用于自责。

### A4 身份系统图（层 S / 理论强）
- **理论来源**：Kaplan & Garner 2017（DSMRI 身份四成分）；Jayasinghe 2026（涌现自我）。
- **核心机制**：身份=信念/目标/自我定义/感知行动可能性的动态系统；"身份吸引子"=反复滑回的构型。
- **适用场景**：反复卡同一类议题、身份滑回、长期模式。
- **训练动作**：用 DSMRI 四成分画当前身份，找卡住的一项；标注触发输入与放大回路。
- **剂量方案**：季度；身份滑回专项时重点。
- **进阶规则**：从画静态图 → 标出吸引子与回路 → 改回路输入而非下决心。
- **禁忌与边界**：身份是描述非定义；不贴"我就是这样的人"死标签。

### A5 叙事地图（层 N / 强）
- **理论来源**：McAdams 叙事身份；Lind 等 2024（9 年纵向，能动性/共融性增量效度）。
- **核心机制**：叙事主题（能动性/共融性、救赎 vs 污染序列）独立预测幸福感；高峰终规则作用于单事件、叙事作用于跨年（不可混用）。
- **适用场景**：被一段经历定义、年度整合、价值拉扯。
- **训练动作**：写下最艰难一段，检能动性（我做了什么选择）/共融性（与谁联结）/结尾（救赎/污染）；先定"若成功会不同什么、对谁"，再改故事。
- **剂量方案**：月/年；被经历定义时即时。
- **进阶规则**：从单段重写 → 看反复出现的序列 → 升级为个人意义框架。
- **禁忌与边界**：不改事实只重构意义；不美化创伤。

### A6 人生工作观（层 M+N / 强）
- **理论来源**：Burnett & Evans 2016《Designing Your Life》（缺长期 RCT，框架优）；SDT 价值冲突。
- **核心机制**：Workview/Lifeview 的冲突处即导航的价值罗盘裂缝。
- **适用场景**：方向模糊、价值拉扯、职业/生活失衡。
- **训练动作**：Workview/Lifeview 各写一页，找冲突处；用"若无人知晓你的选择，你会怎么选"补价值句。
- **剂量方案**：转向时；年度刷新。
- **进阶规则**：从列冲突 → 定位"谁在替你决定"（集体内象限）→ 主动重选。
- **禁忌与边界**：价值观不替用户定；人生设计缺 RCT，提示方法局限。

### A7 寻路 Orient（层 M+S / 强）
- **理论来源**：Burnett & Evans 寻路（wayfinding，缺 RCT）；流程性思考目标澄清。
- **核心机制**：在没地图处先定"不变的方向锚"与"可接受的第一小步"，打破"先想清再动"的瘫痪。
- **适用场景**：不确定期、空白页焦虑、重大未知。
- **训练动作**：写一句方向锚（如"我想更自主"）+ 一个今天可做的第一小步（福格微行为）。
- **剂量方案**：即时；不确定期每日重温。
- **进阶规则**：从第一小步 → 用行动反推地图 → 奥德赛三案并行。
- **禁忌与边界**：不要求想清再动；小步优于蓝图。

## B 族 · 校准（练「调准罗盘」）

### B1 动机重设计（层 M / 强）
- **理论来源**：Ryan & Deci 有机整合理论（外部→摄入→认同→整合）。
- **核心机制**：调节类型越靠整合，动机越自主越持久；"被迫感"多源于外部/摄入调节。
- **适用场景**：被迫感、拖延、半途而废。
- **训练动作**：对目标做整合类型自评，把外部调节推到认同/整合；重述"我做它因为……"。
- **剂量方案**：持续；计划生成前。
- **进阶规则**：从识别外部调节 → 重构价值连接 → 内生动力稳定。
- **禁忌与边界**：不假整合；区分"真认同"与"合理化"。

### B2 元认知校准（层 C+E / 强）
- **理论来源**：基础比率忽视；Wishful thinking/反向思考；Klein 事前验尸（premortem）。
- **核心机制**：高置信判断最易踩盲区；外部基准与反向情景能校正。
- **适用场景**：高置信判断、重大决策、重要预测。
- **训练动作**：基础比率检查 + 反向思考（"我可能错在哪"）+ 事前验尸（"若一年后失败，原因可能是"）。
- **剂量方案**：决策前；每季度重大决策。
- **进阶规则**：从单工具 → 形成"高置信即触发校准"的自动反应。
- **禁忌与边界**：校准不替代决策；只为降偏差。

### B3 变革免疫（层 D / 中）
- **理论来源**：Kegan & Lahey 2009《Immunity to Change》四栏。
- **核心机制**：明知该做却反复不做，源于隐藏的竞争性承诺与大假设；需安全测试而非加压。
- **适用场景**：明知不做、反复破功、内在对抗。
- **训练动作**：四栏映射（目标→反向行为→隐藏竞争性承诺→大假设），对大假设做小规模安全测试。
- **剂量方案**：季度；≥1 次大假设安全测试/周期。
- **进阶规则**：从写四栏 → 设计最小安全实验 → 大假设被经验松动。
- **禁忌与边界**：不施压"克服"；实验须安全可逆。

### B4 决策前提（层 M+E / 强）
- **理论来源**：流程性思考环节三分（硬/明显/隐含逻辑）；锚问题 vs 重力问题（Life-design）。
- **核心机制**：决策卡壳常因隐含前提未显式化；重力问题（结构性不可改）不可当锚问题硬解。
- **适用场景**：决策卡壳、反复纠结。
- **训练动作**：把"如果……就……"隐含前提写出并逐条质疑；区分锚问题（可改）vs 重力问题（结构性）。
- **剂量方案**：决策时；卡壳即触发。
- **进阶规则**：从显式前提 → 识别重力问题并改问法 → 奥德赛三案并行。
- **禁忌与边界**：不替用户定前提；重力问题不硬刚。

### B5 证据分级（层 横切 / 强）
- **理论来源**：元科学素养；效应量修正文献（Gollwitzer&Sheeran 2006+Sheeran 2024；身份化习惯 r=0.55 但干预 g=0.18）。
- **核心机制**：流行方法常效应被高估或因果未闭合；透明标注降低误用。
- **适用场景**：用户带来流行方法、要"速效方案"、引用自助书。
- **训练动作**：给每条建议标证据等级（强/中/弱/自助）；主动提示效应量膨胀与缺 RCT。
- **剂量方案**：每建议。
- **进阶规则**：从被动标注 → 用户能自查"这条证据多硬"。
- **禁忌与边界**：不把自助书当证据；不隐瞒不确定性。

## C 族 · 驾航（练「真的移动」）

### C1 执行分流（层 E / 强）
- **理论来源**：Zimmerman 三阶段循环（前思→表现→反思）；Gollwitzer 执行意图（单次窄窗，d≈0.3–0.5）。
- **核心机制**：任务类型匹配不同执行机制——重复型靠环境设计、单次窄窗靠 if-then、复杂长周期靠循环显式化。
- **适用场景**：启动难、习惯崩、复杂目标。
- **训练动作**：重复型→环境设计+惯例+二元记录；单次窄窗→if-then 执行意图；长周期→Zimmerman 循环进下一轮前思。
- **剂量方案**：持续；按任务类型切换。
- **进阶规则**：从混淆机制 → 一眼判定任务类型并匹配。
- **禁忌与边界**：执行意图只用于单次窄窗；不泛化为万能药。

### C2 原型试错（层 M+E / 强但缺 RCT）
- **理论来源**：Burnett & Evans 奥德赛三案/原型（缺 RCT）；流程性思考路径拆解。
- **核心机制**：低成本原型对话/体验比空想更能揭示真实偏好；三案并行降低单点赌注。
- **适用场景**：人生岔路、转行转专业、方向不明。
- **训练动作**：奥德赛三份五年方案并行；原型对话（访谈 3 位从业者）/原型体验（试做一周）低成本验证。
- **剂量方案**：转向时；每案一个可证伪实验。
- **进阶规则**：从空想 → 真去试 → 用原型反馈修正地图。
- **禁忌与边界**：不在脑中硬推；原型须真发生。

### C3 习惯环境（层 E / 强）
- **理论来源**：Lally 2009（习惯自动性中位 66 天，范围 18–254）；福格 B=MAP。
- **核心机制**：习惯靠频率累积而非意志力；漏一天不伤，漏一周才伤自动性；破罐叙事是最大中断。
- **适用场景**：习惯启动、复工复学、习惯崩。
- **训练动作**：固定线索+降启动摩擦+即时庆祝；识别并改写"漏一天后的破罐叙事"。
- **剂量方案**：启动期每日；22 天不足以自动（中位 66 天，定位启动原型期）。
- **进阶规则**：从靠意志 → 靠环境与锚点 → 自动运行。
- **禁忌与边界**：不追求完美连续；漏一天不补不罚。

### C4 导航迭代（层 S+E / 强）
- **理论来源**：PDCA；Meadows 系统审视；刻意练习迁移。
- **核心机制**：复盘须回到"地图更新了什么"+ 物理变更；同类卡点 ≥3 次强制迁移提取。
- **适用场景**：计划失效、重复踩坑、阶段收尾。
- **训练动作**：周复盘（哪步动了地图）+ 阶段复盘（PDCA 处理栏物理变更）+ 半年系统审视（回路/杠杆）。
- **剂量方案**：周/阶段/半年。
- **进阶规则**：从记完成度 → 记地图变更与迁移 → 系统层看杠杆。
- **禁忌与边界**：复盘不写"下次注意"（非改进）；A 栏不写"更自律"。
