# 法律咨询专家团（Legal Consulting Team）

专业法律咨询团队：解读国内法律法规，提供合同审查、文书起草、案例分析、风险评估与诉讼策略建议。

## 类型

Team 型（多角色协作团队）

## 团队成员

| 成员 | 名字 | 职责 |
|------|------|------|
| 主理人 | 顾衡（首席法律顾问） | 需求受理、问题定性、团队调度、汇编输出 |
| 法律咨询顾问 | 沈知律 | 法律法规解读、法律关系定性、风险评估、解决方案与维权路径建议 |
| 法律文书专员 | 祝文翰 | 合同审查与起草、起诉状/律师函等法律文书撰写 |
| 诉讼策略师 | 孟昭雪 | 类似案例检索、案情与证据分析、诉讼/仲裁/调解策略与成本收益分析 |

## 功能

1. **法律法规蒸馏与咨询**：内置 `law-knowledge-base` 知识库，覆盖民法典、劳动法、合同、借贷、民事诉讼程序、消费与交通事故等常用领域；结合 WebSearch 核验法规时效，给出法律依据、风险评估与多方案行动建议
2. **类似案例检索与案情分析**：诉讼策略师检索公开裁判案例，构建案情时间线与证据清单，预判争议焦点
3. **合同与文书服务**：逐条合同审查（风险标注+修改建议）、常用合同起草、民事起诉状/律师函等法律文书生成
4. **诉讼策略设计**：诉讼/仲裁/调解/和解多方案对比，含时间、成本、执行可行性分析与关键时效提醒

## 内置 Skill

`law-knowledge-base`：7 份法规蒸馏 references（民法典要点、劳动争议、合同、借贷、民诉程序、消费与交通事故、案例检索方法）+ 3 份文书模板（起诉状、律师函、合同审查报告）。

## 使用示例

- 我遇到了一起劳动纠纷，公司拖欠工资还不签合同，我该怎么维权？
- 请帮我审查一份房屋租赁合同，指出对我不利的条款和风险。
- 朋友借钱不还，我想起诉，帮我分析诉讼策略和需要准备的材料。

## 边界说明

本团队提供法律信息与风险分析服务，不构成法律意见，不出具胜诉承诺；涉及重大财产、人身权益或刑事风险的事项，请及时委托执业律师。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/legal-consulting-team/
```

```bash

```
