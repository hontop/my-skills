# 合同审查与起草要点（蒸馏版）

> 核心依据：《民法典》合同编（2021-01-01 施行）+ 各类型合同司法解释。审查合同遵循"效力 → 权利义务 → 违约 → 程序"四步法。

## 一、审查四步法
1. **查效力**：是否违反法律强制性规定、公序良俗；主体是否具备签约资格；是否需审批/登记才生效
2. **查权利义务**：双方义务是否对等；履行期限、地点、方式是否明确；单方权利是否过大
3. **查违约与救济**：违约金比例、定金规则、解除条件、争议解决方式
4. **查程序条款**：通知与送达条款、保密、争议解决（诉讼/仲裁二选一，不得同时约定）

## 二、高风险条款清单（逐条对照）
| 风险类型 | 典型表述 | 问题 | 修改方向 |
|---------|---------|------|---------|
| 权利义务失衡 | "甲方有权随时解除且不承担责任" | 单方免责 | 增加对等解除权与补偿 |
| 缺席违约 | 只约定对方违约，不约定己方 | 显失公平 | 双向违约责任对等设置 |
| 模糊金额 | "费用另行协商" | 履行争议 | 明确金额、税费承担、发票 |
| 无限期模糊 | "尽快""合理期限" | 无法执行 | 改为具体天数 |
| 放弃权利条款 | "乙方自愿放弃诉讼/仲裁权利" | 无效约定 | 删除 |
| 押金风险 | 押金退还条件不明 | 退押难 | 明确退还条件与期限 |
| 口头变更 | "口头约定无效"一刀切 | 不利举证 | 改为书面+邮件等留痕方式 |
| 个人信息过度 | 超范围收集证件信息 | 合规风险 | 限定用途并约定保密 |

## 三、常用条款设计
- **定金/违约金**：定金 ≤ 合同标的额 20%；违约金一般以实际损失的 130% 为参考线，过高可请求调减
- **解除权**：明确列举解除情形 + 兜底条款（"其他致使合同目的不能实现的情形"）
- **争议解决**：被告住所地/合同履行地法院管辖，或明确一家仲裁机构；不得"或裁或审"同时约定
- **通知送达**：约定微信、邮箱、短信等电子送达方式及地址变更通知义务
- **格式条款提示**：免除或减轻提供方责任的条款须显著提示并说明，否则对方可主张该条款不成为合同内容

## 四、常用合同必查点
- **房屋租赁**：产权核验、租期与免租期、押几付几、维修责任、转租与涨租、提前解约、物品交割清单
- **民间借贷**：本金与利息表述、还款方式、担保方式、逾期责任、诉讼时效提示条款
- **劳动/劳务**：主体性质（劳动关系用劳动合同，不用劳务协议规避）、工作内容、报酬与社保、解除条件、保密与竞业
- **服务委托**：服务范围与交付标准、验收机制、付款节点、知识产权归属、成果不达标处理
- **合作分成**：分成基数与结算周期、账目查阅权、退出机制、清算顺序

## 五、起草原则
1. 要素完整：主体信息、标的、数量质量、价款、履行期限地点方式、违约责任、争议解决
2. 表述确定：避免"若干""适当""尽快"等模糊词
3. 留痕设计：约定确认方式（签字+微信留痕）
4. 待填信息用【】标注，禁止替当事人编造事实
