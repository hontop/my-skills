# 类似案例检索指南（蒸馏版）

> 目标：为用户的问题找到有参考价值的公开裁判观点，判断"同类问题法院一般怎么判"。

## 一、检索渠道
| 渠道 | 说明 |
|------|------|
| 中国裁判文书网 | 官方公开裁判文书库，权威性最高 |
| 人民法院案例库 | 最高法建设的参考案例库，含指导性案例 |
| 各级法院官网/公众号 | 发布典型案例与裁判规则 |
| 威科先行、北大法宝等 | 商业数据库（需订阅） |
| WebSearch 通用检索 | 用"案由 + 争议焦点 + 判决/裁定 + 地区"等关键词组合检索 |

## 二、关键词构造技巧
- 基础公式：`案由 + 争议焦点 + 结果词`
  - 例：`劳动争议 未签书面劳动合同 二倍工资 判决`
  - 例：`民间借贷 仅有转账记录 无借条 败诉`
  - 例：`房屋租赁 押金不退 判决 返还`
- 加限定词提高精度：地区（如"北京 互联网法院"）、年份（如 2024）、审级（一审/二审/再审）、法院层级
- 反向检索：检索败诉案例（加"败诉""驳回""不支持"）比只看胜诉案例更客观

## 三、案例参考要点提炼模板
| 项目 | 记录内容 |
|------|---------|
| 案例基本信息 | 案由、审理法院、年份、争议焦点 |
| 关键事实 | 与本案相似的事实特征 |
| 裁判观点 | 法院的认定逻辑与结论 |
| 法律依据 | 判决引用的法条 |
| 参考价值 | 对本案的借鉴点与差异点 |

## 四、使用原则
1. **相似性优先**：事实结构（主体关系、行为模式、证据形态）相似才有参考价值
2. **层级参考**：指导性案例 > 人民法院案例库参考案例 > 地方法院同类判决 > 裁判文书网个案
3. **时效提示**：优先参考近 3 年案例；法规修订后旧案例可能不再适用
4. **不做结果承诺**：个案差异客观存在，须向用户明确"参考≠预判"
5. **无法检索时**：明确告知用户案例部分需联网补充，仅给出基于规则的策略框架
