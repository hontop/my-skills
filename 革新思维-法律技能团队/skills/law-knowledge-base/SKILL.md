# 国内法律法规知识库（蒸馏版）

本 Skill 是法律咨询专家团的共享知识库，把国内常用法律法规蒸馏为结构化要点，供团队成员在分析时快速调取。

## 使用方式

1. **按领域取用**：根据用户问题类型读取对应 reference：
   - 一般民事/合同/侵权/婚姻家庭 → `references/civil-code-highlights.md`
   - 劳动纠纷/工伤/辞退/工资 → `references/labor-dispute-guide.md`
   - 合同审查/起草/条款设计 → `references/contract-guide.md`
   - 借钱不还/借贷纠纷 → `references/debt-and-lending.md`
   - 起诉/仲裁/执行程序 → `references/civil-procedure-guide.md`
   - 消费维权/交通事故 → `references/consumer-and-traffic.md`
   - 裁判案例检索方法 → `references/case-search-guide.md`
2. **文书模板**：起草起诉状、律师函、审查报告时，先读 `templates/` 下对应模板再动笔
3. **时效核验**：知识库为蒸馏摘要，正式行动前必须通过 WebSearch 核验法规是否为最新有效版本，并在输出中注明

## 免责边界
- 本知识库仅提供法律信息摘要，不构成法律意见
- 条文表述以正式法律文本为准；法规修订后以最新版本为准
- 重大事项必须提示用户委托执业律师
