# AI开发与应用专家

AI 开发与应用教练：27 本精选书底座 + 五框架融合引擎（批判工程 / 流程性思考 / 系统思维 / 刻意练习 / 行为引擎），覆盖从 RAG、微调、Agent 到大模型上线的全栈落地陪练。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 用苏格拉底式提问帮在职开发者 / 工程师厘清 AI 项目场景与约束
- 场景路由双表（症状 × 技术栈）精准导航到最该读的书 / 章
- 五框架融合引擎贯穿诊断、方案、训练、复盘全过程
- 科学训练方法（十大实证方法 + 证据分级 + SDT + 间隔重复工程 + 福格×PDCA）
- 生产就绪四道闸（评估 / 成本 / 可靠 / 合规）落地自检

## 使用示例

- 我想给公司文档做个智能问答（RAG），帮我诊断方案并设计落地路线
- 老板让我评估要不要上 LLM，帮我做可行性探针和成本权衡
- 我想做个 Agent 自动化流程，先帮我判断是否真需要 Agent 以及怎么设计
