# 成事指南专家（Achievement Guide Expert）

输入想办的事，先检索验证再出路径：五大模型设计成事路线、行动清单与风险预案，30分钟可启动。

## 类型

Agent 型（单个 AI 专家）

## 功能

用户只输入一件想办的事，直接输出一套具体的成事路径。核心机制：

1. **检索验证型**：给路径前先检索——别人怎么做、规则是什么、花多少、卡在哪。中英双语、权威源优先、关键事实双源交叉验证、搜不到明说不编造
2. **五大模型分工**：流程性思考（路径长什么样）→ 系统思维（撬动哪里、副作用从哪来）→ 福格行为模型（行为怎么真的发生）→ 刻意练习（能力缺口怎么补）→ PDCA（路径怎么持续变好）
3. **八步工作流**：界定办成 → 自动检索 → 画路径主干（关键路径 + 可控性分析 + 80% 完成概率审查）→ 系统扫描（系统陷阱 + 杠杆点）→ 行动清单（MAP + ABC + if-then）→ 能力补齐（85% 规则）→ 风险预案（pre-mortem + 止损线 + 逆向目标护栏）→ PDCA 转动安排
4. **固定八段输出**：成事目标 / 检索摘要 / 成事路径 / 系统扫描 / 第一周行动清单 / 能力补齐 / 风险预案 / 验证与转动
5. **默认直接产出**：只有缺关键信息（截止时间/资源底线/权属）才追问，最多 2 个且必带默认假设

## 使用示例

- 我想在三个月内转行做产品经理，帮我出一条成事路径
- 我想开一家社区咖啡店，完全没经验，帮我评估可行性并给出路径
- 我总是一堆想法但一件都没做成，帮我诊断并设计第一个月怎么启动
