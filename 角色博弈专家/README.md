# 角色博弈专家（role-game-coach）

训练「定位 / 角色 / 博弈」三位一体个人能力的 AI 专家。服务对象以高校学生与职场初期人群为主，核心理念：**先识局，后落子**——位置不是想出来的，是打出来并验证出来的。

## 知识体系

四大知识域蒸馏为 16 张技能卡，分三族：

- **A 族 · 识局**（7 张）：局面框架识别 / 参与方与激励分析 / 均衡思维 / 信号与信息甄别 / 重复博弈与关系视角 / 改变游戏 / 语言游戏识别
- **B 族 · 定位**（5 张）：心智阶梯与空位 / 差异化与信任状 / 七匹马 / 定位三角与定位谈判 / 声誉与标签经营
- **C 族 · 演绎**（4 张）：角色库与身份显著性 / 前后台与印象管理 / 语力工程与表达自检 / 污名与劣势定位管理

理论来源：博弈论（纳什均衡、Schelling《冲突的战略》、Axelrod《合作的进化》）、定位理论（Ries & Trout《定位》《人生定位》、Harré 定位三角）、角色理论（Goffman 拟剧论与《污名》、Burke & Stets 身份理论）、语言哲学（维特根斯坦《哲学研究》《逻辑哲学论》、Austin 与 Searle 言语行为、Grice 会话含义）。

## 双训练引擎

1. **逻辑引擎（维特根斯坦语言哲学七抓手）**：语言游戏识别 / 意义即使用 / 家族相似 / 规则遵循是实践（先自动化后破例）/ 梯子与界限（不可言说层）/ 语力工程 F(p) / 枢轴识别。
2. **五框架融合引擎**：流程性思考（元引擎）/ 系统思维 / 福格行为模型 / 刻意练习 / PDCA 循环。

## 训练闭环

七阶段工作流（局面识别→基线评估→系统诊断→案例匹配→计划生成→引导训练→周复盘调阶）+ 单次博弈五步内循环（识局→定策→演绎→校验→归档）+ 长期外循环（日课→复盘→档案→迁移）。12 周进阶版与 21 天轻量版双版计划骨架，8 大场景加成模块，容量校验与熔断规则，博弈日志台账为唯一状态真源。

## 使用方式

1. 在 WorkBuddy 专家中心选择「角色博弈专家」开始对话；
2. 首次对话回答三问：最近最想赢/最被动的一个对局、持续多久、每天可投入时间；
3. 对局前用「推演五步」场景提示词做准备；对局后归档一条博弈档案。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安全边界

博弈工具仅用于识别局面、公平竞争与自我防卫：不生成欺诈/胁迫/操纵/违法的具体方案；不诊断、不开药、不替用户做真实决策；法律纠纷转介执业律师；自伤自杀意念或持续功能受损转介学校心理中心/医院。
