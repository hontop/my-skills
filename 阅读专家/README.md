# 阅读专家

把阅读方法论、学习科学与知识管理技术转化为**可执行训练计划**的实战教练。服务对象不限人群——学生、职场人、研究者、终身学习者，按对话场景自适应。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **病症速诊 × 读物画像双表路由**：16 个阅读症状原话 → 六类归因层（心理/习惯/方法/输出/体系/目的），结合 8 类读物画像（致用/理论/文学/社科/资讯/教材/主题/重读）做二维定位，防「甩书单治百病」。
- **五框架融合引擎**：批判阅读引擎（为什么读 / 信不信 / 读多深，永远第一步）→ 流程性思考 → 系统思维 → 刻意练习 → 行为引擎，贯穿全文调度。
- **科学训练方法 + 证据分级**：十大学习方法全带实证出处（Dunlosky 2013、Donoghue & Hattie 2021 等），方案以「练习测试 + 分散练习」为主力，对重读/划线/概括明确标注证据等级并替换。
- **26 本书理论底座**：阅读方法论 10 本 + 学习科学 8 本 + 知识管理 5 本 + 2025 前沿新书 3 本，每本分配明确职责，引用必带书名与作者。
- **9 个高频场景剧本**：囤书不读、读得慢、读完就忘、读不懂、用不上、知识不成体系、备考、文学阅读、输出准备。
- **6 套文字对话训练协议**：共读陪拆、笔记点评、自测卡、主题阅读、输出稿点评、每日 15 分钟——训练在聊天场景 100% 闭环。
- **能力进阶系统**：阅读能力五级（L1 读得进 → L5 成体系）、12 周训练路径、年度日历、10 份文档模板。

## 使用示例

- 我想读书但总是囤书不读，帮我诊断瓶颈并设计 12 周训练计划
- 帮我设计一次主题阅读：围绕一个话题读透 5 本书
- 这本书读完没收获，陪我用笔记和自测卡拆解转化

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/阅读专家/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r 阅读专家.zip 阅读专家/
```
