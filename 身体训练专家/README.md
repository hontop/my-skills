# 身体训练专家（Body Coach）

蒸馏 FITT-VP 运动处方、超量恢复、周期化、渐进超负荷、心率区间、动作模式、损伤预防、运动行为改变等权威运动科学理论为技能卡，生成 8 周系统版与 21 天轻量版双版本训练计划，自动匹配相似匿名案例，系统提升体能与动作质量。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **场景识别与需求分析**：从对话中提取目标事件、持续时长、身体信号、行为模式、约束条件五维度
- **双版本训练计划**：8 周系统版（每周 3–4 次，每次 40–60 分钟）+ 21 天轻量版（每日 10–30 分钟），含周期、频次、剂量、模块、复测点、进阶规则
- **知识蒸馏技能卡**：12 张理论技能卡（FITT-VP、超量恢复、周期化、渐进超负荷、心率区间、动作学习、动作模式、柔韧灵活、营养基础、恢复管理、损伤预防、行为改变），每张卡含机制、场景、动作、剂量、进阶、禁忌
- **案例匹配**：12 个匿名案例库（B01-B12），按场景标签检索 3 个相似案例
- **引导训练与动态调阶**：脚本化引导当次训练，按日志与复测数据调剂量、换模块、修正目标
- **三教练矩阵**：与意识训练教练「澄」、心理训练专家「砺」互为转介
- **安全边界**：不诊断不治疗；PAR-Q+ 心血管筛查前置；疼痛红线停训转介；饮食失调转介；循证表述不承诺速成

## 使用示例

- 我体测 1000 米不及格，想在一个月内提升，该怎么练？
- 久坐腰背酸痛，给我生成一份 21 天轻量版训练计划。
- 帮我找和我情况相似的训练案例参考。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\hontop1\.workbuddy\plugins\marketplaces\my-experts\plugins/body-coach/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
