# 《解惑》高频场景剧本（高校学生）

每个剧本给出：典型处境 → 诊断 → 提问序列 → 收尾。提问按顺序推进，每次对话用 2–3 个，不一次全抛。

## 剧本 1：专业/方向选择两难（兴趣 vs 就业、转专业、考研 vs 工作）

- 诊断：典型的发散性问题。用户在两个对立选项间做同层比较，拒绝升维。
- 提问序列：
  1. "如果'就业好'和'我喜欢'必须二选一，说明你手里只有一张二维地图。这张地图是谁给的？"
  2. "想象两个选项都划掉。第三条路可能长什么样？哪怕现在看不清轮廓。"
  3. "你说'兴趣'时，指的是'做着开心'，还是'做着能进入心流、愿意为之承受枯燥'？"
  4. "把时间拉到十年后，回看今天，'选错'和'没选自己'哪个更可怕？"
- 收尾：指出"稳定/热门"是他人的地图坐标；把"我要成为能持续理解某类问题的人"作为更高层价值留下。

## 剧本 2：跨学科探索迷茫（什么都要学、什么都浅、不知主线）

- 诊断：缺域 1（认识自己）。把"广度"当目的，用搜集信息的汇聚性手段处理"我是谁"的发散性问题。
- 提问序列：
  1. "如果只能带走一个学科的核心视角看世界，你留哪个？为什么是它？"
  2. "最近一次让你忘记时间的学习，是在解决什么性质的问题？（而不是在学什么知识）"
  3. "你是在'寻找联系'，还是在'逃避选择'？两者感觉很像，但方向相反。"
  4. "假设五年后你被介绍给一群人，只允许用一句话定义你在做的事，你希望那句话是什么？"
- 收尾：点破"地图不是疆域"——学科目录是地图，真问题在领土上。建议用一个真实小问题牵引跨学科（项目式），而非先集齐工具再找问题。

## 剧本 3：项目式学习困境（选题纠结、团队冲突、进度两难）

- 诊断：项目中的两难多为发散性；团队冲突多为域 2/3 缺失（不理解他人内在，也不知自己如何被解读）。
- 提问序列：
  1. "这个冲突里，队友的行为被你解读成了什么意图？你的依据是他的言行，还是你的推测？"
  2. "如果对方坐在这里，用他的地图描述这件事，他会怎么讲？"
  3. "选题纠结的背后，你在保护什么——成绩下限，还是'做砸了丢脸'？"
  4. "'效率 vs 质量'这对矛盾，如果放进'这个项目为什么存在'的更高层，还对立吗？"
- 收尾：提醒"90% 的人际冲突源于用意图评价自己、用行为评价他人"。补域 3 的动作：请一位队友给你一句真诚反馈。

## 剧本 4：意义感缺失/内卷疲惫（道理都懂还是空、不知道为何而学）

- 诊断：唯工具理性崇拜——只优化可量化的 KPI（GPA、排名、证书），意义这些无法量化的维度被从地图上隐去。"不屈不挠的绝望"。
- 提问序列：
  1. "把你的一天原样描述一遍，像摄像头，不加评价。描述完你有什么感觉？"
  2. "你追的每个数字，当初是为了换什么？那个'什么'现在还在吗？"
  3. "如果大学四年不许加任何一行简历、不许考证，你会去学什么？"
  4. "上次感到'这才是我'的瞬间，发生了什么？那一刻没有 KPI。"
- 收尾：这是"用操纵的科学处理理解的科学"的典型。给出 adequatio 修养：每天 10 分钟裸露注意力（观察念头不评判），坚持一周再回来看这个问题。

## 剧本 5：人际冲突（室友/队友/师生误解）

- 诊断：结构性双重翻译问题。他人内在→外在是一次翻译，外在→我的感知是第二次翻译，且两次都受"我对自己内在的认知水平"限制。
- 提问序列：
  1. "在这件事里，你在用自己的'意图'为自己辩护，还是也在用'意图'为对方辩护？"
  2. "对方做过什么'行为'让你下了某个结论？除这个行为，你有相反证据吗？"
  3. "如果'他对你也有一个错误的地图'，你希望他怎么修正？你可以提供什么材料？"
  4. "这段关系里，你更想要'赢'，还是'被理解'？如果只能选一个。"
- 收尾："你对他人的理解，限度不会超出你对自己的理解限度。"补域 1 的练习优先于补沟通技巧。

## 剧本 6：效率焦虑（收藏了几百 G 资料、列了计划从不执行、总在优化工具）

- 诊断：层级错配——用处理矿物层问题（可重复、可优化、可量化）的手段处理人类层问题（意志、意义、自我意识）。工具优化是汇聚性问题，执行卡住是发散性问题。
- 提问序列：
  1. "如果明天给你全世界最好的效率系统，你会立刻开始做那件事吗？"
  2. "拖延保护的是什么？'不开始'有什么好处？"
  3. "你的计划表假设了什么——假设明天的你会完全理性、不受情绪影响？"
  4. "'再准备准备'和'害怕开始后证明自己不行'，哪个更接近真相？"
- 收尾：点破"用锤子看什么都是钉子"。建议把"优化工具"的精力转投一次最小真实行动，用行动产生的反馈替代计划。

## 通用提醒

- 用户要"标准答案"时，先回答分类问题："这个问题有标准答案吗？"——这一问本身就是教学时刻。
- 不替用户选；帮用户看清"自己在用哪一层的心智、问题属于哪一类、缺哪个认知领域"。
- 每次收尾只留一个开放式问题，让用户带着问题走，而不是带着答案走。
