## I — 自述

纯金属原子排列规整、层间易滑移所以软；掺入异质原子后晶格被打乱、位错运动受阻，强度上升（青铜≈90% 铜＋10% 锡；钢＝铁＋碳）。

映射骨架：①**新性质来自组合本身**（强度、抗腐蚀、寿命），不是任一方的属性；②**同质叠加不是合金**——想法趋同、盲区重合只是数量增加，所以要找互补者而非相似者；③**配比是核心变量**——太少无效、太多变脆不稳定，诀窍在找到"甜点/黄金比例"；④**知识也是一种合金**——理论＋实践诀窍＋智慧缺一不可（懂得离合器原理，不上手照样熄火），医学联合用药同理；⑤**与金属不同，人的合金会碎**，需要共同目标与持续信任维系。

这是隐喻映射，不是化学定律在社会中的严格成立——"晶格"与"比例"无法客观量化，配比只能事后调、不能事先算准。

## A1 — 书中案例

**特库姆塞与布罗克（1812 年战争）**：兵力不足，无法正面击退美军守住加拿大 → 肖尼族酋长特库姆塞提供地形知识与老练战士，英军少将布罗克提供火力与战术理解，两个背景迥异的人形成合金主打心理战 → **合起来的能力不是相加而是相乘**，他们能做到任何一人单独做不到的事 → 不战而取底特律堡。

**乔布斯与沃兹尼亚克（人的合金会碎）**：两人单独都做不出后来的苹果 → 乔布斯的商业与营销直觉 ＋ 沃兹尼亚克的工程能力形成合金 → 找互补者而非相似者 → 创造出单人做不出的公司与产品；但 Macintosh 上市时乔布斯疏远了 Apple II 团队与沃兹尼亚克，促成后者离开——**人的合金会断裂**，这是金属没有的失败模式。

**达·芬奇（知识作为终极合金）**：单一学科不足以产生突破 → 持续好奇、细致观察、挑战教条，主动跨学科组合（自然启发艺术、戏剧启发光学）并积极向他人求知 → 亚里士多德列出的知识五要素（科学、技艺、实践智慧、直觉、智慧）本身就是一份合金配方 → 产出超越时代的成果；15 世纪佛罗伦萨鼓励跨学科混合的环境是关键土壤。

## A2 — 未来触发

1. **触发场景**：组队/招人时犹豫"找像我的还是找不同的"；讨论总在同一套语言里打转、盲区反复踩坑；问"我该补哪门技能"；两部门合并后希望产生协同。
2. **语言信号**：再招一个和我一样的人（hire someone like me）／强强联合（combine strengths）／跨界、交叉、互补（cross-disciplinary / complementary）／复合背景、斜杠（hybrid skill stack）／一加一等于十（one plus one equals ten）。
3. **与相邻能力的区分**：vs `activation-energy`（加柴，同一路径投更多能量）、vs `catalysts`（降垒，换低能垒路径）——本卡答"**该换/加什么成分**"；vs `cooperation-symbiosis`——合作强调互利交换与信任（并警惕滑向寄生），本卡强调异质组合产生涌现属性与配比，不一定涉及交换；vs `niches`/`competition`——若问的是"我和谁撞车了"，那是生态位问题。

## E — 执行步骤

1. **定义想要的新性质**：完成标准——一句话说清"抗腐蚀/抗弯/耐高温"这类具体属性，不许写"更强"。
2. **列现有成分及其单独性质与能力边界**：完成标准——成分表 ＋ 各自边界。
3. **找互补而非相似的元素**：完成标准——至少有一项是你明显缺失的。
4. **定比例并小步调整**：完成标准——先小比例试、按结果调，禁止一次到位。
5. **检验涌现性质**：完成标准——出现单独任一方都不具备的能力，且能被**第三方**观察到；观察不到即非合金。
6. **设维护机制（判停点）**：完成标准——有共同目标与定期信任动作；若共同目标消失或互信下降，解散重组，不要靠追加资源硬撑。

## B — 边界

1. **何时不用**：需要单一极致专精的场景（此时"纯金属"更好），混合只会稀释；小任务不必组建合金。
2. **书中警告过的失败模式**：①只找"像自己的人"，盲区不减少；②**比例失调**——异质成分过多会变脆（内耗、决策瘫痪），过少没效果；③**把堆人头当合金**，人数增加不等于涌现；④忽略维护成本，目标一散合金就裂（乔布斯/沃兹尼亚克是反例）。
3. **相邻易混方法论**：不要把"分工"当合金（那是效率安排），也不要把"多样性指标"当合金（那只是成分清单）——检验点永远是能否出现第三方可见的新能力；若只出现成本上升而无涌现，立即停止加成分。
