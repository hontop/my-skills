## 认知与推理（第 1 册）

| 概念 | 作者的定义 | 章位 |
|---|---|---|
| 思维模型 | 事物运作方式的一种再现；对现实的简化，用于解释与预测 | 前言 |
| 地图 / 疆域 | 地图＝任何描述、模型、报表、理论；疆域＝被描述的真实世界。地图的价值在于解释力与预测力 | V1-01 |
| 制图者 | 地图的创作者；地图必然反映其价值观、标准与局限 | V1-01 |
| 能力圈 | 拥有"挣来的知识"的领域；判据是能否精确说出边界 | V1-02 |
| 挣来的知识 | 多年观察 + 亲身参与 + 失败经验形成的知识，不可速成、不可伪造 | V1-02 |
| 第一性原理 | 特定情境下不可再简化（irreducible）的元素；不等于绝对真理 | V1-03 |
| 类比推理 | "因为它像以前做过的某件事"而做某事；省脑力但只产生微小迭代 | V1-03 |
| 共同信仰 | 除自然法则外的一切约束（金钱、边界、比特币），原则上可重设计 | V1-03 |
| 苏格拉底式提问 | 澄清→挑战假设→找论据→换视角→探后果→质疑原问题（六步） | V1-03 |
| 思想实验 | 在"心智实验室"中探究事物本质的想象工具；可探索不可能情境 | V1-04 |
| 变异法 | 思想实验与物理实验共有的方法：连续改变情境以扩展观念适用范围 | V1-04 |
| 一阶 / 二阶思维 | 一阶＝直接结果；二阶＝结果背后的结果 | V1-05 |
| 意外后果定律 | 二阶思维的别称 | V1-05 |
| 概率思维 | 用数学与逻辑工具估算特定结果发生的可能性 | V1-06 |
| 贝叶斯更新 | 遇到新信息时将其纳入考虑的过程 | V1-06 |
| 基准率 | 同类事件的历史频率，作为先验 | V1-06 |
| 肥尾 / 薄尾 | 极端事件有无真正上限；肥尾域点预测失效 | V1-06 |
| 元概率 | 对自己估计误差本身（大小、方向）的估计 | V1-06 |
| 上行选择权 | 主动进入赔率有利的场合 | V1-06 |
| 正确地失败 | 适度冒险、永不出局 + 从失败中学习 | V1-06 |
| 逆向（Inversion） | 从相反端点切入；"避免愚蠢比追求智慧容易得多" | V1-07 |
| 力场分析（勒温） | 驱动力与制约力并存；多数人只做前者 | V1-07 |
| 奥卡姆剃刀 | 竞争假设中选包含最少假设的那个；"如无必要，勿增实体" | V1-08 |
| 汉隆剃刀 | 能解释为愚蠢的，就不要解释为恶意；含主观意图最少的解释可能性最大 | V1-09 |
| 可得性启发 | 不当地赋予鲜活易记的证据更高权重 | V1-09 |
| 可证伪性 | 能说出"什么观察会推翻我"的属性（波普尔划界标准） | V1-配套1 |
| 必要条件 | "没有它就不行"（No A, no B） | V1-配套2 |
| 充分条件 | "有了它就行"（A implies B） | V1-配套2 |
| 相关系数 | 两个指标之间共享因素的相对权重，介于 −1 与 1 | V1-配套3 |
| 均值回归 | 只要相关不完美，极端群随时间向均值移动，无需任何原因 | V1-配套3 |

## 物理学（第 2 册）

| 概念 | 作者的定义 | 章位 |
|---|---|---|
| 参考系 | 观察者所在的位置/运动状态；决定了你能看到什么 | V2-物理01 |
| 相对主义 | 被作者明确排除："并非所有视角同等有效" | V2-物理01 |
| 相互作用 | 你对事物采取的行动，都会反作用到你自己身上 | V2-物理02 |
| 以牙还牙 / 宽恕型以牙还牙 | 重复囚徒困境中最有效的策略；后者更优，能打破背叛循环 | V2-物理02 |
| 熵 | 系统的无序程度 / 不可用于做功的能量 | V2-物理03 |
| 孤立系统 | 不与外界交换能量与物质的系统；熵增严格适用的前提 | V2-物理03 |
| 辐射 / 对流 / 传导 | 三种传热方式，被映射为三种社会传播模式 | V2-物理03 |
| 惯性 | 物体抵抗运动状态被改变的性质；质量越大越难加减速 | V2-物理04 |
| 动量 | p = m × v；质量与速度越大，越难停下也越难调头 | V2-物理04 |
| 逃逸速度 | 约 7 英里/秒；最大的力必须用在最开始 | V2-物理04 |
| 摩擦 | 阻碍相互接触的物体发生运动的力；无摩擦就无法起步或刹车 | V2-物理05 |
| 黏度 | 流体各层相互滑动的难度；其影响取决于所处尺度 | V2-物理05 |
| 安东绳 | 丰田生产线上任何工人都能拉停整条线的装置 | V2-物理05 |
| 速率 vs 速度 | 速率只是运动；速度还包含方向（位移/时间） | V2-物理06 |
| 杠杆 / 筹码 | 以较小的力获得不成比例的巨大结果；人世间依托"共同认可的价值" | V2-物理07 |
| BATNA | 谈不成时的最佳替代方案；"最好的杠杆是不需要这笔交易" | V2-物理07 |
