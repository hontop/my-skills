# 决策规则速查 — 思考的框架（第 1 册 + 第 2 册）

| 能力 | 一句话规则 |
|---|---|
| 地图不等于疆域本身 | 现实是终极更新——任何模型/报表/简历都只是地图，用它之前先问它丢弃了什么，并至少做一次不经过它的一手核验 |
| 能力圈 | 圈的**大小**不重要，重要的是知道边界在哪——圈外不是必败，是优势转移到了别人手上 |
| 第一性原理 | 除了自然法则，一切都是共同信仰——把「确知为真」从"只是假设"里剥出来，再带着硬约束重建方案 |
| 思想实验 | 在「心智实验室」里推演无法直接实验的情境——先做基础研究划出已知边界，再变异变量，最后必须保留被证伪的可能 |
| 二阶思维 | 然后呢？——把一阶、二阶、三阶后果分栏写满，圈出不可逆项，并注意「一阶为负、二阶为正」往往是竞争者更少的机会 |
| 概率思维 | 不追求确定答案，先找基准率、给出粗糙但明确的赔率，判断薄尾还是肥尾——肥尾域不做点预测，改为调仓位确保输得起 |
| 逆向思维 | 避免愚蠢比追求智慧容易得多——把「怎样做到 X」翻成"怎样保证一定得不到 X"，然后既加驱动力、更削减制约力 |
| 奥卡姆剃刀 | 解释力相当时，选假设最少的那个——每多一个变量就多一次出错机会；但简单不能自证，且世界有时就是复杂的 |
| 汉隆剃刀 | 能解释为愚蠢的就不要解释为恶意——取含主观意图最少、且仍能解释全部事实的那条作默认解释；但恶意一旦被证实就毫不留情 |
| 可证伪性 | 说不出「什么观察会推翻我」的说法，不是更可靠，而是根本没上过考场——把主张改写成可检验形式并预先写死证伪条件 |
| 必要性和充分性 | 必要条件集合是充分条件集合的子集——两者之间那道鸿沟由运气与偶然构成，再多的必要条件也填不满 |
| 因果关系与相关关系 | 相关不证明因果——先量化相关系数，把因果方向倒过来念一遍，再问「这些样本本来是不是极端值」（均值回归） |
| 相对性 | 你看到的世界取决于你的参考系——承认盲区并叠加异质视角；但视角不同不等于所有视角同等正确 |
| 相互作用 / 互惠互利 | 你希望世界变成什么样就先做到什么样——先手给出、用最小的力、按总账而非单次结算；一次性博弈不适用 |
| 热力学：一切都无法逃脱热力学定律 | 秩序是偶然、混乱是常态——想维持差异就得算清绝缘体的持续成本；但完全均衡等于死寂，温差是必要的 |
| 惯性 | 惯性解释的是阻力大小不是方向对错——先估算「质量」（存在多久、嵌入多深），再把 60–70% 的资源前置到启动 |
| 摩擦力和黏度 | 先减阻再加力——列出阻力清单并标注层级与尺度，优先把处置权交给最接近问题的人；摩擦也可主动制造或当武器 |
| 速度（不是速率） | 速率确保运动，速度产生结果——先定义位移，砍掉不产生位移的忙碌，并注意规模越大越难调头 |
| 杠杆 / 筹码 | 筹码的价值在对方眼里而不在你手里——清点、验证对方感知、校准压力、守住退出权；最好的杠杆是不需要这笔交易 |
| 活化能：抵达终点 | 真正的变革要投入「形成新键」的能量而不只是"打破旧键"——定义终点态、准备引火物、多点点火，量不够就加码而不是延长等待 |
| 催化剂 | 催化剂只加速本来就能发生的反应——先确认趋势已存在，再选技术/人/制度做小剂量测试；方向错了加催化剂会加速灾难 |
| 合金化：整体大于各部分之和 | 找互补者而不是相似者——异质成分按恰当比例结合能产生涌现性质；比例太少无效、太多变脆，且人的合金会碎 |
| 进化（上）：自然选择与灭绝 | 适应只在此时此地有效——列出当前被奖励的性状并判断其环境稳定性，找出跌破即不可逆的「种群密度」临界点 |
| 进化（下）：适应率与红皇后效应 | 决定胜负的不是存量实力而是适应率——比较你与对手的适应速度，并优先盘点现有能力的新用途（外适应） |
| 生态系统 | 先画成分与依赖图，找出「谁走了系统会瘫痪」和限制你的最稀缺资源；封闭一段它只会换个方式自组织 |
| 生态位 / 利基市场 | 先判断自己是广适还是特化——特化要满足「小到没人愿意抢、大到能养活你」；与强势者完全重叠就必须做资源分割 |
| 自我保护 | 先识别是战、逃还是冻（冻最需要外部打断），再找出对方真正要保护的是命、地位还是意义——这是激励他人的入口 |
| 复制：坚硬的概念装在柔性的包装里 | 成功的复制内置一点灵活性——内核（≤3 条）绝不能变、包装必须因地制宜，并写清 what/why 而不是只给 how |
| 合作 / 共生 | 合作是各补缺口而不是单方索取——列缺口清单 × 可供给清单找交集，并定期复核关系有没有滑向寄生 |
| 等级组织 | 等级无法废除只能善加利用——同时画出正式等级与影子等级，检查信息是否被过滤，最容易的领导方式是服务 |
| 激励 | 永远不要在应该思考激励的时候去想别的事——对每个行为问「谁因此得到了什么」，并找出谁没有动机去找反面证据 |
| 最小化能量输出的倾向 | 最省力法则同时适用于体力与认知——有效的设计必须顺应而不是对抗它：把正确行为的能量成本降到最低 |
| 竞争（配套理念） | 明确争夺的到底是什么资源——与谁生态位完全重叠就必须资源分割；那一点「有意义的优势」会被放大成淘汰性优势 |
| 邓巴数字（配套理念） | 稳定社会关系的上限约 150——超过后必须靠共同信念、规则与中间层替代人际熟悉；社交精力按 5/15/50/150 分层投入 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
