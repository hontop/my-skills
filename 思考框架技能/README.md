# 思考框架技能

由《思考的框架》（The Great Mental Models，沙恩·帕里什 / Shane Parrish）第 1 册 + 第 2 册蒸馏而成。

原书 34 个思维模型 / 配套理念 -> 编译为 9 个可独立触发的 Skill + 1 个路由入口。

## 9 个独立 Skill

| Skill | 触发话术 |
|---|---|
| `map-not-territory` | 这份数据能信吗 |
| `circle-of-competence` | 这事我该不该接 |
| `first-principles` | 成本为什么降不下来 |
| `second-order-thinking` | 之后会怎样 |
| `probabilistic-thinking` | 该投多少 |
| `inversion` | 怎么做一定会失败 |
| `hanlons-razor` | 他是不是故意的 |
| `friction-viscosity` | 为什么这么卡 |
| `incentives` | 为什么没人动 |

## 路由入口

`sikao-de-kuangjia-router` - 路由入口：承载 25 个能力 + 概览 / 术语词典 / 速查表
其余 25 个能力（思想实验、奥卡姆剃刀、热力学、惯性、催化剂、红皇后、
生态位、邓巴数字等）均由它按需分发。

## 目录结构

```
思考框架技能/
  README.md               本文件
  knowledge-base.html     知识库骨架 + 学习计划 + 易混辨析（单文件，可交互）
  BOOK_OVERVIEW.md        整书理解（阶段 0 产物）
  sikao-de-kuangjia-router/

  second-order-thinking/
  probabilistic-thinking/

  friction-viscosity/

```

每张能力卡为六段结构：R 原文引用（标出处）/ I 自述 / A1 书中案例 /
A2 触发场景 / E 可执行步骤 / B 边界与失败模式。

## 安装方式

把上面 10 个目录整体复制到 WorkBuddy 的技能目录：

- 用户级（跨项目可用）：`~/.workbuddy/skills/`
- 项目级：`{your-project}/.workbuddy/skills/`
