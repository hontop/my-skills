# 匿名案例库（心理训练）

> 案例来源：匿名化训练记录 + 文献典型情境整理，仅作参考方向，不照搬。检索时按场景标签匹配 3 个最相似案例。

## P01 考试失利后自我否定

- **用户画像**：大二学生，高数期中 58 分
- **情境描述**：之后两周回避数学课，默认「我智商不行，肯定挂」，作业抄同学的
- **场景标签**：失败归因 / 自我概念 / 回避
- **理论假设**：固定型归因把单次结果泛化为能力判定；回避保护自尊但阻断掌握经验
- **干预模块**：卡03 归因重构 + 卡01 自动思维记录 + 卡10 韧性档案
- **周期剂量**：21 天版第 1–2 阶段；每次挫败后归因重构 + 每日 1 条记录
- **效果证据**：3 周后重新交作业，期末该科 71 分（匿名训练记录）
- **可复用要点**：归因三行法是入口；恢复行动比「想通」更重要

## P02 答辩竞选失败挫败

- **用户画像**：大三学生，竞选学生会部长落选
- **情境描述**：落选后一周不想社交，反复回放答辩现场说错的每句话
- **场景标签**：反刍 / 社会比较 / 挫败恢复
- **理论假设**：反刍注意固化在负性细节；缺少情绪调节工具中断
- **干预模块**：卡01 自动思维记录 + 卡05 接纳去融合 + 卡10 意义重写
- **周期剂量**：8 周版 W1–W2+W5–W6；每日 1 条记录 + 每周 1 次意义重写
- **效果证据**：2 周后反刍时长从每晚 1 小时降至 15 分钟（匿名训练记录）
- **可复用要点**：「我注意到我有一个关于说错话的想法」对切断回放极有效

## P03 人际冲突被孤立

- **用户画像**：大一学生，与室友矛盾后宿舍关系紧张
- **情境描述**：觉得所有人都在议论自己，上课一个人坐，食欲下降
- **场景标签**：人际敏感 / 被排斥焦虑 / 灾难化
- **理论假设**：「被议论」是自动化思维的灾难化推断；注意窄化只收集负性证据
- **干预模块**：卡01 自动思维记录 + 卡02 ABCDE + 卡04 控制二分
- **周期剂量**：21 天版第 2 阶段；每日 1 条记录 + 每周 2 次辩论
- **效果证据**：3 周后灾难化思维频次从日均 6 次降至 1 次（匿名训练记录）
- **可复用要点**：D 栏「证据是什么」是核心一问；可控圈练习减少对他人想法的消耗

## P04 求职被拒连续受挫

- **用户画像**：大四学生，秋招 20 投 0 offer
- **情境描述**：从「再试试」变成「我什么都不行」，开始逃避招聘会
- **场景标签**：连续挫败 / 自我效能崩塌 / 回避
- **理论假设**：掌握经验连续缺失侵蚀自我效能；失败被归因为全局稳定因素
- **干预模块**：卡03 归因重构 + 卡10 韧性档案 + 卡09 自我对话
- **周期剂量**：8 周版 W3–W4+W7–W8；每周 2 次归因重构 + 3 句脚本 + 档案更新
- **效果证据**：4 周后单周投递从 2 份恢复至 8 份，第 6 周拿到 offer（匿名训练记录）
- **可复用要点**：韧性档案在连续受挫时是「自我证据链」；脚本要具体到下一个动作

## P05 论文被拒科研失败

- **用户画像**：研二学生，论文二拒
- **情境描述**：觉得两年白费，想退学；回避导师
- **场景标签**：科研挫折 / 存在性怀疑 / 意义感
- **理论假设**：结果绑定自我价值；缺少对「过程价值」的重构框架
- **干预模块**：卡10 意义重写 + 卡03 归因重构 + 卡05 接纳去融合
- **周期剂量**：8 周版全周期，重点 W7–W8；每月 1 次意义重写
- **效果证据**：6 周后与导师重建沟通，转投期刊（匿名训练记录）
- **可复用要点**：意义重写处理「两年白费感」；先恢复沟通再谈修改论文

## P06 完美主义导致拖延

- **用户画像**：大三学生，课程作业永远最后一天交
- **情境描述**：怕做不好所以迟迟不开始；开始后反复修改细节
- **场景标签**：完美主义 / 拖延 / 条件性自尊
- **理论假设**：「必须做好否则没价值」的非理性信念驱动回避-赶工循环
- **干预模块**：卡02 ABCDE + 卡06 情绪工具箱 + 卡04 控制二分
- **周期剂量**：8 周版 W3–W6；每周 2 次辩论 + 工具箱整理
- **效果证据**：4 周后作业启动时间从 deadline 前 1 天提前至前 5 天（匿名训练记录）
- **可复用要点**：辩论焦点是「完成比完美更可能被认可」；先用「烂开始」破回避

## P07 与他人比较产生焦虑

- **用户画像**：大二学生，刷朋友圈后焦虑
- **情境描述**：看到同学获奖或实习就心慌，觉得自己落后，静不下心学习
- **场景标签**：社会比较 / 错失焦虑 / 价值外置
- **理论假设**：价值标准外置给他人进度；注意持续扫描「落后证据」
- **干预模块**：卡04 控制二分 + 卡02 ABCDE + 卡05 接纳去融合
- **周期剂量**：21 天版第 1–2 阶段；比较冲动出现时即兴分栏
- **效果证据**：3 周后刷圈后焦虑时长从 2 小时降至 20 分钟（匿名训练记录）
- **可复用要点**：分栏把「别人的进度」挪进不可控圈；比较冲动来了先用一句去融合

## P08 当众表达紧张

- **用户画像**：大二学生，课堂展示手抖声音颤
- **情境描述**：展示前一周开始失眠，现场大脑空白，觉得「全场都在看穿我」
- **场景标签**：表现焦虑 / 社评恐惧 / 生理唤醒
- **理论假设**：威胁评估过高 + 生理唤醒无管理策略；缺预演与赛前例程
- **干预模块**：卡08 心理预演 + 卡09 自我对话 + 卡06 反应调节策略
- **周期剂量**：展示前 21 天版第 3 阶段；每日 1 次预演 + 3 句脚本 + 上台前慢呼吸
- **效果证据**：下次展示自评紧张度从 9/10 降至 5/10，完成脱稿（匿名训练记录）
- **可复用要点**：预演必须含「忘词怎么办」；脚本指向下一句内容而非「别紧张」

## P09 失恋情绪低落

- **用户画像**：大三学生，恋爱三年分手
- **情境描述**：两个月吃不下睡不稳，课上流泪，什么都提不起兴趣
- **场景标签**：丧失 / 抑郁情绪 / 功能下降
- **理论假设**：丧失事件触发悲伤流程；注意与意义系统同时受创
- **干预模块**：卡05 接纳去融合 + 卡10 韧性档案 + 卡06 注意部署策略
- **周期剂量**：8 周版 W1–W2+W5–W6；每日 1 次接纳 + 每周 1 次档案更新
- **效果证据**：4 周后睡眠恢复正常，能完成日常课业（匿名训练记录）
- **可复用要点**：悲伤不需要「治好」需要「陪伴」；注意部署策略先保睡眠和吃饭
- **边界提示**：持续 2 周以上功能受损建议同时求助学校心理中心

## P10 家庭压力与父母冲突

- **用户画像**：大三学生，父母要求考公，自己想深造
- **情境描述**：每次通话都吵，挂电话后半天无法学习，觉得无人理解
- **场景标签**：家庭冲突 / 价值冲突 / 情绪残留
- **理论假设**：不可控的他人期待占用大量情绪资源；缺少沟通后的情绪复位工具
- **干预模块**：卡04 控制二分 + 卡05 接纳去融合 + 卡06 注意部署
- **周期剂量**：21 天版第 1–2 阶段；冲突后即兴分栏 + 5 分钟复位
- **效果证据**：3 周后冲突后恢复时间从半天缩至 30 分钟（匿名训练记录）
- **可复用要点**：分栏聚焦「我能决定什么」；复位练习（慢呼吸+散步）切断情绪残留

## P11 竞赛失利想放弃

- **用户画像**：大二学生，数模竞赛省二
- **情境描述**：觉得一年努力白费，退出社团，说「以后不碰竞赛」
- **场景标签**：成就挫折 / 放弃冲动 / 反刍
- **理论假设**：单次结果被当作能力终审；缺乏「策略-结果」分离的归因训练
- **干预模块**：卡03 归因重构 + 卡07 压力接种 + 卡09 自我对话
- **周期剂量**：8 周版 W3–W4+W7；归因重构 + 阶梯重建信心
- **效果证据**：4 周后重返竞赛队，次年获省一（匿名训练记录）
- **可复用要点**：把「我不行」拆成「哪个策略可以改」；压力阶梯从小挑战重建掌控感

## P12 转专业环境适应困难

- **用户画像**：大一末转专业学生，融入不了新班级
- **情境描述**：没朋友、课跟不上，后悔转专业，每天最怕下课
- **场景标签**：适应障碍 / 孤独 / 后悔
- **理论假设**：新环境注意持续扫描威胁信号；基线社会支持中断
- **干预模块**：卡01 自动思维记录 + 卡06 情绪工具箱 + 卡10 韧性档案
- **周期剂量**：8 周版 W1–W6；每日 1 条记录 + 每周 1 次工具箱整理
- **效果证据**：6 周后结交 2 位稳定伙伴，课业追上（匿名训练记录）
- **可复用要点**：「没人理我」要记录证据再辩论；工具箱先解决「下课 10 分钟怎么过」

## P13 面对导师批评过度恐慌

- **用户画像**：研一学生，被导师当面指出论文问题
- **情境描述**：之后一周不敢发邮件，反复检查每个用词，失眠
- **场景标签**：评价恐惧 / 权威焦虑 / 过度准备
- **理论假设**：批评被解读为全面否定；用过度准备缓解不可控焦虑
- **干预模块**：卡02 ABCDE + 卡04 控制二分 + 卡08 心理预演
- **周期剂量**：21 天版第 2–3 阶段；每次被批评后 ABCDE + 沟通场景预演
- **效果证据**：2 周后能主动约导师沟通，邮件 1 封内发出（匿名训练记录）
- **可复用要点**：辩论「批评=否定」的等式；可控圈内行动是「改论文」不是「改到完美再发」

## P14 时间不够用的慢性焦虑

- **用户画像**：大二学生，课业+社团+考证
- **情境描述**：每天列 10 项待办完成 4 项，睡前焦虑「永远追不上」
- **场景标签**：慢性焦虑 / 过载 / 失控感
- **理论假设**：任务量持续超过可控圈容量；用「待办清单」量化自己的失败
- **干预模块**：卡04 控制二分 + 卡06 情绪工具箱 + 卡09 自我对话
- **周期剂量**：21 天版第 1 阶段起；每日 3 件要事 + 睡前一句脚本
- **效果证据**：3 周后日完成率从 40% 升至 80% 以上，睡前焦虑下降（匿名训练记录）
- **可复用要点**：把清单从 10 项砍到 3 件要事；「今天做完 3 件就是赢」脚本
