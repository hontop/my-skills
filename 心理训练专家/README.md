# 心理训练教练（Psychological Training Coach）

蒸馏心理韧性、CBT/REBT、ACT、情绪调节、压力接种、成长型思维、斯多葛哲学等权威理论为技能卡，生成 8 周系统版与 21 天轻量版双版本训练计划，自动匹配相似匿名案例，系统提升情绪韧性与抗压能力。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **场景识别与需求分析**：从对话中提取压力源类型、持续时长、身体信号、回避行为、自动化思维五维度
- **双版本训练计划**：8 周系统版（每日 15–25 分钟）+ 21 天轻量版（每日 15 分钟内），含周期、频次、剂量、模块、复盘点、进阶规则
- **知识蒸馏技能卡**：10 张理论技能卡（自动思维记录、ABCDE 辩论、归因重构、控制二分、接纳去融合、情绪工具箱、压力接种、心理预演、自我对话、韧性档案），每张卡含机制、场景、动作、剂量、进阶、禁忌
- **案例匹配**：14 个匿名案例库，按场景标签检索 3 个相似案例
- **引导训练与动态调阶**：脚本化引导当次训练，按日志复盘调剂量、换模块、修正目标
- **安全边界**：不诊断不治疗；危机信号转介；不承诺速成

## 使用示例

- 最近压力很大、总失眠，想做心理韧性训练，从哪开始？
- 考试失利后一直自我否定，帮我设计 8 周心理训练计划。
- 当众发言就紧张，有相似案例和训练方法吗？


